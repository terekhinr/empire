# Штерн · «История гирь» — источники для рубрики

Рубрика в Empire: `data/stern_rubrics.json` → `kettlebell_history`.  
Посты **без LLM**: цитата + источник + короткий комментарий канала.  
Ротация: `stern_content.RUBRIC_ROTATION` (понедельник — история гирь).

## Что пошло не так в выпуске «федерация XXI в.»

Выпуск `hist_modern_federation` был **общим** («любитель vs атлет»), без дат и без книги/регламента.  
Строка «История не спорит с фитнес-гирёй» — слабый комментарий редактора, не факт.  
Карточка **отключена** (`deprecated`); вместо неё — `hist_competition_standard`.

## Куда смотреть (подбор материалов)

| Тип | Примеры | Зачем |
|-----|---------|--------|
| **Энциклопедии / статьи** | Википедия «Гиревой спорт», «Гиря» (снаряд); Britannica kettlebell | Хронология, термины |
| **История ФК и спорта** | Учебники и обзоры по истории физической культуры в СССР/РФ | Массовый спорт, секции, разряды |
| **Музеи** | Экспозиции по торговым мерам веса, реконструкция литой гири | XVIII–XIX вв., «гиря на базаре» |
| **Цирк и силачи** | Архивы цирковой прессы; биографии (см. рубрику «Русские силачи») | Почему гиря — зрелище |
| **Федерации** | WKSF, IUKL — официальные Regulations (соревновательная гиря) | Стандарт снаряда, дисциплины |
| **Журналы** | «Гиревой спорт» (архив), материалы федераций РФ | Нормативы, соревнования 1960–2000-х |

## Книги и монографии (ориентир для редакторов)

Имеет смысл **выписать 1–2 факта с страниц** и указать в поле `author` / `work` в JSON (как в классике Gdepar):

- Общие курсы: *История физической культуры и спорта* (разные авторы, вузовские учебники).
- Специализированная пресса СССР/РФ по тяжёлой атлетике и гиревому спорту (разделы в сборниках).
- На английском (для сверки): исторические обзоры strongman / kettlebell sport в спортивной науке.

> Агент **не подставляет** цитаты из книг автоматически — только заранее проверенные абзацы в `stern_rubrics.json`.

## Как добавить новый выпуск

1. Прочитать источник, выписать **один абзац-факт** (не лозунг).
2. Добавить в `entries` объект с полями: `id`, `period`, `quote`, `author`, `work`, `source`, `note`, `tag`, `image_file`.
3. `note` — пояснение для читателя («что это значит сегодня»), без пустых фраз.
4. Проверить длину: `rubric_posts.MIN_CURATED_BODY_CHARS` (≥260 символов в теле).
5. Картинка: Wikimedia Commons → `image_file`, прогон `scripts/prefetch_stern_rubric_images.py`.
