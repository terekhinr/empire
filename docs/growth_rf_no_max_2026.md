## 2. Приоритет спутников (порядок внимания)

1. **Сад** — ВК + Дзен (7 подписчиков → срочно)  
2. **Гдепар** — карта + отзывы + ВК/Дзен с UTM  
3. **Штерн** — ВК клипы + рубрики TG; видео-уроки  
4. **Ленин** — после согласования тона ВК/Дзен  
5. **Пенсия** — не переставлять с TG; усилить Дзен/сайт по желанию

## 5. По каналам — три рычага

### Сад (Степаныч)

- ВК: сообщество, закреп, tripwire PDF, 2–3 поста/нед  
- Дзен: «7 ошибок», сезонные чек-листы → ссылка на ВК  
- TG: автослоты Empire; в постах не «только в TG»  
- Матрица: `garden_posting_matrix_2026.md`

### Гдепар (Михалыч)

- ВК: не только байки — **карта gdepar.ru**  
- Дзен: «как выбрать баню», UTM на карту  
- TG: классика 15:00, промо карты; Obsidian вариант A — свои тексты  
- Сайт: отзывы, саммари (уже на VPS)

### Штерн

- ВК: 1 упражнение/нед + клип  
- Дзен: поясница, офис, гири  
- TG: рубрики 09:00 с фото  
- Продукт: 3 урока → tripwire (после съёмки)

### Ленин

- ВК/Дзен: спокойный тон, календарь, цитаты  
- TG: ядро, донаты  
- Без уличных призывов в заголовках  

### Пенсия

- **TG — главный**  
- Дзen + neverretire.ru  
- ВК — по желанию  
- Не гнать в ту же воронку, что Сад
