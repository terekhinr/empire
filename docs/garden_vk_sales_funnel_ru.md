# П.3 — Полный гайд: Garden · ВК → tripwire 290 ₽ → гайд 1290 ₽

Пошаговый план на **день оформления сообщества** и первые **2–4 недели** продаж без опоры на Telegram (VPN).

**Материалы в репозитории:**

| Файл | Назначение |
|------|------------|
| `data/garden_deliverables/pdf/garden_tripwire_preview_3_errors.pdf` | **Бесплатно** во ВК (3 ошибки) |
| `data/garden_deliverables/pdf/garden_tripwire_checklist.pdf` | Платный tripwire **290 ₽** |
| `data/garden_deliverables/pdf/garden_guide_4weeks.pdf` | Upsell **1290 ₽** |
| `data/garden_vk_copy.json` | Готовые тексты — копировать в ВК |
| `docs/garden_positioning.md` | УТП, запреты формулировок |

**Оплата:** пока ЮKassa в боте не подключена — **фаза A (ручная)**; после [гайда ЮKassa](infoproduct_yookassa_npd_setup_ru.md) — **фаза B (ссылка на оплату)**.

## Карта воронки

```text
Дзен / репосты / знакомые
        ↓
ВК-сообщество «Степаныч · природный огород»
        ↓
Закреп: превью PDF (3 ошибки) бесплатно
        ↓
Посты 2–3/нед (сезон, средняя полоса)
        ↓
Сообщения сообщества: «ЧЕКЛИСТ» → 290 ₽ → полный PDF
        ↓
В PDF и в ответе: upsell «4 недели» 1290 ₽
        ↓
(опционально) TG-бот для тех, у кого VPN
```

## День 1 — оформление ВК (чеклист на завтра)

Все тексты для копипаста: **`data/garden_vk_copy.json`**.

### Утро (30–45 мин) — создать сообщество

1. [vk.com/groups](https://vk.com/groups) → **Создать сообщество** → **Публичная страница** (не закрытая группа — проще растить).  
2. **Название:** `Степаныч · природный огород` (или короче, если лимит).  
3. **Короткий адрес:** `vk.com/stepanych_garden` (проверьте свободен).  
4. **Тематика:** садоводство / дача.  
5. **Аватар:** 500×500, узнаваемый символ (грядка, лопата, зелёный фон) — без мелкого текста.  
6. **Обложка:** 1920×768, слоган: *«7 ошибок грядки — не 100 советов»*.  
7. **Описание** — из `garden_vk_copy.json` → `community.description`.  
8. **Контакты:** ссылка на Дзен (когда будет) или «материалы в документах сообщества».

### День (45 мин) — документы и закреп

1. **Управление** → **Документы** → загрузить:  
   - `garden_tripwire_preview_3_errors.pdf` (превью)  
   - позже — полный чек-лист только **после оплаты** (не выкладывать в открытый доступ).  
2. **Закрепить пост** — текст из `garden_vk_copy.json` → `pin_post`.  
3. В закрепе: кнопка/ссылка «Скачать превью (3 ошибки)» → документ ВК.  
4. **Меню сообщества** (если доступно): «Превью PDF» | «Купить чек-лист» | «О Степаныче».

### Вечер (30 мин) — первый контент

1. Перенести **5–10 постов** из TG-канала (лучшие по сезону) — сократить до 800–1200 знаков.  
2. Пригласить **30–50 знакомых** подписаться (личное сообщение, не спам в чужих группах).  
3. Записать в блокнот: **URL сообщества**, число подписчиков «день 0».

**Цель дня 1:** сообщество выглядит живым, закреп с превью, ≥20 подписчиков.

## Фаза A — продажи вручную (до ЮKassa в боте)

### Триггер покупки

Пользователь пишет в **сообщения сообщества** (не в комментарии к посту):

| Слово | Продукт | Цена |
|-------|---------|------|
| `ЧЕКЛИСТ` | Полный PDF 7 ошибок | 290 ₽ |
| `ГАЙД` или `4НЕДЕЛИ` | Гайд 4 недели | 1290 ₽ |

Автоответ-заготовка в `garden_vk_copy.json` → `auto_replies`.

### Сценарий tripwire (290 ₽)

1. **Ответ в течение 2–4 часов** (можно быстрее):  
   - что внутри (7 ошибок, тест 60 сек, средняя полоса);  
   - цена **290 ₽**;  
   - способ оплаты (см. ниже).  
2. После подтверждения оплаты — **файл** `garden_tripwire_checklist.pdf` в ЛС.  
3. Текст upsell (из JSON → `upsell_after_tripwire`).  
4. Запись в таблицу (Google Sheet / блокнот):

| Дата | VK id / имя | Продукт | ₽ | source | Чек НПД |
|------|-------------|---------|---|--------|---------|
| | | tripwire | 290 | vk_pin | ☐ |

### Способы оплаты в фазе A

| Способ | Плюс | Минус |
|--------|------|-------|
| **Счёт ЮKassa** (ссылка из личного кабинета «выставить счёт») | Чек НПД автоматом | Каждый раз вручную |
| **Перевод СБП** на карту | Быстро | Чек **вручную** в «Мой налог» |
| VK Donut | Удобно подписчикам | Комиссия, не для разовых PDF |

**Рекомендация:** как только магазин ЮKassa одобрен — выставлять **ссылку на оплату 290 ₽** из кабинета, не голый перевод.

### Сценарий upsell (1290 ₽)

Только **после** tripwire (или тёплым лидам с Дзена):

1. «В чек-листе в конце — таблица, с какой недели начать гайд».  
2. Гайд = 4 недели × 3 дела, не 40 видео.  
3. Цена **1290 ₽**, тот же способ оплаты.  
4. Файл: `garden_guide_4weeks.pdf`.

### Что не обещать

- суперурожай за 3 дня;  
- гарантированный урожай;  
- «единственно верный способ»;  
- привязку к бренду удобрений.

См. `docs/garden_positioning.md`.

## Фаза B — после подключения ЮKassa

1. Пройти [гайд НПД + VPS](infoproduct_yookassa_npd_setup_ru.md).  
2. В сообщениях ВК давать **одну ссылку на оплату** (из бота или `pay.neverretire.ru`, когда API готов).  
3. `payments_enabled: true` в `data/garden_products.json`.  
4. Превью PDF остаётся бесплатным в документах; полный — только после webhook.

**TG-бот** (`empire_garden_bot`): вторичный канал — ссылка в закрепе канала «есть VPN».
