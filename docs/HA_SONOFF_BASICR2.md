# Sonoff BASICR2 → Home Assistant (eWeLink, без перешивки)

**Быстрый старт:** [`HA_SONOFF_NOW.md`](HA_SONOFF_NOW.md) — пошагово «сделать сейчас».

Модель: **SONOFF DIY BASICR2** (Wi‑Fi, 10 A), у вас **2 шт.**  
HA: Supervised/Docker на armbian (`192.168.1.41:8123`, Tailscale `100.80.133.85`).

> **Важно:** у BASICR2 **нет** официального **DIY mode** (он у BASICR3+). «LAN mode» в бытовом смысле здесь — интеграция **[SonoffLAN](https://github.com/AlexxIT/SonoffLAN)** (HACS): режим **`auto`** — сначала локальная сеть, при сбое облако eWeLink. Полностью без облака на BASICR2 **не гарантируется**; для 100% локально — **Tasmota** (отдельный гайд).

**Не путать:** Zigbee **донгл** Sonoff (ZHA) и Wi‑Fi **реле** BASICR2 — разные устройства. **Tuya** — отдельно (**LocalTuya**), не этот гайд.

| | |
|---|---|

| Роутер | Закрепить **постоянный IP** реле для каждого BASICR2 |

## Часть 1. Подключение реле к Wi‑Fi (eWeLink)

### 1.1 Установка в щит / подрозетник

- **L in** — фаза с сети  
- **N in** — нейтраль (если есть в коробке; без нейтрали реле может не работать стабильно)  
- **L out** — на нагрузку (свет)  
- **N out** — нейтраль на нагрузку (если схема требует)

⚠️ **220 V** — при сомнениях электрик.

### 1.2 Пейринг в eWeLink

1. Подать питание на реле.  
2. **Удерживать кнопку Reset** ~5 с, пока LED не начнёт **быстро мигать** (режим настройки).  
3. Телефон → Wi‑Fi **2.4 GHz**.  
4. **eWeLink** → **+** → **Быстрое подключение** (или совместимый режим).  
5. Ввести пароль Wi‑Fi → дождаться «Успешно».  
6. Задать имя, например: `Свет гостиная` / `Sonoff BASICR2 коридор`.

### 1.3 Проверка

- В eWeLink переключатель **вкл/выкл** — свет реагирует.  
- Запомнить имя устройства — оно подтянется в HA.

### 1.4 Постоянный IP (рекомендуется)

В роутере: **DHCP reservation** по MAC реле (в eWeLink: настройки устройства → MAC, если есть).

## Часть 2. Интеграция SonoffLAN в Home Assistant

Официальное имя в HA: **Sonoff** (репозиторий AlexxIT **SonoffLAN**).

### 2.1 Установка через HACS

1. **HACS** → **Интеграции** → **⋮** → **Пользовательские репозитории**.  
2. URL: `https://github.com/AlexxIT/SonoffLAN`  
3. Категория: **Интеграция** → **Добавить**.  
4. **HACS** → **SonoffLAN** → **Установить**.  
5. **Перезагрузить Home Assistant** (полная).

### 2.2 Добавить интеграцию

1. **Настройки** → **Устройства и службы** → **Добавить интеграцию**.  
2. Найти **Sonoff** (не путать с ZHA Sonoff dongle).  
3. Войти **логином и паролем eWeLink** (тот же, что в приложении).  
4. Регион: **+7 / Russia** или как в приложении при регистрации.  
5. Режим (**Mode**): оставить **`auto`** ← рекомендуется автором интеграции.  
   - **`local`** только LAN — на BASICR2 часто **нестабильно** или устройство не появится.  
   - **`cloud`** — только облако (работает, но не «только локально»).

### 2.3 Если устройство не появилось

1. В eWeLink реле **онлайн**.  
2. HA и реле в **одной подсети** `192.168.1.x`.  
3. **Перезагрузка** интеграции Sonoff: Настройки → Sonoff → **Перезагрузить**.  
4. **Журнал** HA: фильтр `sonoff`.  
5. **Настройки** → **Система** → **Сеть** — правильный интерфейс (не VPN/Tailscale для LAN).

#### Supervised / Docker (ваш случай)

Локальное обнаружение идёт через **mDNS (Multicast)**. Должно работать в сети hassio; если реле **unavailable** после каждого рестарта HA — см. [Common problems](https://github.com/AlexxIT/SonoffLAN#common-problems-in-only-lan-mode): один роутер, без изоляции Wi‑Fi «гостей», не NAT-only VM.

### 2.4 Настройка в HA

1. **Настройки** → **Устройства** → найти `Sonoff BASICR2` / ваше имя.  
2. **Область** — комната (Кухня, Коридор…).  
3. Переименовать сущность, например: `switch.koridor_svet`.  
4. (Опционально) В опциях Sonoff включить **Debug** — если нужна диагностика.

### 2.5 Проверка «локально ли»

1. Включить/выключить из HA — работает.  
2. В сущностях устройства посмотреть сенсор связи (если включён в опциях) — **local** vs **cloud**.  
3. Тест: **выключить интернет на роутере** (не Wi‑Fi между HA и реле) на 1–2 мин → переключить из HA.  
   - Работает → LAN ок.  
   - Нет → фактически облако; для автономии — **Tasmota** (часть 4).

## Часть 4. Если нужно строго «без облака»

| Вариант | Сложность | Локально 100% |
|---------|-----------|----------------|
| SonoffLAN `auto` | Низкая | Не гарантия на BASICR2 |
| SonoffLAN `cloud` | Низкая | Нет |
| **Tasmota** (прошивка USB) | Средняя | Да |
| Замена на **Zigbee** (ZBMINI) | Замена железа | Да (ZHA) |

BASICR2 на **ESP8266** — Tasmota: [инструкции Tasmota Sonoff Basic](https://tasmota.github.io/docs/devices/Sonoff-Basic/). После прошивки — интеграция **MQTT** или **Tasmota** в HA, eWeLink не нужен.
