Ключевые тезисы аудита (согласие):

1. Setup 45k + банк 90k — это **агентская услуга**, ценность в контенте, не в софте.

## 0. Аудит собственных размышлений и «тестов»

### 0.1. Что было сделано по факту

| Шаг | Тип | Качество доказательства |
|-----|-----|-------------------------|
| Обзор кода Empire (Studio, curated, auto_publish) | Инвентаризация репо | **Сильно** — опирается на файлы |
| Обзоры рынка автопостинга (Buffer/SocialBee/SMMplanner) | Desk research 2025–26 | **Средне** — вторичные обзоры, не первичные интервью |
| Цифры Buffer ARR / SocialBee customers | Публичные апдейты / оценки | **Средне+** для Buffer; SocialBee — оценки |
| ТЗ + финмодель автопоста | Синтез | **Гипотеза** — не валидирована платежами |
| Custdev / лендинг / предоплаты | — | **Не сделано** |
| A/B или пилот внешнего клиента | — | **Не сделано** |
| Автотесты продукта «на продажу» | Есть `tests/test_publisher.py` на внутренний Studio | **Не покрывает** tenant/банков/контракт картинки P0 |

**Итог:** документ pitch — это **обоснованная гипотеза на базе кода + рынка**, не доказанный бизнес-кейс. Самая слабая часть — спрос и Willingness-to-Pay без разговоров с покупателями.

### 0.2. Где рассуждения были сильными

1. Разделение **планировщик** vs **банк+ротация** (SocialBee) — корректная рамка.  
2. Отказ от войны с SMMplanner по цене 990 ₽ — здраво.  
3. Сервис Setup+Банк до SaaS — снижает риск.  
4. CAPEX низкий, потому что Studio уже есть — правда.  
5. Жёсткий контракт «текст+картинка» закрывает реальную боль Empire.

### 0.3. Где рассуждения слабые / дыры

| Риск | Почему опасно |
|------|----------------|
| **Спрос на «банк 90 дней» не доказан** | Клиент может хотеть только «кнопку отложить пост», а банк — наша фантазия о ценности |
| **ARPU 70k Setup завышен без кейсов** | На рынке Setup ботов часто 15–50k; автопост-услуга может оказаться 15–30k |
| **Часы P0 90–130 оптимистичны** | Мультиtenant + биллинг + саппорт обычно раздуваются ×1.5–2 |
| **Opportunity cost vs книга/CPA** | В `05_FINANCIAL_MODEL.md` автопост уже «не строка P&L», а экономия времени — продажа продукта может **отнять** фокус у денег Empire |
| **«Без ИИ» как USP** | Рынок наоборот клеит AI на лендинги; USP может не резонировать в рекламе, только в retention |
| **Смешение Studio и curated engine** | Для клиента это один продукт; в коде два контура — интеграция недооценена в часах |
| **Сравнение с SocialBee** | SocialBee = Instagram/FB/LinkedIn; наш TG-медиа кейс другой покупатель |
| **Нет теста «продай Setup на текущем Studio»** | Самый дешёвый эксперимент ещё не запущен — нельзя утверждать GO на код |

### 0.4. Что выдавалось за «тесты», но тестами не было

- Прогон мысленных сценариев и чтение доков ≠ product test.  
- `pytest tests/test_publisher.py` ≠ готовность к внешнему клиенту.  
- Обзоры «топ сервисов 2026» содержат партнёрский/рекламный шум и разъезжающиеся цены.

### 0.5. Исправленная уверенность (калибровка)

| Утверждение из pitch | Было | Стало |
|----------------------|------|-------|
| Сервисная модель удачнее SaaS на старте | Высокая | **Высокая** (держим) |
| Рынок платит за evergreen-банк | Средняя | **Низкая–средняя** до custdev |
| 1 клиент окупает cash CAPEX | Высокая | **Средняя** (если чек ≥40k) |
| P0 за 5–6 недель фокуса | Средняя | **Низкая–средняя** (заложить 8–12) |
| Стоит разрабатывать P0 сейчас | Условный GO | **Сначала продажа услуги / 5 custdev**, код — после депозита |

## 1. Конструкторы ботов для Telegram — что да как

### 1.1. Карта игроков (RU-фокус, 2026)

| Класс | Примеры | Цена-ориентир | Что покупают |
|-------|---------|---------------|--------------|
| **Простой TG-only / free** | Manybot, часть PuzzleBot free | 0 | Меню, рассылка, «бот за вечер»; устаревание Manybot |
| **Маркетинг / автоворонки** | BotHelp, Senler (VK-сильнее) | от ~1.3–2.5k ₽/мес | Подписчики, рассылки, воронки |
| **Сложные сценарии + CRM** | Salebot | free → ~3–4k ₽/мес + пакеты сообщений | Воронки, оплата в боте, TG+WA+VK+Авито |
| **Визуальный no-code «любой мессенджер»** | Botmother | ~$49+/мес класс | Один сценарий → много каналов |
| **NLU / голос / enterprise** | Aimylogic | от ~6–15k ₽/мес | Интенты, голос, крупный бизнес |
| **AI-агенты / code-first** | Botpress и аналоги | pay-as-you-go / дороже | IT-команды, не массовый RU SMB |
| **Узкий monetize TG** | InviteMember, TeleCrow и др. | $4–30+/мес | Платный доступ к каналу/цифровые товары |

Сигналы выручки (оценки/Latka, ориентир, не бухгалтерия): Botmother порядка **~$0.9M** ARR при маленькой команде; Botpress **~$4M** — другой сегмент. RU Salebot/BotHelp — живые массовые продукты с партнёрками агентствам (у BotHelp до ~35% от оплат привлечённых).

### 1.2. Модели монетизации, которые работают

1. **Подписка SaaS** по подписчикам / сообщениям / ботам.  
2. **Агентство на чужом конструкторе** (настройка под ключ 30–150k + % или retainer) — часто выгоднее, чем свой SaaS.  
3. **Партнёрка** Salebot/BotHelp — продаёшь чужой продукт, берёшь комиссию.  
4. **Шаблоны ниш** (запись, оплата курса, квиз, поддержка) — допродажа.  
5. **AI-слой поверх** (GPT в диалоге) — апселл 2025–26, но саппорт и качество диалога жрут маржу.

### 1.3. Спрос: есть ли он?

**Да, спрос на ботов высокий.** Но спрос на **ещё один конструктор** — низкий для новичка:

| Покупатель хочет | Уже закрыто кем |
|------------------|-----------------|
| Бот-меню / рассылка | Manybot, PuzzleBot, BotHelp |
| Воронка + оплата + CRM | Salebot |
| Агентство «сделайте нам бота» | Фриланс/агентства на Salebot/BotHelp |
| Платный канал | InviteMember и аналоги |
| Сложный кастом | Разработка на aiogram/Botpress |

**Вывод:** рынок **насыщен снизу и в середине**. Вход «напишем свою среду изготовления ботов с разным функционалом» = конкуренция с командами, у которых годы интеграций (платежи, WA Business, VK, лимиты TG API, антиспам, поддержка 24/7).

### 1.4. Где ещё есть узкие клинья (если очень хочется ботов)

| Клин | Почему может взлететь | Почему может умереть |
|------|----------------------|----------------------|
| **Нишевый бот-под-ключ** (бани, салоны, школа) на Salebot + ваш шаблон | Спрос на результат, не на конструктор; низкий CAPEX | Масштаб через ваши руки |
| **Модуль «автопост + бот-лид»** в одном кабинете для медиа | Связка контент→бот→лид редка как продукт | Всё равно интеграции |
| **Self-hosted / white-label для агентств** | Кто боится SaaS-зависимости | Долгая разработка, мало кто платит до продукта |
| **Свой no-code конструктор с нуля** | — | **NO-GO** для соло на 12 мес |

### 1.5. Оценка: смотреть ли в эту сторону?

| Вариант | Вердикт | Почему |
|---------|---------|--------|
| **A. Свой конструктор/IDE ботов** | **NO-GO** | Рынок занят; 6–18 мес до жалкого MVP; саппорт убьёт |
| **B. Услуга «бот под ключ» на Salebot/BotHelp** | **GO слабый / опционально** | Деньги быстрее автопост-SaaS; но это агентский ремесленный труд |
| **C. Партнёрка конструкторов** | **GO микро** | Почти 0 разработки; учит спросу |
| **D. Свой бот только для Empire (gdepar «Пар?», CPA)** | **Уже в стратегии** | Не продукт на продажу; см. voice_bot — не раньше CPA |
| **E. Автопост-услуга (предыдущий pitch)** | **Условный GO** | Меньше конкурентов именно на «банк 90 дней без ИИ»; база кода есть |

**Сравнение с автопостом:** конструктор ботов — **хуже** как product bet (капиталоёмко, конкуренция). Услуга настройки ботов — **сопоставима** с Setup автопоста как способ проверить спрос на «сделайте мне автоматизацию в TG», но **не требует** писать среду.

## 2. Финмодель: конструкторы / бот-направление

### 2.1. Сценарий A — свой конструктор (не рекомендуется)

| | Пессимизм | База | Оптимизм |
|--|-----------|------|----------|
| Срок до MVP | 9 мес | 12 мес | 18 мес |
| Часы | 800+ | 1200+ | 2000+ |
| Cash CAPEX | 150k+ | 300k+ | 500k+ |
| Платящие к M12 | 20 | 80 | 300 |
| ARPU | 1.5k | 2.5k | 4k |
| Выручка M12 run-rate | 30k/мес | 200k/мес | 1.2M/мес |
| Вероятность базы для соло | **<10%** | | |

**Внутренняя цена:** миллионы ₽ opportunity cost. **NO-GO.**

### 2.2. Сценарий B — боты под ключ на чужом конструкторе

| | Пессимизм | База | Оптимизм |
|--|-----------|------|----------|
| Проектов/год | 4 | 10 | 20 |
| Средний чек Setup | 25k | 45k | 70k |
| Retainer (доля клиентов) | 1×8k×6м | 4×10k×8м | 8×12k×9м |
| Выручка год | ~120k | **~650k** | ~1.6M |
| COGS (Salebot и т.п.) | низкий | | |
| Часы на проект | 15–40 | | |
| Конфликт с Empire | Средний (время) | | |

Похоже на финмодель автопост-услуги, но **без** преимущества «свой уникальный движок банка». Конкурируете с тысячами фрилансеров Kwork/TG.

### 2.3. Сценарий C — гибрид «медиа-автопост + простой lead-бот» (единственный разумный product-клин)

Не конструктор. Коробка для владельца канала:

1. Автопост по матрице (ваш Studio).  
2. Бот: `/start` → 2–3 кнопки → заявка/оплата/ссылка (шаблон на aiogram или даже Salebot white под клиентом).  

| | База |
|--|------|
| Чек пакета | 60–100k (контент-банк + бот-лид) |
| Клиентов/год | 6–10 |
| Выручка | **0.5–1.0M** |
| Доп. код | 40–80 ч (шаблон бота), не среда |
| Спрос | выше, чем «ещё один Salebot» |

### 2.4. Сводка GO/NO-GO ботов

| Ставка | Решение |
|--------|---------|
| Среда/программа для изготовления ботов с разным функционалом | **NO-GO** |
| Массовый SaaS-конструктор | **NO-GO** |
| Услуга ботов на Salebot | **OPTIONAL** (если легко идут заявки; не строить империю) |
| Шаблон lead-бота как add-on к автопост-пакету | **CONDITIONAL GO** после первой продажи автопоста |
| Голосовой/сложный бот для gdepar | **Отложить** по текущему Empire-плану |

## 3. Итоговая рекомендация (автопост vs боты)

1. **Не пилить конструктор ботов.** Рынок доказал спрос на *ботов*, не на *ваш конструктор*.  
2. **Автопост-услуга** остаётся лучшей product-ставкой из двух обсуждаемых — но только после custdev/предоплаты (см. аудит §0).  
3. Отнести промпт §0.6 в Gemini; сверить вердикт.  
4. В понедельник: 5 сообщений владельцам TG/агентствам с оффером Setup 29/49/79k **или** «бот-воронка 35k на Salebot» — что ответят быстрее, то и рынок.  
5. Код P0 автопоста и тем более IDE ботов — **после** сигналов оплаты.
