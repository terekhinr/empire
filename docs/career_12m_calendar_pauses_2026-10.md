## 2. Протокол паузы

### 2.1. Бюджет (на 12 мес ленты)

- До **2** PAUSE по **≤4 недели**. Суммарно ≤ **8 недель**.  
- Третья → сдвиг D-day и всех открытых КТ на длину паузы.

### 2.2. За 7 дней до PAUSE

1. Коммит/пуш; в README или `NOTES.md` песочницы — «на чём остановился».  
2. Журнал §5 + статус месяца `PAUSE`.  
3. Пакет: Stepik неделя, 2–3 главы/сценария, Anki/EN.  
4. Запрет: деплой, Flint/VPN, 4K, локальные LLM, **правка файлов на прод-VPS**.  
5. Weekly review: дата старта PAUSE.

### 2.3. Сдвиг КТ

Незакрытые КТ и D-day: `+ число дней PAUSE`. Закрытые не трогать. Нельзя догонять двойной нагрузкой.

### 2.4. Неделя в PAUSE

| Блок | ч/нед |
|---|---:|
| B2B учёба (Stepik и т.п.) | 8–9 |
| Английский | 3 |
| Текст Пенсия / сценарии | 2–3 |
| Где Пар / инфра | 0–1 (мониторинг) |

### 2.5. Выход

RECOVERY 1 нед → обновить §4–§5 → пересчитать КТ → HOME.

Черновой **D-day = 2027-10-22**. При уходе в 2028 — сдвинуть КТ пропорционально; **песочницу не сжимать &lt; 3 мес**.

| **КТ-0** | старт | 2026-10-22 | Режим 20–24 ч; Метрика *или* блокер владельца записан |
