## Анатомия ролика Мячина (по PDF)

1. **Заголовок-вопрос** — парадокс («дефицит кадров, а работы нет»).
2. **Крючок 0:00–1:30** — цитата чиновника / цифра / «все так говорят».
3. **Парадокс с источником** — HH 10:1, ЦБ 25%, и т.д. (в кадре: «источник» на экране).
4. **Представление** — «Меня зовут…» (у вас: **Иосиф Борода** / бренд канала).
5. **Механизм 5–15 мин** — 3–5 причин списком; цитаты; без воды.
6. **Развенчание мифа** — «виноваты зумеры?» → нет, структура.
7. **Вывод для зрителя** — 1–3 действия (не ИИР): компетенция, кэшфлоу, не FIRE.
8. **CTA** — подписка, **neverretire.ru/book**, Boosty-аналог при появлении.
9. **Дисклеймер** — не индивидуальная инвестиционная рекомендация.

**Длина речи:** ~4 000–6 000 слов ≈ 18–25 мин при ~160 сл/мин.
