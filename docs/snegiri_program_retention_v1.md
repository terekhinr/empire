# Снегири · программа v2 · удержание и расширение гиревого блока

**Проблема (честно):** текущий трек K = **3 упражнения × ~14 дней** → пользователь «выучил свинг/рывок/толчок» → **отписка на 2–3 месяце**. Финмодель с churn 8% и LTV 6–9 мес **не сходится** с таким каталогом. Нужен **конвейер на 6–12+ месяцев**.

**Ориентиры по содержанию:** программы **Виктора Блуда** (вводный + 4-недельный цикл: hinge, goblet, swing, get-up, press), **функциональный гиревой фитнес** (Каширин / streetfit: круговые, связки, мобility), классика **StrongFirst / RKC** (TGU, clean, press, snatch progression).

---

## 1. Диагноз: почему финмодель «херовая»

| Допущение Gemini | Реальность при 3 движениях |
|------------------|---------------------------|
| Churn 8%/мес | **12–15%** с месяца 3 (контент кончился) |
| LTV 6–9 мес | **3–4 мес** фактически |
| ARPU 480 ₽ | то же |
| **LTV ₽** | 480×4 = **1 920 ₽** vs модель **2 880–4 320 ₽** |
| CAC тренера ~0 | OK |
| CAC платный 1200–1800 ₽ | **убыток** |

**Вывод:** продукт = **не разовый курс**, а **еженедельный контроль техники + бесконечная лестница навыков**. Подписка продаёт **привычку и прогрессию**, не «выучи 3 упражнения».

---

## 2. Архитектура v2: три слоя

```
Слой 1 · CORE (всегда)     — McGill Big 3 + 1–2 «служебных» (carry, hinge drill)
Слой 2 · SKILL LADDER (K)  — 12+ недель новых паттернов, разблокировка по CV
Слой 3 · SEASON (каждые 4 нед) — блок: «Заброс», «Турлиш», «Комplex», «Плотность»
```

### 2.1. Лестница гиревых навыков (16 паттернов, 24+ недели)

| Фаза | Нед | Упражнения | CV | Зачем |
|------|-----|------------|-----|-------|
| **K0** | 1–2 | Hip hinge, dead stop, goblet squat, farmer carry | частично | база до маха |
| **K1** | 3–4 | Двуручный свинг | ✅ | первая баллистика |
| **K2** | 5–6 | Одноручный свинг, hand-to-hand | ✅ | асимметрия |
| **K3** | 7–8 | **Заброс (clean)** в стойку, rack hold | ✅ | связка свинг→press |
| **K4** | 9–10 | Жим из стойки, push press | ✅ | сила над головой |
| **K5** | 11–12 | **Турлиш (TGU)** по сегментам → полный | ✅ | мобility + стабилизация |
| **K6** | 13–14 | Рывок (snatch) | ✅ | соревновательная база |
| **K7** | 15–16 | Толчок / длинный цикл (ввод) | ✅ | продвинутый |
| **K8+** | 17+ | **Комplex** (clean+press+ squat), windmill, halo, bent press lite | частично | **не кончается** |

**Разблокировка:** следующая фаза открывается, когда **средняя оценка CV ≥7** за 2 недели по ключевому упражнению фазы (не календарём только).

### 2.2. Что добавить в McGill (трек S) — не только 3 статики

| ID | Упражнение | Зачем |
|----|------------|-------|
| S4 | Suitcase carry / farmer walk | перенос в гирю |
| S5 | McGill curl-up **вариации** | прогрессия |
| S6 | Side plank **ноги** / star | сложнее |
| S7 | Dead bug / anti-rotation band | ротация |

Трек S: **8 нед** минимум → **12 нед** полный → дальше **S+ maintenance** 1–2 раза/нед (не бросаем).

### 2.3. Механики удержания (не только новые упражнения)

| Механика | Как |
|----------|-----|
| **Еженедельный план LLM** | новые связки, объём, акцент — не тот же день 28 раз |
| **Сезон 4 нед** | тема: «Заброс», «Турлиш», «10 мин EMOM», «−20% deload» |
| **Skill of the month** | один навык в фокусе + челлендж |
| **Streak + регресс** | 7 дней без тренировки → −ступень; 30 дней streak → badge |
| **Вес гири / второй вес** | прогрессия 8→12→16→20→24 кг |
| **Дневник** | вес тела, талия, объём, **график техники** |
| **Новый разбор = новый угол** | даже тот же свинг — другая ошибка на другой неделе |
| **K+ после K8** | бесконечные **вариации** (комplexes, timed sets, «программа от Штерна») |

## 3. Сравнение с «3 упражнениями»

| | Было | v2 |
|--|------|-----|
| Уникальных паттернов K | 3 | **16+** |
| Недель активного K | 14 | **24+**, потом K+ |
| Причина остаться мес 6 | слабая | сезоны + новый навык + график |
| CV эталонов для съёмки | 18 | **~55–70** клипов (фазы) |
| Churn (цель) | 8% | **5–6%** |

---

## 4. Пересчёт юнит-экономики (упрощённо)

**Было (тонкий каталог):** LTV ≈ 480 × (1/0.12) ≈ **4 000 ₽** gross, маржа ~290 → **~2 400 ₽** — еле окупает RevShare.

**Стало (v2, churn 6%):** LTV ≈ 480 × (1/0.06) ≈ **8 000 ₽** gross → **~4 600 ₽** маржи — **×1.9** к удержанию.

**Стало (v2 + годовой тариф 40% mix):** ARPU **~550 ₽**, churn **4%** → LTV **~13 750 ₽** — финмодель Gemini начинает **сходиться**.

## 5. MVP vs полный каталог CV

| Этап | Упражнения с CV | Без CV (видео-инструкция только) |
|------|-----------------|----------------------------------|
| MVP релиз | S1–S3, K1 swing, K3 clean, K5 TGU partial | goblet, carry, halo, complex |
| +3 мес | + snatch, jerk, press | windmill, bent press |
| +6 мес | все K0–K8 ключевые | flows |

**Не ждать 70 клипов для старта** — но **программу в приложении** показывать полную, CV включать по мере готовности (fallback: «сними видео — разбор базовый»).
