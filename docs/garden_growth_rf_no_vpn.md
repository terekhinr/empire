# Garden: рост аудитории без опоры на Telegram (РФ, 2026)

**Контекст:** в РФ Telegram для большинства аудитории доступен **только через VPN**.  
**Следствие:** TG не может быть главным каналом привлечения. Домом становятся **ВК + Дзен + MAX**; TG — опционально для «продвинутых» и внутренней автоматизации Empire.

Связано: `docs/garden_positioning.md`, `empire_publish.py` (каналы `vk_wall`, `dzen_rss`, `max`).

---

## 1. Роли площадок

| Площадка | Роль | VPN | Приоритет для Garden |
|----------|------|-----|----------------------|
| **Дзен** | Длинные статьи, поиск, холодный трафик | нет | **№1 привлечение** |
| **ВК** | Сообщество, клипы, обсуждения, лид-магнит | нет | **№1 удержание + прогрев** |
| **MAX** | Короткие рассылки, подписчики мессенджера | нет | **№2** (когда подключён адаптер) |
| **Telegram** | Автопост Empire, бот (если есть VPN) | да | **вспомогательный** |
| **YouTube Shorts** | Опционально, если есть ресурс | нет | **№3** |

**Цель «1000»** пересчитываем:

- не «1000 в TG»;
- **~500 подписчиков ВК** + **~300 подписчиков Дзен** + **~200 в MAX** (или один якорь 800 ВК + 200 Дзен — как пойдёт).

---

## 2. Воронка (новая)

```
Дзен (статья «7 ошибок» / сезонный совет)
    ↓ ссылка в конце
ВК-сообщество «Степаныч · огород»
    ↓ закреп, обсуждения
Лид: PDF-превью / заявка / VK Donut позже
    ↓
Продажа: VK + ЮKassa / файл в ЛС сообщества
```

**Telegram** — в конце цепочки: «есть VPN — дублируем там же» (не требуем для доступа к контенту).

---

## 3. Контент-машина (один источник → много площадок)

Уже есть в Empire:

- генерация постов `garden` в `main.py`;
- **`dzen_rss`** — `rss_maker.py` → RSS для Дзен;
- **`vk_wall`, `max`** — заглушки в `empire_publish.py` (нужны токены и доработка).

### Рабочий цикл (ручной + полуавто)

| Шаг | Действие |
|-----|----------|
| 1 | Пост рождается в Empire (как сейчас) |
| 2 | **Дзен:** раз в 2–3 дня расширить лучший пост до статьи 1500–2500 зн., опубликовать, в конце — ссылка на ВК |
| 3 | **ВК:** тот же текст сократить до 800–1200 зн. + 1 фото; 2–3 поста в неделю |
| 4 | **Клип ВК:** 3 тезиса из поста, 30–45 сек, субтитры |
| 5 | **MAX:** одна строка + ссылка на пост ВК (когда адаптер готов) |
| 6 | **TG:** автопост без ссылки «только у нас в TG» |

## 4. План роста по фазам (реалистично)

### Фаза 0 (2 недели) — «дом в ВК + первая статья Дзен»

- [ ] Создать **сообщество ВК** (не личная страница): название «Степаныч · природный огород»  
- [ ] Аватар, обложка, описание (УТП из `garden_positioning.md`)  
- [ ] Закреп: кто такой Степаныч + **ссылка на статью Дзен** или PDF на диске ВК  
- [ ] Перенести **10–15 лучших постов** из TG-ленты (если есть) в ВК вручную  
- [ ] **1 статья Дзен** из tripwire: «7 ошибок грядки» (сокращённая версия + «полный PDF в ВК»)  
- [ ] Пригласить 30–50 знакомых **подписаться на ВК**, не на TG  

**Цель:** 40–80 подписчиков ВК, 20–50 подписчиков Дзен.

### Фаза 1 (1–2 мес) — органика

| Канал | Действие | Ожидание |
|-------|----------|----------|
| Дзен | 2 статьи/нед, SEO-заголовки, средняя полоса | +30–80 подписок Дзен/мес |
| ВК | 3 поста + 1 клип/нед, комментарии в группах дачников | +50–120 ВК/мес |
| Коллабы | Обмен с микросообществами 300–1500 подписчиков | +20–50/мес |

**Цель:** ~200–350 в сумме по якорным площадкам.

### Фаза 2 (2–4 мес) — лид-магнит без TG

- PDF **превью** (первые 3 ошибки) — файл в документах ВК или статья Дзен  
- Полный чек-лист — **платно** через VK + ЮKassa или «напишите в сообщения сообщества»  
- Серия «7 ошибок» — по одному посту ВК в день недели  

**Цель:** 500–700 суммарно.

### Фаза 3 (4–8 мес) — добор до 1000 эквивалента

- Таргет **ВК** (доступен без VPN): креатив «7 ошибок», ведём на сообщество  
- Повтор удачных статей Дзен  
- MAX — при подключении `empire_publish` → `max`

## 5. Что делать с ботом и TG

| Инструмент | Решение |
|------------|---------|
| `empire_garden_bot` (TG) | Не главная воронка; оставить для тех, кто уже в VPN-TG |
| Продажи PDF | **ВК:** сообщения сообщества + ЮKassa; файл в ответ |
| Автопостинг Empire | Можно крутить TG для архива; **добавить публикацию в VK** приоритетно |
| Ссылка в контенте | Везде вести на **vk.com/…** или **dzen.ru/…**, не t.me |

## 6. Технический бэклог Empire (под стратегию)

| # | Задача | Зачем |
|---|--------|--------|
| 1 | `VK_TOKEN` + живой `vk_wall` в `empire_publish` | автопост в сообщество |

| 4 | MAX адаптер | рассылка без VPN |
| 5 | Лендинг / страница ВК «скачать превью PDF» | лид без бота |
| 6 | Метрики: `vk_post`, `dzen_click` в `analytics.db` | что работает |

## 7. KPI (еженедельно)

| Метрика | Слабо | Норма |
|---------|-------|-------|
| Подписчики ВК (прирост) | &lt; 15 | 25–50 |
| Подписчики Дзен | &lt; 10 | 15–40 |
| Просмотры поста ВК | &lt; 50 | 100–300 |
| Дочитывания Дзен | &lt; 20% | 35%+ |
| Комментарии ВК | 0 | 2+ |

TG-метрики — **не основные** до смены доступности.
