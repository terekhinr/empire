## 0. Решение по объёму

**Сразу все 25 упражнений — нельзя качественно.** Рабочий режим:

1. Одно упражнение → каталог ошибок по школам → brief → промпт Gemini → QA → M → F → в прод.
2. Параллельно только **A/B пилоты** (локация, M→F, 1 vs 2 гири) — 6–10 картинок, не каталог.

**Основной генератор:** Gemini (ты + референсы). Cursor — дублирование промпта для сравнения в A/B, не основной поток.

## 2. Мерч и бренд на модели / в кадре

### 2.1 Что НА модели (канон)

| Зона | Содержимое | Запрет |
|------|------------|--------|
| **Футболка** | Белый line-art: **снегирь на гире** (грудь, 8–10 см) | Логотипы школ, Nike, SF |
| **Шорты/леггинсы** | Чёрные, **без** принта | Крупный мерч на бедре |
| **Обувь** | Минимал кроссы или босиком | — |
| **Гиря** | Чугун, 16 кг (12 halo), без бренда производителя крупно | Цветные гири |

### 2.2 Что на стенах зала (если фон — зал)

| Вариант | Описание | A/B |
|---------|----------|-----|
| **A · чистый** | Бетон/металл, **без** постеров и логотипов | default для CV |
| **B · мерч** | Тонкий трафарет «СНЕГИРИ» / силуэт птицы на гире, один угол кадра | не перекрывает атлета |
| **C · штерн** | Не в мультиках MVP | отложить |

**Запрет на стенах:** чужие залы, бренды фитнес-клубов, мотивационные постеры с лицами, **штанги и стойки в фокусе**.

### 2.3 Промпт-блок (вставка в каждый brief)

```
ОДЕЖДА: чёрная футболка, на груди белый снегирь на гире (кибер-гравюра).
Шорты/леггинсы чёрные без логотипов.
ФОН: индустриальный зал — бетон, металл, тени; без чужих логотипов на стенах.
В кадре ТОЛЬКО гиря(и) из brief — без штанги и блинов.
```

## 3. Дом vs индустриальный зал — анализ

Раньше в spec было «дом». Сейчас запрос: **профи в industrial gym**.

| Слой | Дом | Industrial gym |
|------|-----|----------------|
| **Продукт / программа** | ✅ «одна гиря дома» | не требует абонемента в зал |
| **Визуал эталона** | бытовой, риск «дешёвого» | ✅ как Руднев/Денисов на YouTube |
| **Доверие** | «я так же дома» | ✅ «серьёзная школа» |
| **Риск** | — | штанга на фоне, противоречие копирайту |

### Рабочая формула (предлагаем зафиксировать)

> **Тренируешься дома с одной гирей. Эталон снят в стиле industrial gym — как у тренеров, но в кадре только твой снаряд.**

- Фон: **industrial_gym** (бетон, металл, пустой зал, размытый реквизит).
- **В фокусе:** только атлет + гиря(и) из brief.
- **Запрет:** штанга, гриф, блины, силовая рама в кадре.
- App hint: «Сними дома с тем же ракурсом».

### A/B локации (обновить)

| Код | Для пилота |
|-----|------------|
| `industrial_gym` | **новый default** — пустой industrial |
| `home_room` | контроль — коврик, комната |

Пилоты: `swing` + `curl_up` × 2 локации × M = **4 картинки** (сократили с 6).

## 4. Ошибки по школам (не «от балды»)

Источник правды: [`snegiri_comic_errors_catalog.md`](snegiri_comic_errors_catalog.md).

**Принцип:** на каждую панель ERROR — **одна** типичная ошибка, подтверждённая школой (Руднев / Денисов / Алферова / McGill / SF RU).

### Пример: толчок (K17) — твоя правка

| | Было в генерации | Должно быть (Алферова / сорев. стойка) |
|--|------------------|------------------------------------------|
| Стойка | локти в стороны | **локоть на подвздошную кость**, предплечье на корпусе, треугольник |
| Толчок | «отжим» руками | импульс ног → **фиксация**, не жим |
| ERROR | размыто | **ОШИБКА: ЛОКТИ** (отведены) или **ОШИБКА: ОТЖИМ** |

Аналогично **стойка K5** — треугольник локтей (Алферова), не «локти торчат».

### Процесс на одно упражнение

1. Выписать 3–5 фаз **правильно** (школа + `program_data.hint`).
2. Выбрать **1** ERROR для панели (самая частая для новичка-дома).
3. Зона красной линии #FF3300.
4. Утвердить текстом → потом промпт Gemini.

**Статус каталога:** шаблон готов; **детально заполнены 5 упражнений**; остальные 20 — по одному в очереди.

## 5. Пайплайн «одно упражнение» (Gemini)

Подробно: [`snegiri_comic_gemini_workflow.md`](snegiri_comic_gemini_workflow.md).

```
errors_catalog[slug] → build_comic_briefs.py → render_comic_prompt.py
    → Gemini (M) + hero-poster.png → QA
    → Gemini (F) + ref M → QA
    → slice → status: ok
```

**Лимит Gemini:** ~2 картинки/день бесплатно → **1 упражнение (M+F) = 2 дня** минимум. Каталог 25 = ~5 недель при дисциплине. Это нормально.
