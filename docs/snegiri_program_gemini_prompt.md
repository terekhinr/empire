# Gemini · программа snegirinegi.ru v2 · лестница навыков и удержание

**Контекст для Gemini:** продукт — подписка с **разбором техники по видео**. Проблема: **3 гиры (свинг, рывок, толчок) за 2 недели = отписка**. Нужна **программа на 6–12 месяцев** как у сильных гиревых школ, но с **CV-контролем**.

**Изучи (опиши в ответе, что взял):**
- Виктор Блуд — вводный и 4-недельный гиревой курс (hinge, goblet, swing, get-up, press)
- Сергей Каширин / Streetfit / mosgiri — функциональный гиревой, круговые, связки
- RKC/StrongFirst прогрессия: TGU, clean, press, snatch
- Наш текущий скелет: McGill Big 3 → гиря

**Ограничения продукта:**
- Домашняя 1–2 гири 8–32 кг
- Разбор CV ~30 сек, не live-coach
- Не медпродукт
- Голос Штерна: brutal, без wellness

## Быстрый ответ (до Gemini)

**Ты прав:** продавать «3 гиры за 590 ₽/мес» — **слабое предложение**. Продавать **«каждую неделю новый навык + разбор + не откатить поясницу»** — другое.

Минимальный must-have для v2:
- **заброс (clean)**
- **турлиш (хотя бы по частям)**
- **goblet + carry**
- **комplex или EMOM-блок** после недели 16
- **сезоны** и **LLM-план**

Финмодель без этого — **оптимистичная фантазия**. С v2 — **реалистична** при churn 5–6%.
