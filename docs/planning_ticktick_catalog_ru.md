# Каталог проектов и чек-листов (после импорта TickTick)

Обновлено: 2026-06-29. Описания проектов записаны в базу; **9 чек-листов** перенесены в раздел **Чеклисты** в приложении.

## Проекты (списки TickTick)

### Входящие (Inbox) — 106 задач
**Что это:** задачи без списка в TickTick.  
**Как использовать:** каждую разобрать — назначить проект, дату или удалить. Не путать с шаблонами чек-листов.

### Инкубатор мыслей — 15 задач
**Что это:** идеи «на подумать» — бизнес, контент, эксперименты.  
**Примеры:** видео про разборку стиралки, разговор с Ухановым про гранты, программа бега.  
**Когда активировать:** когда есть время на исследование; иначе оставить или перенести в «Когда-нибудь».

### Информация — 78 задач
**Что это:** справочник — факты о детях, книги, цитаты, ссылки.  
**Не действие, а память:** «Макс говорит…», книги Леви-Брюля, заметки для детей.  
**Совет:** если нужно сделать — выделить отдельную задачу с датой в другом проекте.

### Когда-нибудь — 19 задач
**Что это:** GTD Someday/Maybe — интересно, без срока.  
**Примеры:** стопы/пятки, рамные уголки, схема экрана проектора.  
**Ритуал:** раз в квартал просмотр — в работу или в архив.

### На этой неделе — 1 задача
**Что это:** фокус недели (3–7 пунктов идеально).  
**Сейчас:** внесение извещений в журнал КД.

### Проекты — 2 задачи
**Что это:** многошаговые дела с результатом.

| Задача | Смысл | Контекст |
|--------|--------|----------|
| **Написать завещание** | Юридический документ для семьи | Личное / финансы, дедлайн окт 2026 |

### Цели — 6 задач
**Что это:** долгосрочные ориентиры без жёсткого дедлайна.

| Цель | Комментарий |
|------|-------------|
| Ходить на сплавы ≥2 раза в год с сыном | Связано с чек-листом «Сплав поход» |

| Английский до свободного разговора | Навык / карьера / контент |

### Чек-листы (проект в TickTick) — 9 задач-шаблонов
**Что это:** в TickTick это были шаблоны; в Empire они уже в **Чеклисты** (боковое меню). Задачи в проекте можно архивировать или оставить как напоминание.

## Чек-листы в приложении (9 шт.)

Откройте **Чеклисты** в боковом меню — там интерактивные списки с галочками.

### 1. Чек-лист командировка
**Когда:** перед выездом в служебную командировку (278 ВП и др.).  
**Проект:** служба. **Связь:** после поездки — чек-лист «Отчёт по командировке».

| Пункт | Зачем |
|-------|--------|
| Принадлежности для бани | Гигиена в гостинице / общежитии |
| Командировочный | Удостоверение командировки |
| Ножи в рюкзак | Если нужны по маршруту / быт |
| Отключить чайник | Безопасность дома |
| Справка-допуск | Допуск на объект при необходимости |
| Паспорт | Идентификация, регистрация |
| Регистрация на рейс | Авиа / ЖД |
| Номер в гостинице | Бронь подтверждена |
| Выключить компьютер | Дом / офис |
| Наличные и кредитка | Расходы в поездке |
| Фильмы на планшет | Досуг в дороге |
| Вещи по чек-листу «путешествие» | Если используете общий travel-лист |
| Такси вызвано | До аэропорта / вокзала |

### 2. Чек-лист отчёт по командировке
**Когда:** после возвращения, до сдачи в бухгалтерию.  
**Проект:** служба.

| Пункт | Зачем |
|-------|--------|
| Чек и справка из гостиницы + ЕГРЮЛ | Подтверждение проживания и контрагента |
| Справка с предприятия (был в командировке) | Подпись директора, печать |
| Билеты с ценами и корешками | Проезд |
| Выписки из приказов убытие/прибытие | Кадровое оформление |
| Отчёт о командировке | Итоговая форма с расчётом |
| Командировочное с отметками | Отметки прибыл/убыл; **278 ВП** на пункте 4 |
| Реквизиты карты для перечисления | Возврат / компенсация |
| Маршрутная квитанция | Доп. проездные документы |
| Договор с гостиницей | Если оплата по договору |

### 3. Чек-лист по службе в целом
**Когда:** ежедневно или в конце недели.  
**Проект:** служба / офис.

| Пункт | Зачем |
|-------|--------|
| Летучий контроль | Статус поручений руководства |
| Бумажная почта | Входящие документы |
| Стол без лишней бумаги | Порядок рабочего места |
| E-mail прочитан | Входящие письма |
| Папка «Написать письма» пуста | Исходящие закрыты |

### 4. Чек-лист по ведению конкретной работы
**Когда:** еженедельный обзор одного контракта/темы.  
**Проект:** служба / ведомая тематика.

| Пункт | Зачем |
|-------|--------|
| Донесения и доклады | Отчётность по проблемам |
| Название работы | Актуальность номенклатуры |
| Доп. соглашения к договору | Изменения условий |
| Совещания, протоколы | Фиксация решений |
| Доп. документы к ТЗ | Изменения техзадания |
| Летучие по теме | Закрыты ли открытые |
| Список проблемных вопросов | Актуализация рисков |
| Ведомости исполнения/поставки | Сверка с планом |

### 5. Чек-лист для наполнения рабочей папки
**Когда:** при передаче темы / аудите папки по контракту.  
**Проект:** служба / архив.

Пункты: дополнения к ведомостям, трудоёмкость, запросы о ходе, заключения ВП, техакты, ведомости, акты, донесения, расчёт цены, ТЗ и дополнения, совместные решения, договор и допы — **полный комплект документов по одной теме**.

### 6. Чек-лист сплав поход
**Когда:** за 1–2 недели до сплава.  
**Проект:** семья / отдых. **Цель:** сплавы 2×/год с сыном.

| Пункт | Зачем |
|-------|--------|
| Одежда куплена | По списку участников |
| Снаряжение | Палатки, костры, безопасность |
| Еда куплена / приготовлена | Меню и заготовки |
| Меню согласовано | Кто что готовит |
| Кто что берёт / несёт | Распределение груза |
| Маршруты в Garmin | Навигация |
| Электропитание на маршруте | Гаджеты, связь |

### 7. Разбираем вещи
**Когда:** уборка шкафа / сезонная ревизия.  
**Проект:** быт.

Каждый пункт — вопрос про **одну вещь**: сезон, стирка, работа/дом, глажка, выброс, полка.

### 8. Чек-лист уборка на работе и дома
**Когда:** быстрая уборка 15–30 мин.  
**Проект:** быт.

Правило: нужное → хранилище, ненужное → выброс, сомнение → хранилище; проверить стол, сейф, шкаф, стулья.

### 9. Поставить в нетбук твёрдый диск
**Не шаблон**, а разовая техзадача. Лучше перенести во **Входящие** или **Проекты** и удалить из чек-листов.

## Empire · Финансовая модель (planning PWA)

Импорт из репозитория (не TickTick):

```bash
./venv/bin/python scripts/seed_empire_pipeline_2026.py        # первый раз
./venv/bin/python scripts/seed_empire_pipeline_2026.py --sync   # обновить заметки
./venv/bin/python scripts/seed_empire_pipeline_2026.py --force  # пересоздать чеклисты
```

| Где в приложении | Что смотреть |
|------------------|--------------|
| **Проекты → Empire · Финансовая модель** | 14 задач «ФМ: …» с пояснениями (что / зачем / KPI / источник) |
| **Календарь** | Вехи с датами (launch 15.09, bridge, CPL 15.11, Premium фев 27…) |
| **Чеклисты → Empire Pipeline 2026 · Итоговый %** | Общий % по весам (30 пунктов трекера) |
| **Фаза 0…3** | Помесячные действия июн 26 — ноя 27 |
| **Финмодель · cashflow** | Сверка план vs факт раз в месяц |
| **Финмодель · метрики R5** | KPI недели, gift_emails, Метрика |
| **Блок 0…G · чеклист** | Прогресс по блокам пайплайна |

Документы: `docs/audit/05_FINANCIAL_MODEL.md` · `docs/audit/14_PIPELINE_R5_AUTOPOST.md`

## Что дальше

1. **Ctrl+F5** — обновить приложение (исправлен наезд текста в меню).
2. Открыть **Чеклисты** — должно быть **9** списков.
3. Задачи-шаблоны в проекте «Чек-листы» можно отметить выполненными или удалить — рабочие копии в разделе Чеклисты.
4. **Входящие (106)** — разобрать по проектам при следующем GTD-обзоре.

Скрипт повторного применения описаний: `./venv/bin/python scripts/setup_ticktick_catalog.py`
