# Google Drive Backup — дополнение Home Assistant

**Сервер:** Home Assistant Supervised на armbian (`192.168.1.41`).  
**Дополнение:** [Home Assistant Google Drive Backup](https://github.com/sabeechen/hassio-google-drive-backup) (sabeechen).

В HA 2024+ есть встроенный **Резервное копирование** (интеграция Backup). Дополнение Google Drive удобнее: **автозагрузка в облако**, расписание, очистка старых копий. Можно использовать **вместе** со встроенным бэкапом.

---

## 1. Установка дополнения

1. Откройте HA: `http://192.168.1.41:8123` (или Tailscale `100.80.133.85`).
2. **Настройки** → **Дополнения** → вкладка **Дополнения** (не «Магазин дополнений» внизу — сначала репозиторий).
3. Справа вверху **⋮** → **Репозитории** (Repositories).
4. Вставьте URL:
   ```text
   https://github.com/sabeechen/hassio-google-drive-backup
   ```
5. **Добавить** → закрыть.
6. **⋮** → **Проверить обновления** / обновить страницу (F5).
7. В списке найдите **Home Assistant Google Drive Backup** (часто внизу, после «Local add-ons»).
8. **Установить** → дождаться окончания (1–3 мин).
9. Включите:
   - **Запуск при старте** (Start on boot)
   - при желании **Показывать на боковой панели**
10. **Запустить** → **Открыть веб-интерфейс** (Open Web UI).

### Если дополнения нет в списке

- Убедитесь, что **Supervisor** работает (`Настройки → Система → Supervisor` — healthy).
- Повторите **Проверить обновления** у Supervisor.
- Очистите кэш браузера (Ctrl+F5).
- Репозиторий без опечаток, одна строка.

### Если ошибка «no supervisor internet connection»

Supervisor не видит интернет — репозиторий не добавится.  
**Починка:** [`docs/HA_SUPERVISOR_INTERNET.md`](HA_SUPERVISOR_INTERNET.md)  
**Временно:** встроенный бэкап HA → скачать `.tar` → вручную в Google Drive.

### Если «Установить» серое / другая ошибка

- **Настройки → Система → Обновления** — обновите Supervisor и HA.
- Мало места на диске armbian: `df -h` по SSH.
- Журнал дополнения / Supervisor — скопировать текст ошибки.

## 2. Первый запуск — Google аккаунт

В **веб-интерфейсе** дополнения (Getting Started):

1. **Authenticate with Google Drive** / **Войти в Google**.
2. Выберите **Google-аккаунт** (лучше отдельный или семейный, не рабочий с жёсткими политиками).
3. Разрешите доступ к Google Drive (папка приложения создастся сама).
4. Если браузер блокирует окно — разрешите всплывающие окна для IP HA.

После успеха: статус **Connected** / зелёная галочка.

---

## 3. Рекомендуемые настройки (empire)

Откройте **Settings** в UI дополнения (не путать с настройками HA).

| Параметр | Рекомендация |
|----------|----------------|
| **Schedule** | **Еженедельно**, ночь (например **Вс 03:00**) |
| **Retain** | **4–8** копий в Google Drive (или 30 дней) |
| **Retain local** | 1–2 локальные копии (экономия места на armbian) |
| **Backup name** | `HomeAssistant` + дата (по умолчанию ок) |
| **Notifications** | Включить — ошибка бэкапа в HA |
| **Encrypt** | По желанию пароль на архив (запишите пароль!) |

### Что попадает в бэкап

Полный снимок Supervisor, в том числе:

- `/config` — **packages**, **secrets.yaml**, **zigbee.db** (ZHA!), automations  
- дополнения, их данные  
- **Не забывайте:** без бэкапа потеря `zigbee.db` = перепривязка всех Zigbee-устройств.

### Ручной бэкап сейчас

В UI дополнения: **Backup now** / **Создать резервную копию** → дождаться **Upload complete**.

Проверка: в [Google Drive](https://drive.google.com) → папка вроде **Home Assistant Backups**.

## 4. Встроенный бэкап HA (дополнительно)

**Настройки** → **Система** → **Резервные копии** (Backup):

- можно сделать **локальный** снимок перед крупными изменениями;
- Google Drive дополнение может использовать тот же механизм создания backup.

Имеет смысл **раз в месяц** вручную: Backup в HA + проверка, что файл появился в Drive.

---

## 5. Восстановление (кратко)

1. Скачать `.tar` из Google Drive на ПК.  
2. **Настройки** → **Резервные копии** → **Загрузить** / восстановить (или через UI дополнения **Restore**).  
3. HA перезагрузится; время — от размера (10–30+ мин).  
4. **Не прерывать** питание armbian во время restore.

После restore: проверить Telegram, ZHA, LocalTuya.

---

## 6. Безопасность

- Бэкап содержит **secrets.yaml**, токены, **zigbee.db** — доступ к Google-аккаунту = доступ к дому.  
- Включите **2FA** на Google.  
- Не публикуйте ссылку на бэкап.  
- Опционально: **шифрование** в настройках дополнения + пароль в менеджере паролей.

## 8. Альтернатива без дополнения

Если дополнение не ставится:

1. **Настройки** → **Система** → **Резервные копии** → **Создать**.  
2. Скачать `.tar` на ПК.  
3. Вручную загрузить в Google Drive / Synology.

Минус: нет автоматизации и напоминаний.
