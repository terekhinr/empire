# Гдепар: экосистема TG ↔ сайт ↔ отзывы

**Статус:** июнь 2026, после аудита Gemini + P0.

## Роли (не дублировать)

| Слой | Задача | Формат |
|------|--------|--------|
| **gdepar.ru** | Каталог, карта, карточки, отзывы, SEO, лиды B2B | Факты, структура, UTM |
| **Telegram** | Живой голос, споры, «баня недели», трафик на карточку | **Ручной дуэт** `[Дуэт]` из JSON + approve |
| **Отзывы на сайте** | Доверие, сравнение | Цитата в TG + ссылка на карточку |

Канал **не** заменяет энциклопедия на сайте. Сайт **не** имитирует байки в TG.

## Персонажи

- **Михалыч** — традиция: пар, веник, этикет, атмосфера, отзыв гостя.
- **Кириллыч** — техника: печь, вентиляция, материалы, цифры, «как устроено».

Формат поста: 1–2 обмена репликами (`<b>Михалыч:</b>` / `<b>Кириллыч:</b>`), без шаблона «Кириллыч, слушай…».

Запрещён только **шаблонное** обращение в начале; диалог — норма.

## Слоты в Empire

| Слот | Когда | Код |
|------|-------|-----|
| Промо карты | Пн 11:00 | `promo_map` → `gdepar_promo_copy.json` |
| Практика / дуэт | 11:00 | `duo_curated` pool=practice — **без LLM** |
| **Баня недели** | (опц.) | pool=banya_week — ручной пост со ссылкой на карточку |
| Классическая баня | 15:00 | curated, без LLM |
| Практика / байка | 11:00 / 21:00 | LLM + `duo_dialog_prompt_block` |

## UTM

| Кампания | Слот |
|----------|------|
| `weekly_map` | Промо понедельника |
| `banya_week` | Пятница, карточка бани |

## Чеклист редактора (1×/нед)

1. Пятница: пост «Баня недели» ведёт на реальную карточку с отзывом.
2. Понедельник: промо карты с UTM.
3. На сайте: у выбранной бани есть ≥1 одобренный отзыв или пометка «ждём отзыв».
4. Нет поста без якоря на сайт 3 дня подряд — добавить нативную ссылку.
