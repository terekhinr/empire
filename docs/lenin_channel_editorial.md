# Ленин: режим публикаций

## Как сейчас (3 слота)

| Слот | Что | LLM | Approve |
|------|-----|-----|---------|
| **10:00** | `[В этот день]` — календарь | Да, жёсткий шаблон по `data/lenin/revolutionary_calendar.txt` | Да (черновик в боте) |
| **12:00** | Рубрика: литература / искусство / биография / кино | **Нет** — `data/lenin_rubrics.json` | Да + фото |
| **19:00** | Цитата / марксистский анализ / чтение / донат | Да (+ RAG ПСС, иногда скаут) | Да |

Автопост в канал **выключен** (`data/auto_publish.json` → `lenin.enabled: false`). Всё уходит в черновик → вы жмёте «Опубликовать».

## Рубрики 12:00 (база постов)

- Карточки в `data/lenin_rubrics.json`: поле **`quote`** — текст в blockquote; **`source`** — строка «Источник: …».
- Поле **`note`** в Telegram **не выводится** (только для черновика редактора в JSON).
- Ротация без повтора id: `data/lenin_rubrics_used.json`.
- Добавляйте выпуски: новый `id`, длинный `quote` (до ~900 знаков), `source`, `image_file` (Commons).

## Вечер 19:00 — меньше повторов

В коде:

- стоп-фразы: «Сим победиши», «парадокс? нет», «актуально сегодня», «Ленин vs бюрократия» и др.;
- память последних ~12 постов в промпт;
- self-critic переписывает, если клише осталось.

**Рекомендация:** оставить в расписании **один** вечерний LLM-слот — `[Марксистский анализ]` (новости + ПСС), остальные вечера — только curated/календарь/чтение. Так «почти всё из базы», один слот — новости с обязательным approve (уже так).
