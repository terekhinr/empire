## 2. Явные косяки контента TG

1. **Монолог-завод.** Много коротких «из истории / веник / печь» без адреса «куда пойти сегодня». Читатель не получает next action.
2. **Классика без комментария в эфире.** `note` в JSON есть, `show_commentary=False` — отстройка «литература» недораскрыта; пост выглядит как цитата ради цитаты.
3. **Пул classic: used.ids раздуты, но ~83 записи ещё можно крутить** — при этом last-40 всё равно уходит в mono. Нужна дисциплина слотов, не «пул кончился».
4. **Слабый CTA на gdepar.ru.** Конкуренты-гиды живут списками мест; мы почти не даём «3 бани у метро X» со ссылкой UTM.
5. **Дубли темы** («Из истории бани» повторяется в ленте) — размывает доверие.
6. **Сайт и TG не в одном ритуале:** карта огромная, канал не «продаёт» районы/фильтры карты.
7. **ВК/Дзен** — в планах, системного пайплайна под лиды нет (только TG).
8. **Нет доказательного B2B-контента** («владелец, вот сколько кликов по телефону в вашем районе») — без этого Premium не продать.

Это не «тупость ради тупости», а **разрыв brand-content vs money-content**. Литература — хорошо для отстройки; без еженедельного гида — **0 лидов**.

## 3. Сравнение с конкурентами

| | Конкурент-гид (pbkan, russian_bath) | Мы |
|--|-------------------------------------|-----|
| Формат хита | топы, wow-локации, «куда сходить» | классика + монолог |
| CTA | место / адрес / «сохрани» | редко карта |
| Монетизация контента | посевы, нативка, партнёрки | задуманы CPA/Premium |
| Риск | мусорные «9 причин» | наш риск — **элитарность без пользы** |
| Уникальность | низкая | **высокая** (классика) — надо упаковать в пользу |

**Правило 60/40 на 90 дней:**  
40% классика/история (бренд), **60% utility** (район, цена-ориентир, муж/жен день если знаем, «три варианта», ссылка на карту).

Не копировать «токсины/наука доказала».

## 4. Точные действия к деньгам (90 дней)

### P0 (эта неделя)

1. Metrika + цели: `phone_reveal`, `assistant_submit`, `map_click`, `partners_view`.
2. В каждый 2-й пост — блок: «Открыть на карте → gdepar.ru/?utm_source=tg&utm_campaign=…&region=MSK».
3. Phone enrich приоритет: **MSK, MO, SPB** (там платят за лиды).
4. Починить/завести журнал лидов в ledger раз в неделю (даже если 0).

### P1 (октябрь)

5. Рубрика **«Куда в субботу»** 1×/нед: 3 published точки одного района, факты из БД (рейтинг/отзывы), без выдуманных цен.
6. Вернуть `show_commentary=True` на 10 тестовых classic — A/B по ER.
7. Догрузить **новую** curated-пачку classic (не LLM) на 8–10 недель.
8. 15 personal outreach владельцам (сандуны-сегмент не трогать; средние общественные MO): «покажем телефон только по клику, пакет 4k».
9. ВК: 2 поста/нед — зеркало гида (не монолог).

### P2 (ноябрь–январь)

10. Триал CPA после ≥50 phone_reveal/мес.  
11. Premium не раньше **мар 27** (R6).  
12. Директ — только со стоп-лоссом; иначе органика+outreach.

### Не делать

- Массовый publish Сибири «для галочки».  
- Duo curated spam.  
- Покупной трафик до Metrika.
