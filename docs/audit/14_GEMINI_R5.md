## №1 · Посевы TG 7k ≠ 30 продаж

| | Математика |
|--|------------|
| Бюджет | 5–7k ₽ |
| CPA подписчик | **100–150 ₽** |
| Итого | **50–70** новых в TG/email |
| 30 продаж с 70 | конверсия **43%** — нереально |

**Правка:** посевы = **сбор email**, не прямые продажи.

| Инструмент | Цель |
|------------|------|
| Лид-магнит | PDF «5 принципов анти-пенсии» (3–5 стр) |
| Посевы август | **50–80 email** |
| Продажи launch | **YT (2 ролика) + своя база + pre-sale** |

→ Воронка: `docs/pension_august_funnel_2026.md`

## №2 · IVR и `billsec` (не `duration`)

**Риск:** 90 сек на автоответчике ≠ разговор с админом.

**Правка webhook:**
- Зачёт только при `disposition == ANSWERED`
- Длительность = **`billsec`** (разговор после ответа), не общий `duration`
- Порог **≥90 billsec**

→ Код: `tools/cpa_trial.py`, `POST /api/banya/calltrack`
