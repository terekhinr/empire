## UX: 7 правок до включения трафика

1. **Gdepar / Карта:** Визуально скрыть (или увести вниз выдачи) 1128 карточек без телефона. Они генерируют отказы при попытке phone_reveal.
2. **Gdepar / Метрика:** Жёсткий блок. Включить `metrika_id_set: true`. Без этого весь UX-анализ (в т.ч. A/B LLM-помощника) слеп.
3. **Gdepar / UTM:** Прошить все ссылки в TG Gdepar жесткими UTM-метками (source=tg, medium=post, campaign=brand).
4. **Gdepar / «Пар?»:** Снять LLM со сплита 25% или добавить трекинг событий взаимодействия. Без счетчика 25% трафика сжигают ключи OpenRouter впустую.
5. **Pension / `/buy`:** Изменить состояние UI с waitlist на реальную заглушку ЮKassa (хотя бы тестовый режим), чтобы проверить флоу checkout.
6. **Pension / `/gift`:** Исправить перезапись JSON. Добавить чекбокс согласия на обработку ПДн (иначе блокировка трафика).
7. **Pension / Навигация:** Убрать любые ссылки на несуществующий YT-канал, чтобы не уводить пользователя в «тупик».
