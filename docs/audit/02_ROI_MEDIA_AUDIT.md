# ROI-аудит: Media Buyer

**Роль:** Performance / Media Buyer. **Метрика:** окупаемость, не объём контента.

---

## Жёсткая правда

Месяцы ушли на **content pipeline для себя**, не на **distribution + monetization**. Garden ~7 подписчиков. Деньги — в **gdepar.ru (лиды)** и **ручных продажах**, не в RAG-объёме.

---

## Матрица каналов (4 TG + Pension)

| Канал | Вердикт | Почему | Автопост |
|-------|---------|--------|----------|

## Монетизация «на этой неделе» (из аудита)

1. **Gdepar:** outreach 20 владельцев → 1 Premium **2 990 ₽**.
2. **Pension:** pre-sale книги **149 ₽** → 10 копий = **1 490 ₽**.
3. **Не делать:** покупка подписчиков, масштаб рекламы до product-market fit.

## Диагностика заказчика (зафиксировано)

| Ответ | Следствие |
|-------|-----------|
| Цель — аудитория | Нет метрики денег |
| <5k ₽/мес денег, много времени | Сотни часов = упущенная выгода |
| Платящий клиент не определён | Двигатель без адресата |
| Только автопост | Рост не стратегия |
| Тест ЦА — слабая реакция | Продукт не прошёл проверку |
