# Диммер + датчик присутствия: день 100% / ночь 20%

**Логика (ванная):**

| Условие | При присутствии |
|---------|-----------------|
| **День** | свет **100%** |
| **Пониженная яркость** | свет **20%** |

Ночь (`binary_sensor.empire_vannaya_dim_night` = on) **только по расписанию**: **01:00–05:50** `Europe/Moscow`. Режим «Ночь» / Алиса на ванную **не влияют**.

После **30 с** без присутствия — выключение.  
**«Отпуск»** — **то же** поведение (блокировки нет).

С **05:51** МСК — снова **100%**; если свет уже горит — плавная смена яркости.

---

## Что нужно в железе

| Компонент | Требование |
|-----------|------------|
| **Диммер / лампа** | Сущность **`light.*`** с `brightness` (Zigbee, LocalTuya) |
| **Датчик** | **`binary_sensor.*`** присутствия (ZHA), area — комната |
| **Не подходит** | Лампа **только с ИК** (гостевая, Макс) — нет точных % в HA |

---

## Шаг 1. Пейринг в ZHA

1. **ZHA** → датчик присутствия → area (коридор / комната).
2. Диммер или умная лампа → та же area.
3. Записать **entity_id** из **Настройки → Сущности**, например:
   - `binary_sensor.koridor_prisutstvie`
   - `light.koridor_potolok`

---

## Ванная (настроено в репозитории)

| Устройство | entity_id |
|------------|-----------|
| **SONOFF SNZB-06P** (присутствие) | `binary_sensor.sonoff_snzb_06p` |
| Свет (Алиса + автоматизации) | `light.empire_vannaya_svet` (template, инверсия TS0052) |
| Сырой диммер ZHA | `light.tz3000_mgusv51k_ts0052` — не в Алису |
| HOBEIAN ZG-222Z | `binary_sensor.hobeian_zg_222z` — **протечка**, не свет |

`off` = «Не обнаружено», `on` = занятость. Тайм-аут датчика в ZHA: **15 с** (настройка на устройстве).

## Шаг 2. Файл автоматизаций

1. Скопировать `homeassistant/packages/empire_motion_light.yaml` → `/config/packages/`.
2. **Проверка конфигурации** → перезагрузка YAML.

Должны появиться 3 автоматизации (можно включить/выключить в UI).

---

## Шаг 3. Проверка

| Тест | Действие |
|------|----------|
| День (до 01:00, «Ночь» off) | присутствие → **100%** |
| Ночь (с 01:00 МСК или «Ночь» on) | присутствие → **20%** |
| Выключение | нет присутствия 30 с → свет off |
| Смена режима | свет горит → 01:00 / 05:51 или **Ночь** → 20% или 100% за 1 с |

Таймаут **30 с** — в файле `for: seconds: 30`, при необходимости измените.

---

## Несколько комнат

Скопируйте блок автоматизаций в том же файле с **новыми id** (`_komnata_maks_...`) и своими entity_id, либо создайте `empire_motion_light_koridor.yaml`.

---

## Расписание ванной (в репозитории)

В `empire_motion_light.yaml`: template **`binary_sensor.empire_vannaya_dim_night`** — **01:00–05:50** `Europe/Moscow` + `rezhim_noch`.

Глобальный «Ночь» по расписанию (22:00 / 07:00 для всего дома) — опционально, отдельно в `rezhim_noch`; на ванную уже влияет только с 01:00, если «Ночь» не включали вручную.

---

## ИК-лампы (гостевая, Макс)

Отдельные **script**: движение → script «свет 100%» / «ночник 20%» (выученные коды ИК). См. `docs/HA_YANDEX_IR_ALICE.md`.

---

## Алиса

`light.empire_vannaya_svet` в `yandex_smart_home.yaml`, комната **Ванная**. После деплоя: `yandex_smart_home.reload` и обновить УДЯ. См. `docs/HA_YANDEX_ALICE_SETUP.md`.

## Связанные файлы

- `homeassistant/packages/empire_motion_light.yaml`
- `homeassistant/packages/empire_mvp.yaml` — `rezhim_noch`
- `homeassistant/packages/empire_alice_scripts.yaml` — голос «ночь»
