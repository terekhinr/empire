# Что случилось с мультиками (провал пакета)

Мы сгенерировали ~50 комикс-эталонов (полосы 4 панели: SETUP → DRIVE → ST → ERROR) **пакетом без gate'ов**. Качество плохое:

| Дефект | Пример | Частота (оценка) |
|--------|--------|------------------|
| Штанга, стойки, блины в кадре | swing с power rack на фоне | ~40% |
| EN и RU вперемешку | «DRIVE», «ST», «ERROR» рядом с кириллицей | ~35% |
| 1 гиря vs 2 гири без правила | у M одна, у F две | ~25% |
| Разная хореография M/F | мужчина и женщина делают «разное упражнение» | часто |
| Техника неверная | толчок: локти в стороны вместо «локоть на подвздошную» (школа Алферовой) | ~30% у F |

**Решение команды:** все 50 WebP помечены `needs_regen`. В прод не идут. Дальше — **одно упражнение за цикл**: каталог ошибок → brief → Gemini web → QA мужчина → QA женщина.

**Генератор картинок:** только **gemini.google.com в браузере** (API с сервера: 429 quota / 403 ToS). Текстовые аудиты — Cursor + OpenRouter.

# Канон решений v2 (черновик — проверь и оспорь слабое)

1. **Язык:** все подписи, ошибки, названия в приложении — **русский**. Запрет EN-заголовков (ST, DRIVE, Push press).

2. **Локация (спорное место!):**
   - **Продукт** = пользователь тренируется **дома** с одной гирей 16 кг.
   - **Визуал эталона** = **industrial gym** (как ролики Руднев/Денисов на YouTube), но в фокусе **только гиря(и)** — без штанги, стоек, блинов.
   - Подсказка в app: «сними у себя дома с тем же ракурсом».

3. **Снаряд:** весь стартовый курс — **1×16 кг** (halo 12 кг, резина S4). Две гири — tier **advanced** (пока только farmer_walk_2kb).

4. **M/F:** сначала **мужчина** → QA → **женщина** с референсом на мужскую ленту; та же хореография; одноручные — **правая рука**.

5. **Мерч на модели:** чёрная футболка, белый line-art снегирь на гире на груди 8–10 см; шорты/леггинсы без логотипов.

6. **Стена зала:** A/B — чистый industrial **или** лёгкий трафарет «СНЕГИРИ» (ещё не выбрано).

7. **Ошибки ERROR-панели:** не выдумывать — из школ **Алферова, Денисов, Руднев, McGill** (каталог заполнен 5 из 25 упражнений).

8. **Экономика (finmodel v4):** churn планировать **10%/мес**, не 4%; CV — **квота 8 разборов/мес**, не «безлимитный ИИ»; годовой 3990 ₽ — убыточен → **5990** или убрать; paid реклама 80k/мес — **NO** до 30 organic paid.

9. **Stage-Gate:** сейчас Gate 3 (продукт v1) пройден частично; **Gate 4 (валидация: 3–10 платящих beta)** — **НЕ пройден**. Генерация 50 мультиков была прыжком в Gate 5 без Gate 4.

# Два независимых аудита — сверь и вынеси вердикт

## Источник 1: Cursor (детальный, в репозитории)

**Сессия 0 — согласен с каноном:**
- Остановить пакетную генерацию; одно упражнение за цикл.
- Формула **«дом в продукте / industrial gym на картинке»** — осознанное напряжение, не баг; проверить A/B (industrial_gym vs home_room).
- 25 gate-пунктов; топ-риски: CV stub vs маркетинг, McGill trademark, 0 beta pay, годовой тариф.

**Сессия A — предзапуск:**
- Playbook v1: Stage-Gate 6 уровней, 5 гипотез Lean на 4 недели, Kano (must: CV, McGill, 1 мультик, Metrika, ЮKassa).
- GTM 90 дней без paid до 30 платящих.

**Сессия B — finmodel:**
- PIVOT: продавать программу + ограниченный CV, не «магический ИИ».
- LTV при churn 10% ~1500 ₽/мес маржи, не 8k из старых моделей.
- Opportunity cost: 5 недель на 25 мультиков без платежей = NO-GO.

**Сессия J — мультики:**
- Спасти ~5/50; negative prompts обязательны; F без M — процессная ошибка.

## Источник 2: OpenRouter / DeepSeek (~$0.008 за прогон)

**Согласен с Cursor:** пакет 50 — ошибка; Gate 4 до контента; churn 10%; год 3990 — плохо; 12 ловушек соло-основателя.

**Расходится / ужесточает:**

| Тема | OpenRouter | Cursor |
|------|------------|--------|
| Локация | «Фокус на **доме**, не зале» — industrial gym запутает | Формула v2: дом + industrial визуал; A/B тест |
| Юридика школ | Жёстче: нужны **согласования** с McGill/Алферовой, не «цитируем YouTube» | Риск есть; формулировки «методика вдохновлена» |
| Пилот J | clean + overhead press | rack_hold или jerk (короче rack) |
