# Garden: ценность и отстройка от конкурентов

Использовать при **любом** контенте: PDF, посты, бот, гайд 4 недели, промо.

Конкуренты для spy (TG): `@dachnik_ru`, `@ogorod_life` + массовые «100 советов», курсы «суперурожай за 3 дня», реклама удобрений.

---

## 1. Обещание бренда (одна фраза)

**Степаныч:** не «волшебные рецепты», а **что проверить на вашей грядке в средней полосе — сегодня, этим месяцем** — чтобы урожай не «утекал» в мелочах.

---

## 3. Чем «как у лучших, но лучше»

Темы те же (мульча, полив, сидераты), но усиление:

1. **Критерий «сделано правильно»** — не «полейте умеренно», а «земля влажна на 10 см, верх сух к обеду».
2. **Ошибка дороже совета** — показываем цену косяка (потеря рассады, неделя без завязи).
3. **Схема грядки** — пустой шаблон в PDF, конкуренты редко дают заполнить своё.
4. **Сводка да/нет** — самодиагностика, не пассивное чтение.
5. **Связка с каналом** — посты = сезон; PDF = система; бот = покупка без лишнего.

- совет без привязки к **месяцу** (в постах — обязательна сезонность)

## 5. УТП tripwire (290 ₽)

**Название для обложки:** «7 ошибок грядки, из‑за которых тает урожай»

**Не продаём:** энциклопедию, список сортов, календарь на 365 дней.

**Продаём:** приоритетный аудит огорода за один вечер + таблица «исправить в этом сезоне».

**Upsell:** гайд 4 недели = внедрение по неделям, не ещё 200 страниц. Текст: `data/garden_deliverables/garden_guide_4weeks.md`.

| Продукт | Цена | УТП в одной строке |
|---------|------|-------------------|
| Tripwire | 290 ₽ | 7 дорогих ошибок + тест 60 сек |
| Гайд 4 недели | 1290 ₽ | 4 недели × 3 дела, чеки, связка с tripwire |

## 6. Метрики ценности (для себя)

- Дочитывание PDF / возврат в бот за гайдом  
- Отзыв в формате: «поправил X — Y перестало гнить / завязалось»  
- Меньше однотипных вопросов в комментариях канала  

---

## 7. Чеклист перед публикацией материала

- [ ] Есть **полевой тест** (руки/глаза/запах), не только теория  
- [ ] Указан **месяц или фаза сезона** для средней полосы  
- [ ] Нет **более 3 действий** на один блок («сделайте одно»)  
- [ ] Есть контраст **«так делают все / так делаем мы»** или явная цена ошибки  
- [ ] Нет рекламы сторонних магазинов/удобрений
