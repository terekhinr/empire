Вам прислали 3 ссылки VPN (все три нужны).

1) Поставьте приложение Hiddify
   • Android: https://github.com/hiddify/hiddify-app/releases (файл .apk)
   • iPhone: App Store → Hiddify

2) В Hiddify нажмите + и по очереди вставьте все 3 ссылки из сообщения (из буфера).

3) Нажмите «Подключить» → разрешите VPN.

4) Откройте вкладку «Прокси» → нажмите тест (молния).
   Приложение само выберет рабочий сервер.
