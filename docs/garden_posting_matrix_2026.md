# Garden TG: 14 рубрик × слоты (гибрид с текущим расписанием)

**Решение редактора:** **08:00** и **20:00** не трогаем — погода/план и лунный итог остаются якорями дня.

Меняем «середину дня»: **12:00** и **16:00** — туда встраиваем новые рубрики **как дополнительные варианты** в `content_config.json` → `garden.topics[*].12:00|16:00.variants` (бот по-прежнему выбирает тему из слота; разнообразие даёт расширенный пул + префиксы в квадратных скобках).

**Неизменно:** воскресенье **16:00** — `type: bot_promo` (как сейчас).

---

## 1. Слоты (итог)

| Слот | Роль | Что делаем |
|------|------|------------|
| **08:00** | Якорь | Оставляем: `[План на день] …` |
| **12:00** | «Грядка дня» — главный практический пост | Добавляем рубрики **1, 4, 5, 6, 8, 10, 11 (в межсезонье), 13, 14** как новые `variants` рядом с существующими `[Почва]`, `[Томат]`, … |
| **16:00** | «Второй заход» — уход, инструмент, теплица, здоровье, банный мост | Рубрики **2, 3, 7, 9, 11 (зима), 12** + часть пересечений с уже есть `[Полив]`, `[Сидераты]`, `[Эко-удобрения]` |
| **20:00** | Якорь | Оставляем: `[Лунный календарь] …` |

Так получается **гибрид**: старые темы не выкидываем — они остаются в `variants`; новые 14 — **новые строки-триггеры** для промпта и визуала (фото с участка).

---

## 2. Матрица: 14 рубрик → куда и когда логичнее

Ниже **предпочтительный слот** и **сезон** (для ручной ротации или будущего «сезонного фильтра» в коде). Дни недели — мягкая рекомендация, чтобы не класть всё в один день.

| № | Рубрика | Слот | Сезон / частота | Совпадение с текущим конфигом |
|---|---------|------|------------------|----------------------------------|
| **1** | Томатная секта | **12:00** | май–август пик; вне сезона — «разбор ошибок прошлого года» | Уже есть `[Секреты урожая] Томат…` → **добавить** варианты с тегом `[Томатная секта]` (гибрид) |
| **2** | Агрофитнес | **16:00** | весь сезон; пик — май–сентябрь | Новое; не дублирует утренний план |
| **3** | Банный огород | **16:00** | **1× в 2 недели** (мост с Gdepar) | Отдельный префикс `[Сад↔Баня]`; не подряд с чисто банными постами Gdepar в тот же час |
| **4** | Лентяйские грядки | **12:00** | весна–осень | Пересекается с мульчей/Розумом → варианты «минимум возни» |

| **8** | Хирургия сада (обрезка) | **12:00** | фев–апр, июль (кусты) | Уже воскресенье частично `[Сад] Обрезка` → перенести часть вариантов в `[Хирургия сада]` |
| **9** | Тепличные интриги | **16:00** | апр–сен | Новые `[Теплица]` варианты |

| **11** | Аптека на подоконнике | **16:00** | **нояб–фев** приоритет; летом реже | Зимний контент в «длинный день» 16:00 |
| **12** | Инструментальный цех | **16:00** | круглый год | Уже `[Инструменты] Фокин…` → расширить секаторы, опрыскиватели |
| **13** | Сорняки как индикаторы | **12:00** | май–июнь | Новое; хорошо после дождя / «первые всходы» |
| **14** | Сезонные чек-листы | **12:00** | пики: майские, 15 авг, «закрытие сезона» | Короткий формат; **пятница 12:00** удобна под «на выходные» |

## 3. Чередование по дням недели (черновик, без правки JSON)

Цель: в одну неделю не бить **томат** четыре раза подряд.

| День | 12:00 (акцент) | 16:00 (акцент) |
|------|----------------|----------------|
| пн | чек-лист / план недели (14) | агрофитнес (2) |
| вт | томаты или рассада (1) | теплица (9) |
| ср | лентяйские грядки (4) | компост/сидераты (7) |
| чт | вредители (6) | инструменты (12) |
| пт | сорняки-индикаторы (13) | **сад↔баня** (3) или лёгкий юмор (10) |
| сб | экзотика (5) или томаты | агрофитнес / теплица |
| вс | обрезка/сад (8) | **bot_promo** (как сейчас) |

Реализация: не обязательно жёсткий код — достаточно **набора variants** в JSON по дням (у вас уже `0`…`6`).

---

## 4. Формат поста (как дробить рубрику)

Универсальная цепочка для промпта (как вы описали):

1. **Крючок** (1–2 предложения, ирония без перегиба).  
2. **Фото с участка** (или схема).  
3. **Ошибка из опыта** / «как было у Степаныча».  
4. **Вывод** — 3–5 строк, без выдуманной «науки».

В теме строки для LLM можно добавить: `формат: крючок → фото → ошибка → совет`.

---

## 5. Что править в репозитории (поэтапно)

1. **Фаза «обкатка»:** в `content_config.json` для каждого `weekday` в **12:00** и **16:00** добавить по 1–2 новых `variants` с новыми скобками `[Томатная секта]`, `[Агрофитнес]`, … не удаляя старые.  
2. Через 2–4 недели по метрикам: ослабить дубли (если `[Почва]` и `[Лентяйские грядки]` дают одинаковый текст — сузить варианты).  
3. Опционально позже: **сезонный фильтр** в коде (не показывать `[Кабачковое безумие]` в январе) — пока не нужен, если редактор следит руками.

---

## 6. Связь с Gdepar (рубрика 3)

- **Сад:** мята, полынь, зола с печи на грядки.  
- **Gdepar:** тот же факт с другой стороны (пар, веник).  
- **Правило:** один и тот же «факт недели» не двум каналам в один день; смещение на 2–3 дня или разный угол (сад = грядка, баня = пар).
