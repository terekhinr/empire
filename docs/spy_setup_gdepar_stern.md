# Spy для Gdepar и Stern: как организовать

Связь: `docs/empire_partisan_architecture.md`, `data/spy_competitors.json`.

---

## 1. Логика (кратко)

```
Один техаккаунт Telegram + Telethon на VPS
    → читает публичные каналы конкурентов (без подписки часто достаточно)
    → считает просмотры/реакции → anomaly_score
    → spy_signals в БД
    → 1×/нед слот spy_inspired → черновик → вы approve → в сетку автопоста
```

**Пенсия** в этом контуре **не участвует** (только RSS в дашборде).

---

## 2. Что покупать (и что не нужно)

| Нужно | Зачем | Ориентир |
|-------|--------|----------|
| **Telegram-аккаунт** (1 шт.) | Сессия Telethon на сервере | Ваш личный «тех» или отдельный номер |
| **api_id + api_hash** | [my.telegram.org](https://my.telegram.org) → API Development | Бесплатно |
| **Номер телефона** | Привязка аккаунта | Уже есть SIM / виртуальный номер при создании нового аккаунта |
| **VPS** | Уже есть (Empire) | — |

| Не нужно на старте | Почему |
|--------------------|--------|
| Пачка телефонов | Один аккаунт читает десятки **публичных** каналов |
| Платные «фермы» TG | Риск бана, не нужны для чтения |
| Отдельный аккаунт на каждого конкурента | Достаточно одного reader-аккаунта |
| VPN для VPS | VPS уже смотрит TG API напрямую |

**Нейрокомментинг** (позже) — тот же или второй аккаунт; лимит 3–5 комм/день. Можно отложить.

### Рекомендация по аккаунту

1. **Отдельный** номер/аккаунт «Empire Spy» (не личный основной) — если бан, не потеряете личку.  
2. Профиль нейтральный: имя + аватар, без массовых подписок/спама.  
3. Подписаться на 10–15 каналов из списка ниже (или не подписываться — Telethon часто читает public по username).

## 3. Настройка в Empire (когда есть api_id/hash)

```bash
# .env на VPS
TELETHON_API_ID=...
TELETHON_API_HASH=...

# Один раз: логин сессии (интерактивно с VPS или локально, файл .session в проект)
# python scripts/telethon_login.py   # если скрипт есть; иначе — по инструкции в TZ
```

После `.session` → worker переключается с `dry_run_news` на реальные посты каналов.

Пока сессии нет — **spy выключен** (`stop_spy: true`, без `SPY_ALLOW_DRY_RUN`). 
Сад / Ленин / Пенсия **не** используют spy. Авточерновики из spy **не** создаются.

## 4. Где взять конкурентов

### 4.1. Критерии отбора

| Критерий | Gdepar (баня) | Stern (спина / гири) |
|----------|---------------|----------------------|
| Тема | Парение, баня, веник, здоровье | Гири, спина, офис, функционал |
| Язык | Русский | Русский |
| Формат | Посты с текстом + фото в TG | То же + Shorts/Reels если видно |
| Охват | От ~2k подписчиков; смотреть **ER поста**, не только subs | От ~3k; офис/гири нишевее |
| Не брать | Чистая реклама саун без контента | Бодибилдинг «качай бицепс» |

**ER (упрощённо):** (просмотры поста / подписчики) или реакции/просмотры vs медиана канала за 30 дней. Empire ставит `anomaly_score` — в дашборде сортировать по ER.

### 4.3. Будет ли Empire искать сам?

| Сейчас | План |
|--------|------|
| Список **вручную** в `spy_competitors.json` | Вы правите раз в квартал |
| Dry-run не ищет новых каналов | Live Telethon только **мониторит** известные @ |
| Автопоиск по теме | **Фаза 2:** TG Search / каталоги (telemetr API) — отдельная задача |

Я могу раз в месяц **предлагать** дополнения к списку (поиск + telemetr), вы утверждаете в JSON.

## 5. Рабочий процесс в дашборде

1. **Разведка · Gdepar/Stern** — таблица сигналов, фильтр по персоне.  
2. Взлётевший пост → **«В сетку автопоста (черновик)»**.  
3. **Модерация постов** — правка → Опубликовать.  
4. Раз в неделю (когда включим код) — слот `spy_inspired` сам создаст **один** черновик на персону → снова approve.

**Видео:** вкладка **«Видео · Shorts»** — позже привязка к `kind=video` в spy; Stern в приоритете, Gdepar в бэклоге.

---

## 6. Риски

| Риск | Митигация |
|------|-----------|
| Бан reader-аккаунта | Один аккаунт, только чтение, без массовых комментов до нейро-пилота |
| Копирование конкурента | Prompt: новый угол, полевой тест; не копипаст |
| Пустой spy без сессии | Пока dry-run; не ждать «взлёты» до Telethon login |
| Нерелевантный FitnessRU | В prompt слота: «только спина/офис/гиря» |

## 7. Чеклист запуска

- [ ] Создать/выделить TG-аккаунт «Empire Spy»  
- [ ] Получить api_id / api_hash → `.env`  
- [ ] Проверить каналы из JSON (живые ли)  
- [ ] Telethon login → `.session` на VPS  
- [ ] `systemctl restart empire_worker`  
- [ ] Через 2–3 дня — смотреть «Разведка · Gdepar/Stern»  
- [ ] Включить автослот `spy_inspired` (1/нед, approve) — после стабильных сигналов
