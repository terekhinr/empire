# Gdepar TG: матрица тем, слоты, картинки, RAG/ИИ (2026)

**Задача:** не утонуть в «тишина / верхняя полка / веник», держать **сериал** (Михалыч + Кириллыч), чередовать экспертизу, юмор и быт.

Связка с кодом: `content_config.json` → `gdepar`, семейства и cooldown — `data/gdepar_angle_families.json`, `docs/gdepar_content_diversity_tz.md`.

---

## 1. Ритм сейчас (3 поста / день)

| Слот | Роль в матрице | Содержание |
|------|----------------|------------|
| **11:00** | Столб / день | Экспертиза, мифы, инженерия, сезонность, география (см. треки 1–2, 5–6, 8, 11–13) **или** еженедельное **промо карты gdepar.ru** |
| **15:00** | Фикс | **«Классическая баня»** (curated, без LLM) — литература, не конкурирует с 11:00 |
| **21:00** | Воздух / эмоция | Фауна, байки, чай, дипломатия, антихрупкость, мыльня (треки 3–4, 7, 9–10, 14) |

Принцип из вашего текста сохранён: **утром «матчасть и польза», днём классика, вечером истории и атмосфера** — внутри недели за счёт чередования **треков**, а не «только вторник = эксперт».

## 4. Ротация по неделям (пример)

**Неделя A (треки на 11:00, кроме дня promo_map):** G1 → G11 → G2 → G8 → G5 → G12 → G13  
**Неделя B:** G11 → G1 → G8 → G2 → G5 → G13 → G12  

**21:00 чередование:** G3 ↔ G7 ↔ G4 ↔ G10 ↔ G14 ↔ G9 (G9 не подряд).

Реализация в коде: расширить **`variants`** в `content_config.json` префиксами `[Физика пара]`, `[Веники]`, `[Фауна]` … чтобы `gdepar_content.angle_families` и анти-клише не склеивали всё в «тишину».

## 5. Откуда картинки (приоритет)

1. **Свои фото** (баня, веник, чай, сумка) — максимум доверия и уникальности.  
2. **Wikimedia Commons** — архитектура, история, растения; ссылка в посте не обязательна, но хранить имя файла для отчётности.  
3. **Скрин/мокап gdepar.ru** — для географии и промо (уже бренд).  
4. **Генерация (SD / API)** — схемы, «второй веник», атмосфера без узнаваемых лиц; **единый визуальный стиль** (лог в промпте); в спорных темах — оговорка «иллюстрация».  
5. **Сток** — только с нормальной лицензией; избегать «голливудской сауны», если позиционируете русскую баню.

## 6. RAG и ИИ: кто за что отвечает

| Задача | RAG (фактура) | ИИ (язык) |
|--------|----------------|-----------|
| Цифры, вентиляция, веники, история | Сайт **gdepar.ru**, статьи, **книги/статьи в индексе** (при появлении корпуса), выдержки с пометкой источника | Не выдумывать цифры — только пересказ найденного |
| Диалог Михалыч / Кириллыч | Короткие **шаблоны реплик** из редактуры или 3–5 примеров в системном промпте | Генерация сцены **в рамках** RAG-факта |
| Мифы и здоровье | RAG: ВОЗ/обзоры **общими словами**; не «лечит от …» | В конце поста **«не медсовет; при болезнях — к врачу»** |
| Классика 15:00 | `gdepar_literature.json` / `gdepar_classic_banya.json` | Без LLM или только выбор варианта |

**Анти-выгорание редактора:** раз в месяц прогон по матрице — какие треки не светились 21+ день; подтянуть `variants` в JSON.
