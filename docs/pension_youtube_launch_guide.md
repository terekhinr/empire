# YouTube для «На пенсию никогда» — полный гайд запуска

**Контекст РФ 2026:** значительная часть аудитории открывает YouTube **только через VPN**. Это влияет на охват, монетизацию и рекламу — учитываем в стратегии, не отменяем YouTube.

Связь: Pension — главный проект; Shorts для Pension — **позже**; Stern Shorts — VK/Дзен/Rutube.

---

## 1. Стратегия при VPN-аудитории

| Факт | Следствие |
|------|-----------|
| Без VPN YouTube в РФ ограничен | Не строим **только** YouTube |
| Ядро аудитории Pension — думающие, финансы | VPN-пользователи часто **ваша** ЦА |
| Дзен / VK / сайт / TG | Параллельные «без VPN» якоря |
| YouTube | Длинный формат, доверие, монетизация, поиск **с VPN** |

**Воронка:**

```
Дзен + VK + neverretire.ru (без VPN)
        ↓
YouTube — полные выпуски (VPN-аудитория + SEO)
        ↓
Сайт / бот / донаты / инфопродукты
```

В каждом выпуске и в описании — **ссылка на сайт и VK**, не только «подпишись на YT».

## 2. Юридическое и аккаунт (не пропускать)

### 2.1. Кто владелец канала

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **Физлицо (вы)** | Быстрый старт, AdSense на себя | НПД/самозанятость при доходах |
| **ИП** | Прозрачные договоры с рекламой | Регистрация, отчётность |
| **ООО** | Бренд «Никогда» | Дороже, если нет ООО — не сейчас |

Для старта: **физлицо + самозанятость/НПД** при первых выплатах (см. §6).

### 2.2. Google-аккаунт

1. Отдельный Google-аккаунт **«На пенсию никогда»** (не личный Gmail вперемешку).
2. **2FA** обязательно (Authenticator).
3. Резервные коды — в менеджер паролей.
4. Страна аккаунта — как у AdSense (обычно **Россия**, если резидент РФ).

### 2.3. YouTube channel

1. [studio.youtube.com](https://studio.youtube.com) → создать канал.
2. **Брендовый аккаунт** привязан к Google «Никогда».
3. Имя канала = бренд с сайтом (единый стиль с neverretire.ru).

## 6. Монетизация (поэтапно)

### 6.1. YouTube Partner Program (AdSense)

**Условия (проверять актуальные в справке Google):**

- 1000 подписчиков + 4000 часов просмотра за 12 мес **или** порог Shorts;
- Без страйков за авторские права;
- Привязка **AdSense** к тому же Google-аккаунту.

**РФ и выплаты:**

- AdSense для РФ: уточнять **текущие** способы вывода в кабинете Google (менялись).
- Вести учёт дохода → **НПД/самозанятость** (лимит 2,4 млн ₽/год на НПД).
- Empire `sales.db` / НПД-алёрт — для продуктов; рекламу YT учитывать отдельной строкой.

### 6.2. Доходы кроме рекламы (важнее на старте)

| Источник | Когда |
|----------|--------|
| **Инфопродукты** | Книга, курс, консультации → ссылка с YT |
| **Дзен** | Партнёрка + дубли статей |
| **Прямая реклама** | После 5–10k подписчиков — медиакит |
| **Донаты** | Boosty / VK Donut — если ЦА там |

**Реклама в роликах:** не принимать «гарантированную доходность»; чек-лист комплаенса.

### 6.3. VPN и рекламный доход

- Просмотры из РФ **через VPN** часто считаются; CPM может отличаться от «локальной» РФ без VPN.
- Не закладывать в бюджет «только AdSense» первые 6–12 мес.
- KPI старта: **подписчики + переходы на сайт** (UTM `utm_source=youtube`).
