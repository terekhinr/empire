**Ваш HA:** `http://192.168.1.41:8123` · Tailscale `http://100.80.133.85:8123`  
**Интеграция:** Yandex Smart Home → **Yaha Cloud** (облако, без белого IP).  
**План освещения по комнатам:** [`HA_LIGHTING_ALICE_ROADMAP.md`](HA_LIGHTING_ALICE_ROADMAP.md) (ванная без голоса, кухня/спальня — голос, ИК — гостевая/Макс).

## Почему в Алисе только «Дети спят», «Ночь» и т.п.

Это **нормально**, если в настройках интеграции вы отметили только **`script.*`** (сценарии режимов).

| В «Дом с Алисой» | Что это в HA | Почему так |
|------------------|--------------|------------|
| Сценарии «Ночь», «Дети спят»… | `script.rezhim_*_vklyuchit` | Вы их **явно** добавили в «Объекты для передачи» |
| Нет «свет в ванной» | нет в YAML / не обновили УДЯ | Нужны `light.empire_vannaya_svet` в `yandex_smart_home.yaml` + reload |
| Свет не реагирует с Алисы | Сырой `light.tz3000_*` | У диммера **перепутаны on/off** — в Алису только `light.empire_vannaya_svet` |

**Сценарии в HA работают** (проверено по API): «Ночь — включить» переключает `input_boolean.rezhim_noch`. Если в приложении Алисы сценарий «не делает ничего» — см. [раздел 8 — не работает](#8-не-работает--чеклист).

## Схема

```mermaid
flowchart LR
  A[Колонка / телефон] --> B[Дом с Алисой]
  B --> C[Yaha Cloud]
  C --> D[Home Assistant]
  D --> E[script / light]
```

1. Вы говорите или нажимаете в приложении.  
2. Яндекс шлёт команду в **Yaha Cloud**.  
3. Облако вызывает ваш **HA** (нужен интернет на armbian).  
4. HA выполняет **script** или **light.turn_on/off**.

## Часть 2. Yandex Smart Home (уже установлен)

Если интеграции нет:

1. **HACS** → репозиторий `https://github.com/dext0r/yandex_smart_home` → установить.  
2. **Настройки → Устройства и службы → Добавить** → **Yandex Smart Home** → **Yaha Cloud**.

Документация: [docs.yaha-cloud.ru](https://docs.yaha-cloud.ru/v1.0.x/config/getting-started/)

## Часть 3. Список устройств для Алисы (YAML — рекомендуется)

Так проще, чем вручную отмечать сотни сущностей: всё в репозитории, повторяемо.

### 3.1 Скопировать конфиг

1. `homeassistant/yandex_smart_home.yaml` → **`/config/yandex_smart_home.yaml`**
2. В **`/config/configuration.yaml`** добавить (если ещё нет):

```yaml
yandex_smart_home: !include yandex_smart_home.yaml
```

Полный пример фрагмента: `homeassistant/configuration.yaml.snippet`.

Если `packages` ещё не подключены:

```yaml
homeassistant:
  packages: !include_dir_named packages
```

### 3.2 Включить режим «Через YAML» в интеграции

1. **Настройки → Устройства и службы → Yandex Smart Home** (ваша запись Yaha Cloud).  
2. **Настроить** (шестерёнка).  
3. **Объекты для передачи в УДЯ** → выбрать способ **«Через YAML конфигурацию»** (не «Через интерфейс»).

Если раньше отмечали сценарии вручную:

- **Сервисное меню** интеграции → **«Перенести фильтр объектов из YAML»** (по желанию),  
  или оставить только YAML после переключения способа.

### 3.3 Применить

1. **Настройки → Система → Перезапуск** не обязателен.  
2. **Панель разработчика → YAML → Перезагрузка конфигурации YAML** (или перезагрузка всей конфигурации).  
3. **Инструменты разработчика → Службы** → `yandex_smart_home.reload` → **Вызвать**.

## Часть 4. Синхронизация с «Дом с Алисой»

### 4.1 Телефон

1. Приложение **[Дом с Алисой](https://alice.yandex.ru)** (тот же аккаунт, что при привязке HA).  
2. **Устройства** (вкладка внизу).  
3. **+** или **Обновить** / потянуть список вниз.  
4. Найти производителя **Yaha Cloud** (или название вашего навыка).  
5. **Обновить список устройств** (в карточке производителя — см. [документацию](https://docs.yaha-cloud.ru/v1.0.x/platforms/yandex/#discovery)).

После настройки YAML должны появиться:

| В приложении | В HA |
|--------------|------|
| Сценарий **Ночь** | `script.rezhim_noch_vklyuchit` |
| **Выключить ночь** | `script.rezhim_noch_vyklyuchit` |
| **Дети спят**, **Отпуск**, **Ушёл** | аналогично |
| **Свет** в комнате **Ванная** | `light.empire_vannaya_svet` |

**Не должно быть:** сырой диммер `_TZ3000_mgusv51k`, `script.empire_test_telegram`.

### 4.2 Колонка

- Тот же **Яндекс ID** и тот же **дом** в приложении.  
- Колонка: **Настройки → Умный дом** — дом совпадает с телефоном.  
- После обновления списка подождите **1–5 мин**.

## Часть 5. Как говорить Алисе

### Режимы (сценарии)

Сценарий в УДЯ — это **одно действие** (как кнопка), не переключатель.

| Скажите | Действие |
|---------|----------|
| «Алиса, **запусти сценарий ночь**» | включить ночь |
| «Алиса, **запусти сценарий выключить ночь**» | выключить ночь |
| «Алиса, **включи дети спят**» | часто срабатывает как сценарий |
| «Алиса, **запусти сценарий отпуск**» | отпуск + Telegram (если настроен) |

Короткие фразы «включи ночь» / «выключи ночь» тоже часто работают — зависит от имени в УДЯ. Если нет — используйте **«запусти сценарий …»**.

**Режим «Ночь»** влияет на **всю квартиру** (`input_boolean.rezhim_noch`).  
**Ванная** дополнительно: **01:00–05:50** МСК → 20% даже без «Ночи» (`binary_sensor.empire_vannaya_dim_night`).

### Свет

| Скажите | Условие |
|---------|---------|
| «Алиса, **включи свет в ванной**» | передан `light.empire_vannaya_svet`, комната **Ванная** |
| «Алиса, **выключи свет в ванной**» | то же |
| «Алиса, **сделай свет в ванной на десять процентов**» | только **`light`**, не `switch` |

Имена комнат должны совпадать с **Областями** в HA (**Ванная**).

## Часть 6. Проверка по шагам (обязательно)

### Шаг A — только Home Assistant

1. **Разработчик → Службы** → `script.turn_on` → entity `script.rezhim_noch_vklyuchit`.  
2. **Настройки → Сущности** → `input_boolean.rezhim_noch` → должно стать **on**.

Если здесь не работает — проблема в **packages**, не в Алисе.

### Шаг B — приложение «Дом с Алисой»

1. Найти сценарий **Ночь** → нажать.  
2. В HA `rezhim_noch` → **on**.

Если A работает, B нет — **синхронизация / аккаунт / Yaha Cloud**.

### Шаг C — голос

«Алиса, запусти сценарий ночь» на колонке в том же доме.

### Шаг D — свет ванной

1. `light.turn_on` → `light.empire_vannaya_svet` — лампа **загорается** (см. `docs/HA_DIMMER_INVERT.md`).  
2. В приложении — переключатель **Свет** в **Ванной**.  
3. Голос: «включи свет в ванной».

## Часть 7. Два способа выбора устройств (не смешивать)

| Способ | Где настраивается | Когда использовать |
|--------|-------------------|---------------------|
| **Через интерфейс** | Интеграция → галочки по сущностям | Быстрый тест 2–3 сценариев (у вас сейчас так) |
| **Через YAML** | `/config/yandex_smart_home.yaml` | **Рекомендуется empire** — свет + все сценарии |
| **Через ярлыки** | Ярлык на сущностях | Удобно добавлять по одному устройству |

**Одновременно два способа нельзя** — выберите один в настройках интеграции.

## 8. Не работает — чеклист

| Симптом | Что сделать |
|---------|-------------|
| В Алисе только сценарии, нет света | Включить YAML-фильтр + деплой `empire_vannaya_dimmer_fix.yaml` + `yandex_smart_home.reload` + обновить УДЯ |
| Сценарий в приложении есть, в HA тишина | Другой Яндекс-аккаунт; перепривязать интеграцию |
| В HA работает, в Алисе нет | Обновить устройства Yaha Cloud; проверить интернет на armbian |
| «Включи свет» — не тот результат | В Алисе отдан **сырой** диммер → убрать, оставить `light.empire_vannaya_svet` |
| Свет всегда горит, датчик молчит | Инверсия / настенный ключ — `docs/HA_DIMMER_INVERT.md` |
| Долго думает и ошибка | Норма до ~5 с; при Starline-подобных — `slow: true` в entity_config |
| Дубликаты устройств в УДЯ | Удалить лишнее в приложении; одна интеграция HA; при необходимости отвязать навык и привязать снова |

**Отвязка навыка** (если насоздавали лишнего): Дом с Алисой → Yaha Cloud → отвязать с «Удалить устройства» → снова привязать HA.

## Часть 9. Добавление новых устройств позже

1. Подключить в HA (ZHA / LocalTuya), задать **Область**.  
2. Добавить entity в `yandex_smart_home.yaml` → `filter.include_entities` и `entity_config` (имя + комната).  
3. Перезагрузка YAML → `yandex_smart_home.reload` → обновить УДЯ.

**ИК-лампы** (гостевая, Макс): не `light` с % — отдельные **script**-сценарии, см. `docs/HA_YANDEX_IR_ALICE.md`.
