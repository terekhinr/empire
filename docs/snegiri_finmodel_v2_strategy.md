## 1. Эталоны: интернет, курс, тренер

### 1.1. «Скачать разборы из интернета»

**Техника:** CV (MediaPipe) сравнивает **углы скелета пользователя** с правилами или с кадрами эталона. Нужны: одинаковый ракурс (CAM-A/B из shot list), те же варианты упражнения (correct / error-sag / error-back), стабильная одежда.

**Проблемы:**

| Риск | Детали |
|------|--------|
| **Авторское право** | Чужие ролики YouTube/VK — нельзя копировать в коммерческое приложение без лицензии. «Образовательное использование» ≠ SaaS с подпиской. |
| **Качество CV** | Разные камеры, кроп, FPS → точность падает; калибровка на «зоопарк» роликов дороже, чем 42 своих клипа. |
| **Маркетинг** | На лендинге «разбор от нейросети» без лица эксперта — конверсия как в сценарии **F** (CAC 1 500–2 000 ₽). |
| **McGill** | «Big 3 по мотивам Макгилла» — trademark; нельзя выдавать чужие ролики за методику McGill. |

**Вердикт:** использовать для **внутренней отладки алгоритма**, не для релиза. Минимум для prod — **лицензированные** эталоны (см. §3).

---

### 1.2. Купить онлайн-курс тренера

**Плюсы:** готовые ракурсы, единый стиль, иногда **дешевле съёмки** (50–150k ₽ за пакет + переговоры).

**Минусы:**

- Стандартная оферта курса = **личное использование**, не «встроить в AI и продавать подписку».
- Нужен **доп. пункт договора:** бессрочная лicense на извлечение поз/углов для автоматического сравнения; право хранить фрагменты на сервере; **без** перепродажи полных видео клиенту (если не хотите конкурировать с курсом).

**Вердикт:** **рабочий путь**, если тренер продаёт не «курс пользователю», а **«лицензию на biomechanical reference pack»** (15–40k ₽ разово или включено в RevShare). Пользователю по-прежнему показываем только **оценку**, не весь курс.

---

### 1.3. Участие тренера без новой съёмки (RevShare / амбassador)

Это **дешевле и масштабнее** для GTM, но **не заменяет** эталонный слой для CV.

| Роль тренера | Что даёт | CAPEX | Ваш COGS/мес |
|--------------|----------|-------|--------------|
| **A. Лицензия на уже существующие ролики** (YouTube, школа) | Эталоны + имя на сайте | **0–40k ₽** (разово) | RevShare 20–25% |
| **B. Только промо** (посты, промокод, имя) | Трафик, доверие | **0 ₽** | RevShare 25–30% |
| **C. Методический совет** (1 созвон/мес, правки программы) | Программа, FAQ | **5–15k ₽/мес** | фикс |
| **D. Новая съёмка 42 клипа** (старый K0) | Максимум качества CV + PR | **85–130k ₽** | RevShare 20–25% |

**Рекомендация v2:** **B + минимальный эталон L** (§3.2), не D на старте.

**YouTube-ролики тренера:** публикация на YouTube **не** даёт вам права встраивать в приложение. Нужно **письменное согласие** + договор (вариант A). На лендинге можно **embed/link** без копирования файла.

## 2. Что видит пользователь vs что нужно системе

Вы поняли верно **для MVP UI:**

```
Пользователь → снимает подход → получает:
  • оценка 1–10
  • «таз провисает» / «спина ок»
  • кадр СВОЕГО видео (опционально со скелетом)
```

**Эталонное видео тренера в UI — опционально** (блок «как должно быть» в v0.2). Для алгоритма эталон нужен **на сервере** (углы по кадрам или rule-based пороги, откалиброванные по 5–10 эталонным клипам на упражнение).

**Итог:** можно **не показывать** чужие/тренерские видео пользователю и всё равно иметь лицензию на **использование в CV-pipeline** — это дешевле юридически (не конкурируете с их курсом в UI).

| **LICENSE** | Лицензия на 20–40 уже снятых клипов + имя | **25–50k ₽** | 20% | школа с архивом |
| **STUDIO** | Новая съёмка по shot list + эксклюзив на 12 мес | **80–120k ₽** | 15–20% | топ, 50k+ |

Обновить письма: [`snegiri_trainers_outreach.md`](snegiri_trainers_outreach.md) — добавить **START** и **LICENSE** выше **STUDIO**.

### 3.2. Минимальный эталон без тренера (bootstrap)

Если K0 «нет договора» ослабить до «нет **LICENSE/START** партнёра»:

| Источник | Стоимость | Упражнения |
|----------|-----------|------------|
| Самосъёмка заказчика + 1 знакомый (м/ж) | **0 ₽** | 6×2 ракурса = 12 клипов |
| Rule-based CV (уже в коде) | 0 ₽ | side_plank, swing |
| + LICENSE 12 клипов у тренера позже | 15–25k ₽ | полный набор |

**42 клипа → 12 «must-have» для MVP:**

- S2, S3, K1 — correct + 1 error × CAM-B = **12 файлов**

Этого хватит для **beta и первых 200 платящих**, если честно писать «beta · уточняем алгоритм».

### 4.4. Риск «тонкого каталога» (churn)

Текущий MVP: **McGill × 4 нед + 3 гиры × 2 нед**. Пользователь **выучивает паттерны за 6–8 нед** → мотив «я уже знаю, зачем платить» → **churn 12–15%** с 3-го месяца, **LTV ~3–4 мес** (не 6–9 из таблицы выше).

| Каталог | Churn (реалист.) | LTV (мес) | LTV ₽ @480 |
|---------|------------------|-----------|------------|
| 3 гиры | 12–15% | 3–4 | 1 440–1 920 |
| Лестница 16+ паттернов, 24+ нед | 5–6% | 8–12 | 3 840–5 760 |
| + годовой тариф 40% mix | 4–5% | 10–14 | 5 500–7 700 |

**Действие:** расширение программы — не «nice to have», а **условие сходимости L/CAC**. Спека: [`snegiri_program_retention_v1.md`](snegiri_program_retention_v1.md), промпт Gemini: [`snegiri_program_gemini_prompt.md`](snegiri_program_gemini_prompt.md).

**Рекомендация:** целиться в **L (License)** — переговоры «используйте ваши уже снятые ролики + 20% с промокода», CAPEX **~50k ₽**, break-even **~4 месяца** при одном партнёре 20–40k подписчиков.

## 5. Продукт v2 — ваши пункты + предложения

### 5.1. Регистрация (RU)

| Метод | Приоритет | Примечание |
|-------|-----------|------------|
| **Email** (код на почту) | MVP | только `.ru` TLD + белый список: mail.ru, yandex.ru, bk.ru, inbox.ru, list.ru, rambler.ru |
| **VK ID** | MVP | OAuth, основной social |
| **Yandex ID** | MVP | OAuth |
| **Mail.ru** | MVP | OAuth |
| Google / Apple | **не в RU MVP** | блок или «скоро» |

Импортные домены: **не блокировать жёстко** (диаспора), но **не рекламировать**; опционально captcha + «рекомендуем Яндекс-почту».

### 5.2. Онбординг — расширенный профиль

| Поле | Зачем |
|------|-------|
| **Пол** | нормы углов/амплитуды, питание v0.2 |
| **Рост, вес, талия** | BMI, дневник, LLM-план |
| **Возраст** (опционально) | recovery, не медицина |
| **Цель** | похудеть / масса / техника / выносливость |
| **Опыт** | новичок / 1–2 года / 3+ |
| **Инвентарь** | гири: произвольный вес (8–32 кг) + «нет гири» |
| **Трек по умолчанию** | см. §5.3 |

### 5.3. McGill vs гири — политика доступа

**Ваш запрос:** сразу к гирям, любой вес.

**Предложение (безопасность + конверсия):**

```
При выборе «Только гиря»:
  1. Дисклеймер: «без острой боли в спине»
  2. Чекбокс: «Спина в порядке, пропускаю блок McGill»
  3. Мини-тест: bird-dog 30 сек (1 бесплатный CV) — не блокер, но warning если score <5
  4. Трек K открыт сразу; вес гири — любой из списка (8–32)
  5. В приложении баннер: «Рекомендуем 2 недели трека S» (можно закрыть)
```

**Трек S** остаётся **рекомендуемым по умолчанию** для goal «оба» и «спина».

**Программа K:** прогрессия от **выбранного веса** (не фикс 16/24): свинг — reps по % от max test (опрос «сколько повторов 10 мин comfortably»).

### 5.4. Дневник тренировок

| Функция | MVP v1.1 | v0.2 |
|---------|----------|------|
| День / упражнение / ✓ | ✅ есть | — |
| **Оценка CV по подходу** | ✅ | график |
| **Вес, талия** | ✅ | — |
| **Объём** (подходы×сек/повторы) | добавить | — |
| **Регресс** (7 дней без тренировки → −10% hold) | добавить | push/email |
| **Прогресс** (3 недели score ≥7 → +hold/reps) | добавить | — |
| Экспорт PDF | — | v0.2 |

Формула регресса (простая): если `daysSinceLastWorkout > 7` → следующий день **−1 ступень** прогрессии (не ниже week-1).

### 5.5. Питание / калории

**Не в MVP v1** — в ТЗ уже **R5 / v0.2**. Зависит от пол + цель + вес; OpenRouter ~15 ₽/активный/мес. Запуск после **100 платящих RU**.
