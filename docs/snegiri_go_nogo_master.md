# Снегири · GO / NO-GO · мастер-рамка решения

**Дата:** июль 2026 · **статус:** решение не принято — нужна финмодель v3 с Gemini и 2–4 недели валидации, не ещё 3 месяца разработки.

**Контекст:** ~3 дня уже вложено (лендинг, PWA v1, программа v2, позиционирование). Вопрос не «как назвать», а **имеет ли смысл продолжать вообще** и **что минимально нужно**, чтобы это понять.

---

## 1. Бренд: Снегири остаются (решение)

| Аргумент Gemini «переименовать» | Твой контраргумент | Вердикт |
|--------------------------------|-------------------|---------|
| «Милота vs brutal» | Визуал ч/б + #FF3300 + голос Штерна **переопределяют** шутку; птица — крючок, не wellness | **Оставить** |
| «Нет SEO по снегирям» | SEO идёт через «гира дома», «боль в спине», «разбор техники» — **в meta**, не в названии | **Оставить** |
| «Точка жёсткости звучит экспертнее» | Таких названий сотни; **снегирей нет нигде** — это moat в памяти | **Оставить** |
| Домен/канал/Дзен уже есть | Rebrand = выбросить актив | **Не трогать** |

**Позиционирование (формула):**

> **Снегири не гири** — запоминающаяся шутка из куплета + школа **Штерна** (суровый голос, McGill → гиря).  
> Продукт продаёт не «милая птица», а **«шутка, за которой стоит жёсткая биомеханика и ИИ-разбор»**.

Rebrand на «Точку жёсткости» и аналоги — **закрыт**.

## 2. Что было не так со старыми финмоделями

Старые модели ([`snegiri_finmodel_gemini.md`](snegiri_finmodel_gemini.md), v2) **оптимистичны**, потому что **не моделировали бизнес целиком**:

| Проблема | Что игнорировали | Последствие |
|----------|------------------|-------------|
| **Каталог** | 3 гири × 2 нед → churn 12–15% | LTV ~2k ₽, не 4–8k |
| **Маркетинг** | «50k аудитории тренера дадут 0.5%» без воронки | M1 = фантазия |
| **Контент-машина** | TG мало подписчиков, Дзен, YouTube с нуля | CAC ≈ 0 только **если** есть ритм публикаций |
| **Время основателя** | 3+ дня dev + будущие часы = opportunity cost | Не в P&L |
| **Штерн как актив** | Канал Stern уже есть; Snegiri — отдельный продукт | Нужна связка или два бренда? |
| **Книга** | Модель Цацулина (книга → доверие → продукт) | Не оценена |
| **CV реальность** | Rule-based stub, не точность % | Обещания на лендинге > продукта |
| **Юридика** | McGill trademark, LICENSE эталонов | Риск стопа |
| **Kill-metrics** | K0 «договор с тренером» размыт | Нет чёткого STOP |

**Вывод:** старые цифры «окупаемость за 2 месяца» — **не для принятия решения**. Нужна **finmodel v3** (промпт ниже).

## 4. Маркeting flywheel (без paid до валидации)

```
Штерн TG / Дзен / VK (лонгриды, боль спины)
        ↓
Снегири TG (мем + продукт + кейсы разборов)
        ↓
Лендинг → 1 бесплатный разбор → trial
        ↓
Удержание программой 6–12 мес (v2)
```

| Канал | Роль | Сейчас | Нужно для GO |
|-------|------|--------|--------------|
| **TG Штерн** | Доверие, экспертиза | есть | 2 поста/нед → ссылка на Snegiri |
| **TG Снегири** | Продукт, мем | мало subs | 3 поста/нед, не дубль Stern |
| **Дзен** | SEO, лонгриды | есть | 1 статья/2 нед «гира + спина» |
| **VK** | Репост Дзен | опционально | если есть время |
| **YouTube** | Короткие разборы 60 сек | нет | **не блокер** для GO; фаза 2 |
| **Paid таргет** | Масштаб | — | **только после** 30 платящих organic |

**Книга (модель Цацулина):**

| За | Против |
|----|--------|
| Доверие, SEO, lead magnet | 3–6 мес работы, не быстрый cash |
| «Школа Штерна» в обложке | Конкурирует с подпиской, если бесплатно всё |

**Рекомендация:** книга = **фаза 2** (месяц 6+), если organic conversion > 1%. До GO — **PDF «5 ошибок свинга»** на email (lead magnet за 2 дня).

## 6. GO / NO-GO критерии (жёсткие)

### GO (продолжаем серьёзно), если к **01.11.2026**:

| Метрика | Порог |
|---------|-------|
| Платящие (cumulative) | **≥ 30** |
| MRR | **≥ 15 000 ₽** |
| Churn месяц 2–3 | **≤ 10%** |
| Free → paid | **≥ 3%** |
| Контент: Stern+Snegiri | **≥ 8 постов/мес** стабильно |
| LICENSE или эталоны | **≥ 1** договор или 10 клипов |

### PIVOT, если:

- 10–29 платящих, churn высокий → **упростить** (только трек S или только swing CV)
- Конверсия есть, CV слабый → **продавать программу + видео-разбор текстом**, не «AI magic»

### NO-GO (остановить paid, заморозить dev), если к **01.11.2026**:

| Условие |
|---------|
| **< 10 платящих** при ≥ 500 визитов на app |
| **0** LICENSE/эталон и CV остаётся stub |
| **< 4 постов/мес** — нет GTM дисциплины |
| Finmodel v3 показывает **LTV/CAC < 1** даже в base case |

**Sunk cost 3 дня:** не аргумент продолжать. Аргумент — **дешёвая проверка** §5 за 2–4 нед.

## 8. Позиционирование (финальное, под бренд)

**One-liner:** Снегири не гири — шутка, за которой школа Штерна ставит спину и гирю по биомеханике, а ИИ ловит твои ошибки на видео.

**Vs YouTube:** не «ещё один курс», а **разбор ТВОЕГО подхода** + лестница на год.

**Vs generic «биомеханика»:** **запоминающееся имя + голос Штерна + мем**.

**Trust:** методология (McGill/SF) + математика CV — **без фейковых лиц**; цитаты тренеров E-tier **после** договоров.
