## Почему повторялось (до 2026-06-07)

| Проблема | Было | Сейчас |
|----------|------|--------|
| **Короткий цикл** | 7 дней × 2 варианта → та же тема каждые 2 недели | **3–4 варианта** на слот |
| **Пн 21:00 байка** | Одна строка «История перед сном» (8 раз в истории) | **4 разных задания** байки |
| **Классика 15:00** | Сброс пула после 60 id → автор мог вернуться через ~2 мес. | **Cooldown 56 дней** на каждый id (`last_by_id`) |
| **Выбор варианта** | Lookback 14 дней | **28 дней** для gdepar + штраф за точное совпадение topic |

## Механизмы разнообразия

1. **11:00 / 21:00 (LLM)** — `_pick_least_similar_variant`: семейства из `data/gdepar_angle_families.json`, память тем 30 дней, self-critic на клише.
2. **15:00 (классика)** — 160 цитат в `data/gdepar_classic_banya.json`, ротация без повтора id **56 дней**.
3. **Пн 11:00** — 3 текста промо в `data/gdepar_promo_copy.json` (случайный).

## Цикл без повтора тем LLM

- **21 уникальный слот** в неделю (11 + 21), у каждого **3–4 seed-темы** → **~70** разных заголовков до полного цикла (≈10 недель при равномерном выборе).
- Классика: **160** выпусков ≈ **23 недели** ежедневных постов без повтора автора/фрагмента.
