# Google Drive · почему ссылка не открывается на телефоне

## Что вы видите

```text
http://127.0.0.1:53682/auth?state=...
Waiting for code...
```

**127.0.0.1** = «этот же компьютер». Ссылка указывает на **VPS**, не на интернет.  
Телефон не имеет доступа к внутреннему адресу сервера → **на телефоне не откроется**. Это нормально, не ваша ошибка.

---

## Что делать (ПК, не телефон)

Терминал **не закрывать** — он ждёт, пока вы войдёте в Google.

### Способ 1 · Cursor (удобнее)

1. Терминал VPS: скрипт ждёт, в логе есть `127.0.0.1:53682` (порт может быть другой — смотрите в ссылке).
2. В Cursor: панель **Ports** / **Порты** (снизу, рядом с Terminal).
3. **Forward port** → введите **число порта** из ссылки (например `53682`).
4. На **ПК** в Chrome откройте **ту же ссылку** из терминала целиком.
5. Войти в Google → **Разрешить**.
6. В терминале VPS должно продолжиться само (исчезнет `Waiting for code…`).

### Способ 2 · PowerShell на Windows

**Второе** окно PowerShell (первое с VPS не трогать):

```powershell
ssh -L 53682:127.0.0.1:53682 root@moderate-amethys
```

(замените `53682` на порт из вашей ссылки)

Окно не закрывать. Ссылку `http://127.0.0.1:53682/auth?...` открыть в Chrome **на ПК**.

## Карта «где что»

| Место | Роль |
|-------|------|
| **Терминал `root@moderate-amethys`** | VPS, скрипт ждёт |
| **Телефон** | только диктофон → Google Drive, **не** для этой ссылки |
| **Chrome на ПК** | открыть `127.0.0.1:…` **после** проброса порта |
| **Obsidian на ПК** | смотреть готовые заметки потом |
