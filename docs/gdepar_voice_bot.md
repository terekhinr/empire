**Статус:** справка на будущее (июнь 2026). **Не в приоритете Q3–Q4 26.**  
**Связь:** `docs/gdepar_cpa_deposit.md`, `docs/gdepar_ai_assistant_tz.md`, `docs/audit/05_FINANCIAL_MODEL.md`, `scripts/empire_finance_simulator.py`

## 1. Зачем и когда

Голосовой бот **не заменяет** текстового помощника «Пар?» и **не стартует** до работающего коллтрека и первых CPA-депозитов.

| Период | Действие |
|--------|----------|
| **Июн–сен 26** | Ничего голосового — каталог, «Пар?», метрики |
| **Окт–дек 26** | Коллтрек + триал CPA; усилить **анти-IVR** в webhook (`billsec`, `disposition`) |
| **Янв–мар 27** | Callback-виджет («перезвоните») — opt-in, без холода |
| **Апр 27+** | Скриптовый пре-квалификатор на входящий — опция Premium |
| **Не в год 1** | Массовый холодный AI-обзвон бань |

**Код коллтрека:** `tools/cpa_trial.py`, `POST /api/banya/calltrack`  
**Текстовый ассистент:** `POST /api/gdepar/assistant` — дешевле и уже в проде.

## 2. Сценарии использования (сравнение)

| # | Сценарий | Для кого | Сложность | ROI год 1 | Рекомендация |

### 4.2. Переменные

| Компонент | Ориентир |
|-----------|----------|
| SIP + платформа | 0,5–2 ₽/мин |
| STT + TTS (Yandex SpeechKit) | 2–6 ₽/мин |
| LLM (если диалог) | 1–5 ₽/мин |
| **Итого AI-бот** | **~5–15 ₽/мин** |

### 4.3. Примеры месяца

| Объём | Только скрипт | С LLM |
|-------|---------------|-------|
| 50 звонков × 1,5 мин | ~500–1 500 ₽ | ~2 000–4 000 ₽ |
| 200 × 2 мин | ~2 000–4 000 ₽ | ~8 000–15 000 ₽ |
| 500 × 2 мин | ~5 000–8 000 ₽ | ~20 000–40 000 ₽ |

**Правило:** один зачтённый CPA-звонок = **400 ₽** выручки. Бот на 2 мин ≈ **10–30 ₽** — ок, если звонок реальный; бот «крутит» 90 сек без человека — **убыток и споры** (админ CPA **6–12 ч/нед**).

## 5. Плюсы и минусы

### Плюсы

- 24/7 приём входящего с карточки
- Пре-квалификация (дата, гости) → выше ценность депозита для бани
- Фильтр «свободно?» &lt; 45 сек — меньше оспариваний
- Дифференциатор Premium («умный приём»)
- Масштаб обзвона без вашего голоса (но конверсия B2B всё равно **1–2%**)

### Минусы

- Ложный `billsec` → триал сгорает, баня оспаривает
- Доверие: баня хочет живого клиента
- Холод без opt-in — жалобы, блокировки
- Отвлечение от Q4 (Директ + депозиты)
- STT на шумных линиях хуже тишины
- Голос дороже чата «Пар?» (~3 ₽/запрос LLM)

## 6. Механика в схеме заработка

```text
Директ/SEO → gdepar.ru + «Пар?» → клик «Позвонить»
    → коллтрек (подменный номер)
    → [опционально: бот 30–60 сек] → баня
    → webhook calltrack (billsec, disposition)
    → триал 3 звонка / депозит 4k / Premium 2990
```

| Этап плана | Роль бота |
|------------|-----------|
| Окт–дек 26, триал CPA | Не зачислять IVR/автоответчик; короткие «свободно?» — отдельная метрика |
| После 3 звонков → блок | TG-отчёт без изменений; бот влияет на **качество** |
| Депозит 4k | Баня платит за реальных клиентов |
| Premium 2990 | Опция «умный приём» / callback / CRM |
| Директ CPL 400–450 | Бот не снижает CPL; может поднять долю billable с **35%** до **38–40%** |
| Пенсия 50/50 | Голос **только** ветка Где Пар |

**Каналы дополняют друг друга:**

| Канал | Когда | ~Стоимость | Метрика |
|-------|-------|------------|---------|
| Чат «Пар?» | До звонка | ~3 ₽/запрос | `assistant → phone_click` |
| Голос | После решения позвонить | ~10–30 ₽/звонок | `phone → billsec ≥ 90` |

## 7. Финансовая модель (сценарии Δ к базе)

База: `05_FINANCIAL_MODEL.md`, симулятор `scripts/empire_finance_simulator.py`.

| Сценарий | Механика | Δ выручка/год | Δ расход | **Δ net** |
|----------|----------|---------------|----------|-----------|
| Пессимизм | Бот = IVR, споры, отток | −20…−50k | +15k | **−35…−65k** |
| База | Анти-IVR + callback, без LLM | +15…+30k | +8k | **+7…+22k** |
| Оптимизм | +5% phone→billable, скрипт | +40…+80k | +25k | **+15…+55k** |

**Май 27 (стабильная фаза):** без бота ~36k Где Пар; с ботом (база) ~38–40k; оптимизм ~42–48k.  
**Год 1:** прирост **+5–15%** к ветке Где Пар — не удвоение.

### Строки P&L (когда включать)

| Статья | ₽/мес | С какого месяца |
|--------|-------|-----------------|
| `voice_platform` | 2 000–3 000 | **фев 27+** (не раньше 2 депозитов CPA) |
| `voice_variable` | 5–15 ₽ × billable_calls | там же |
| `voice_dev_amort` | 0 (свой код) | разово при старте |
| Premium voice addon (опц.) | +500–1 000 к Premium | апр 27+ |

**Включать в cashflow только после:** ≥2 оплаченных CPA-депозита и стабильного коллтрека.

## 9. Чеклист внедрения (когда дойдёте)

- [ ] Коллтрек стабилен ≥30 дней, ≥10 billable звонков
- [ ] ≥2 депозита по 4k — доказательство CPA
- [ ] Анти-IVR в `qualify_call` / отчётах (короткие, `NO ANSWER`, автоответчик)
- [ ] Callback-виджет на gdepar (opt-in, Метрика `gdepar_callback_request`)
- [ ] Выбор провайдера voice API (Mango vs Voximplant)
- [ ] MVP скрипт: приветствие → дата/гости → перевод на баню
- [ ] `billsec` считать **после** соединения с баней, не во время бота (иначе споры)
- [ ] A/B: с ботом / без — CR `phone_click → billsec≥90`
- [ ] Premium-опция в `/partners` и прайсе

## 10. Симулятор

Базовый сценарий **без** голоса (как R3):

```bash
./venv/bin/python scripts/empire_finance_simulator.py
```

Сценарий «voice с фев 27»:

```bash
./venv/bin/python scripts/empire_finance_simulator.py \
  --voice-from 8 \
  --voice-platform 2500 \
  --voice-per-call 15 \
  --voice-call-uplift 0.05
```

Параметры: `--voice-from` — индекс месяца (0=июн 26, 8=фев 27), `--voice-platform`, `--voice-per-call`, `--voice-call-uplift` (доля, напр. 0.05 = +5% к call_rate).
