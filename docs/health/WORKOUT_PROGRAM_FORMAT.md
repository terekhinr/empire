# Файл программы тренировок (v1)

Канонический формат: **JSON** (или YAML). Схема: `empire-workout-program/v1`.

Зачем: программу пишет тренер / вы сами **один раз**, загружаете в Зал, дальше только лог подходов. ИИ для составления цикла больше не нужен.

Пример: `docs/health/examples/full_body_3day.json`.

В приложении: **Программа → Загрузить файл**. На VPS файлы лежат в `data/health/programs/{id}.json`.

## Минимальный JSON

```json
{
  "schema": "empire-workout-program/v1",
  "id": "my_cycle",
  "title": "Мой цикл",
  "short": "Цикл",
  "note_prefix": "подход",
  "weekdays": ["mon", "wed", "fri"],
  "rolling_sessions": 12,
  "phases": [
    {
      "id": 1,
      "title": "Фаза 1",
      "days": [
        {
          "id": "A",
          "title": "Сила",
          "exercises": [
            {
              "key": "жим_штанги_лежа",
              "name": "Жим штанги лёжа",
              "sets": 4,
              "reps": [4, 6],
              "weight_kg": 100,
              "rest_sec": 180,
              "notes": "запас 1 повтор"
            }
          ]
        }
      ]
    }
  ]
}
```

## Поля

| Поле | Обязательно | Смысл |
|------|-------------|--------|
| `schema` | да | всегда `empire-workout-program/v1` |
| `id` | да | латиница, цифры, `_`, 2–41 символ. Нельзя: `gym_2026`, `outside_hall` |
| `title` / `short` | да / нет | полное имя и чип в переключателе |
| `note_prefix` | нет | префикс заметки в логе (`подход 1/4`). Разные программы — разные префиксы, логи не смешиваются |
| `weekdays` | нет | дни слотов. `["mon","wed","fri"]` или `[0,2,4]` (пн=0) |
| `rolling_sessions` | нет | сколько тренировок накрутить от даты старта, циклируя дни A/B/C… |
| `calendar` | нет | явные даты `[{ "on":"2026-09-07", "phase":1, "day":"A" }]` |
| `phases[].days[].id` | да | `A`…`G` |
| `exercises[].key` | да | стабильный ключ (`snake_case` или кириллица с `_`) |
| `exercises[].name` | нет | подпись; неизвестный `key` попадёт в каталог упражнений |
| `sets` / `reps` | да / как надо | `reps`: число, `[мин, макс]` или `"max"` |
| `weight_kg` | нет | число или `[от, до]` (в лог подставится середина) |
| `hold_sec` + `is_time_hold` | нет | планка и удержания — лог в секундах |
| `rest_sec` / `notes` | нет | подсказка в карточке |

Ключ `отдых` — не пишется в силовые логи.

## Markdown (старый формат)

Файлы `docs/health/workout_program_*.md` по-прежнему читаются как встроенные программы. Их тоже можно загрузить: сервер конвертирует в v1 JSON.

## Бэкап

`scripts/health_backup.sh` копирует `health.db` и `data/health/programs/` в `data/health/backups/`. В приложении: **Статистика / Замеры** не нужны — кнопка «Скачать бэкап» на экране программы.
