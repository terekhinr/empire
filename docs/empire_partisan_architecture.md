# Партизанщина по персонам (целевая модель)

**Не путать:** одна вкладка «Разведка» в дашборде ≠ один сценарий для всех. У каждой персоны свой контур.

## Сводка

| Персона | Вход | Действие Empire | Выход |
|---------|------|-----------------|--------|
| **Pension** | RSS / таблица `news` | Лента заголовков → **вы** выбираете новость | Разбор голосами → публикация |
| **Gdepar** | Spy: взлётевшие **посты** конкурентов | Переработка → слот в **обычной сетке** автопоста | Пост Михалыча |
| **Stern** | Spy: взлётевшие **посты** конкурентов | То же | Пост Штерна |
| **Gdepar/Stern video** | Spy: взлётевший **видео**-контент | Сценарий Shorts + длинное видео (Stern); Shorts (Gdepar — опционально) | Съёмка вручную |

**Нейрокомментинг** — отдельный рычаг роста в чужих TG-каналах, **не** часть редакции Pension и **не** замена spy-постов.

---

## 1. Pension (главный проект)

```
RSS ingest → news
    → автопост [RAW] = только заголовки (без «воды»)
    → дашборд «Пенсия · новости»
         → выбор 1–2 новостей
         → голоса: Антонов | Марков | Кримсон | Талеб (мультивыбор)
         → [ANALYSIS] → LLM + KB → черновик → approve → TG / сайт / Дзен
```

- **Не** подмешивать spy конкурентов в pension-посты по умолчанию.
- `spy_competitors.json` для pension — опционально (наблюдение), не автосетка.

---

## 2. Gdepar / Stern (текстовые посты)

```
Telethon Spy → spy_signals (persona=gdepar|stern)
    → топ по anomaly_score за 7 дней
    → слот расписания type: spy_inspired ИЛИ кнопка в дашборде
    → LLM: новый угол, не копия, полевой тест Михалыча/Штерна
    → pending → approve → TG (позже VK+Дзен)
```

- Взлётевший пост конкурента = **тема**, не текст для копипасты.
- Частота: 1–2 поста/нед на персону (не каждый слот).

---

## 3. Видео (Shorts + длинный ролик)

```
Spy (video / Reels / Shorts ER) → сигнал с kind=video
    → script_factory / shorts_scripts
         → stern: short + outline длинного урока
         → gdepar: short (опционально)
    → съёмка и монтаж — вручную
```

Сейчас `shorts_scripts` — каркас из news; целевое состояние — привязка к **video** spy_signals.

---

## 4. Что было «странного» в дашборде

| Вкладка | Почему казалось «всё для всех» | Как должно быть |
|---------|-------------------------------|-----------------|
| Разведка | Общая таблица всех `persona_key` | Фильтр **Gdepar / Stern**; pension — отдельная вкладка |
| Нейрокомментинг | Глобальный список | Подпись: только рост в TG, не редакция |
| Shorts | Все персоны в одном списке | Фокус stern + gdepar; pension убрать из генерации по умолчанию |
| Пенсия · новости | Новая, но рядом с «разведкой» | Только RSS + голоса, без spy |
