# Weekly Sprint Review · воскресенье

~30–40 мин. Чеклист в Задачнике: **«Карьера · Еженедельный review»** + задача repeat weekly (вс).

Три вопроса (обязательны):

1. Что из плана недели сделано, что провалено?  
2. Какие темы в коде до сих пор не понимаю? → список вопросов ИИ-ментору на пн.  
3. Главная цель на следующие 7 дней (одна).

Дополнительно: % пайплайна на вкладке «Карьера · B2B»; ближайшая КТ; были ли дни семья &lt;4 ч.
