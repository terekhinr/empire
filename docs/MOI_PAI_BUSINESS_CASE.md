## 2. Конкуренты и отстройка

| Игрок | Сила | Слабость | Ход «Мои паи» |
|---|---|---|---|
| **vsezpif.ru + TG ~5.9k** | Живой скринер, Pro, календарь выплат | Мало личности | Не копировать таблицу; ссылаться; свой бренд = портфель |
| **FinDay / Сиденко** | Годовые обзоры всех фондов на YT | Редкость, не дневник | Частота + кейсы сделок |
| **Smart-Lab / Дзен** | Глубокие разовые разборы | Нет воронки и бренда | Серия + клуб + B2B |
| **Сайты УК** | Бюджет, объекты | Нулевое «независимое» доверие | Независимый тон + дисклеймеры |

### Позиционирование (одно предложение)

> **«Мои паи»** — публичный рентный портфель и разборы финмоделей ЗПИФ без индивидуальных рекомендаций; trust-media, не data-terminal.

### Что не делаем

- Второй скринер всех 41 фонда  
- Обещания доходности «как у УК»  
- Массовые Shorts «пассивка 25%»

### Что делаем

1. Дневник портфеля (покупки, выплаты, XIRR, ошибки)  
2. Разбор финмодели 15–20 мин (долг, cap rate, рефинанс, отсечки)  
3. Календарь / алерты как утилита (после аудитории)  
4. Интервью с УК как B2B-воронка

## 3. Юнит-экономика

### 3.1. Формулы

```
Club_revenue_year = paid_members × ARPU × avg_active_months
UK_revenue_year   = deals_per_year × AOV_deal
Other_revenue     = YT/adsense + affiliate + one-off (консервативно)
Total_revenue     = Club + UK + Other

LTV_paid          = ARPU × avg_active_months
CAC_paid          = spend_on_ads / new_paid_members   (только платный канал)
LTV/CAC           = LTV_paid / CAC_paid
Contribution/mo   = ARPU × (1 − variable_cost_ratio)   # variable ~15% (платежи, саппорт)
```

### 3.2. Базовые допущения (до аудита)

| Метрика | Pess | Base | Opt |
|---|---|---|---|
| ARPU клуба, ₽/мес | 1 990 | 2 490 | 2 990 |
| Avg active months / year | 4–5 | 6–7 | 7–8 |
| Free→Paid | ~1.5–2% | ~2.5–3% | ~4% |
| CAC платного подписчика | 500 ₽ | 350 ₽ | 250 ₽ |
| AOV натив УК | 60–80к | 120к | 180–280к |
| Слотов УК / год | 0–2 | 2–6 | 3–8 |

### 3.3. Base Y2 (пример)

- 8 000 TG, 220 платящих, ARPU 2 490, 6 мес → клуб **≈ 3.3 млн ₽**  
- 4 сделки УК × 120к → **0.48 млн**  
- Прочее 0.2 млн  
- **Итого Y2 до аудита ≈ 4.0 млн** ← завышено (см. §6)

**LTV/CAC base:** LTV ≈ 14.9к / CAC 0.35к ≈ **42x** на бумаге — нереалистично красиво, потому что CAC не включает время основателя и органика доминирует. Для решений использовать **полный cost per paid** ≥ 2–5к (время+реклама).

## 6. Критический аудит собственных расчётов

### 6.1. Что завышено

1. **Аудитория Y3 base 14k** — vsezpif ~6k за годы; без вирусного чуда потолок ближе к **8k**.  
2. **Клуб 220 платящих × 6 мес в Y2** — даёт ~3.3 млн только с подписки; для узкой темы конверсия часто **1%**, не 2.75%. При 1% и 8k → 80 платящих → клуб ~1.2 млн.  
3. **LTV/CAC 40x** — игнорирует труд основателя; экономически бессмысленно.  
4. **UK AOV 120к × 4** — зависит от личных продаж; в Y1–Y2 реалистичнее **1–2 сделки**.  
5. **Opex без зарплаты** — при 150к/мес основателя base Y2 уходит почти в ноль/минус.

### 6.2. Что занижено / пропущено

1. Стоимость compliance (маркировка ОРД, юрист по рекламе ЦБ).  
2. Риск блокировки/жалоба на «скрытую ИИР».  
3. Налоги УСН/НДС на услуги.  
4. Churn клуба может быть выше (3–4 мес, не 6–7).

### 6.3. Веса сценариев (экспертно)

| Сценарий | Вероятность | Смысл |
|---|---|---|
| Пессимистичный | **40%** | Хобби + мелкий доход |
| Base × 0.6 | **45%** | Рабочий медиа-побочный бизнес |
| Optimistic | **15%** | Нужны сильный личный бренд + удачные УК-контракты |

### 6.4. Честный коридор (после аудита)

| Год | Выручка (честный base) | Комментарий |
|---|---|---|
| Y1 | **0.3–0.6 млн** | 1 УК-сделка + слабый клуб или без клуба |
| Y2 | **0.8–1.2 млн** | Клуб 80–150 чел + 2–3 натива |
| Y3 | **1.5–2.5 млн** | 5–8k TG, узнаваемость у квалов |

**Решение:** стартовать только пакет A; B — по kill/go метрикам; C — не открывать без отдельного data-MVP и бюджета.

1. Жёстче по Free→Paid и CAC — правильнее для холодного фин-TG.
