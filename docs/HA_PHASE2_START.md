# Фаза 2 — старт (сегодня)

Датчики **присутствия** — позже. Сейчас: ZHA (реле + протечка), LocalTuya (розетки), убрать облако Tuya.

---

## Шаг 0. Файлы на HA (5 мин)

В **File editor** скопировать в `/config/packages/` из репозитория:

- `empire_devices.yaml` (новый)
- `empire_automations.yaml`, `empire_mvp.yaml` — если ещё не обновляли

**Проверка конфигурации** → перезагрузка YAML.

---

## Шаг 1. ZHA — реле и протечка (15–30 мин)

1. **Настройки → Устройства и службы → ZHA → Добавить устройство**.
2. **Реле 1** — режим пейринга на устройстве → дождаться «Найдено».
3. **Реле 2** — то же.
4. **Протечка** — пейринг → **Область: Кухня** (или Ванная).
5. Каждому устройству: **Переименовать** (шестерёнка → Имя), например `Кухня протечка`.

### Протечка → Telegram

1. **Настройки → Автоматизации** → «Протечка — Telegram» → **Изменить в YAML**.
2. Заменить `binary_sensor.zamena_posle_zha` на ваш entity (например `binary_sensor.kuhnya_protecka`).
3. Включить автоматизацию (**enabled: true**).
4. Тест: положить каплю воды / кнопка теста на датчике → сообщение в Telegram.

---

## Шаг 2. Tuya Cloud — ключи, потом удалить

**Сначала** получить `local_key` для розеток (пока облако есть или через [Tuya IoT](https://platform.tuya.com/) + tinytuya).

Когда ключи сохранены:

1. **Настройки → Устройства → Tuya** → **Удалить** (`setup_error` всё равно не работает).
2. Перезагрузка HA.

---

## Шаг 3. LocalTuya — 2 розетки

1. **HACS** → Integrations → **Local Tuya** → Install (если нет).
2. **Настройки → Устройства → Добавить интеграцию → LocalTuya**.
3. Розетка **чайник**:
   - IP (закрепить в роутере)
   - Device ID, Local Key, версия 3.3/3.4
   - **Область: Кухня**
4. Розетка **мультиварка** → **Область: Балкон**.
5. Проверка **без интернета** (только Wi‑Fi LAN): вкл/выкл из HA.

### Группа «отпуск»

**Настройки → Группы → Техника — выкл. в отпуске** → добавить обе розетки.

Включить **Режим Отпуск** — розетки должны выключиться.
