## P0 — владелец сказал «не работает», приёмки нет

### 1. Задачник и «Личный Практикум» на телефоне

**Ожидание владельца.** Как Яндекс Практикум: открыл на Android → нажал «продолжить» → урок → галочки → прогресс и даты. Завтра нужен на тренировке. APK не ставил и не хочет: рабочая поверхность — PWA в браузере.

**Что сделано и не принято.**
- Много входов: `/x/` (SPA), `/tasks/` (старый, Service Worker часто даёт чёрный экран), `/go/`, `/go-tasks/`, `/go-learn/`, `/gym/`, `/go-reset/`.
- 2026-10-22 агент записал вердикт: prefix `/tasks-*` больше не должен отдавать `Not Found`, recover ведёт на `/x/`, APP_VER 86. Файл: `docs/zadachnik_fix_prompt_2026-10-22.md`.
- Курс описан как LMS на `https://neverretire.ru/go-learn/` (недели, %, Continue).
- Последняя реплика владельца по этому контуру — сарказм: это **не** Практикум, кнопка не ведёт в курс.

**Не решено.**
- Один канонический URL с телефона, который открывается без сброса кэша и без знания про Service Worker.
- Ощущение курса (урок → шаг → «дальше»), а не чеклист задач.
- Привязка прогресса к датам так, чтобы это было видно на тренировке без ПК.

**Проверка, которую агент считал PASS (владелец не подтвердил):** UI ready, splash скрыт, задачи есть, вкладка карьеры открывается, `/go-reset/` ведёт на `/x/`.

### 2. Озвучка книг (Yandex SpeechKit, голос filipp)

**Симптомы, которые владелец присылал уже после правок словаря.**
- «много» читается как «мново».
- Неверные ударения (примеры: «Эдуарда», «отчего» вместо «от чегО», «самоодобренИя» вместо «самоодобрЕния»).
- Частица «то» слипается с предыдущим словом («сказалто»). Вопрос владельца: «когда всё заработает?» — ответа с принятым прогоном нет.

**Что уже есть в коде.** Пайплайн до синтеза: clean → алиасы → числа → silero-stress → словарь `scripts/tts_pronunciation_dict.txt` → SpeechKit. Попытка отделить частицу «то» — `scripts/tts_nsw.py`. Словарь на «самоодобрение» добавлен. Это не закрыло ухо владельца.

**Не решено.** Стабильное произношение на длинном тексте без ручной строки на каждую ошибку; регрессия «то»; способ проверить кусок ухом и сказать PASS/FAIL одной командой.

### 3. Домашний роутер: ИИ, YouTube, Telegram

**Факт от владельца (2026-10-21).** Рабочая схема Flint + podkop + Amnezia `awg0` + VLESS для ИИ, YouTube и Telegram **заморожена**. Агент до этого ломал exit (в том числе уводил не в Вену). Повторная перестройка = поломка дома.

**Открытый вопрос того же дня, без права трогать роутер.** YouTube с дома «хуёво»; хотелось, чтобы ИИ шли через VPN, а YouTube — через podkop/zapret. Аудит качества не доведён до принятого владельцем ответа. Чинить маршрутами нельзя.

**Что считать решённым только по чекпоинту, не по словам владельца.** 2026-10-20: DNS и Telegram на профилях user01–20, Reality Aeza на `:443`, healthcheck YouTube 204 / Telegram 200 с Flint. Мобильный интернет до этого несколько суток «ничего не подключается» при живом домашнем Wi‑Fi. Повторной приёмки с LTE после 20.10 в чатах нет.

**Не делать в ответе Gemini.** Новые SNI, смена exit, рестарт podkop, перенос доменов между `main` и `ai_awg`.
