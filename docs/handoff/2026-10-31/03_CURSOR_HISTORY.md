## 3. Сквозные решения, которые другой ИИ обязан помнить

1. Два флагмана: Пенсия и Где Пар. Сад, Штерн, Ленин — только автопост.
2. HA и VPN — дом и инфра, не новые бизнесы.
3. Код на origin Aeza, сайты снаружи через VDSina. Второй комплект сервисов не поднимать.
4. Метрику не выдумывать.
5. Flint (podkop, awg0, VLESS, FakeIP, списки, exit) заморожен 21.10 после того, как агент ломал exit.
6. Секреты не в git и не в чат.
7. Коммит только по просьбе. Force push / hard reset — только по явной просьбе.
8. Ментор практикума и карьеры не пишет готовое решение за студента, пока не сказали «режим продакшен / просто почини» про уже существующий код Empire.
9. Локальная замена Cursor задумана так: Ollama `qwen2.5-coder:7b` + Roo, рассуждения `deepseek-r1:8b`. Облако — только `[ARCH]` / `[CRITICAL]`.
