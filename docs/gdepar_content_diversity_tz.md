# Доп. ТЗ: контент и разнообразие gdepar (и смежные каналы)

Статус: **внедрено частично в код** (см. ниже). Документ — источник правды для редакторских правок.

**Матрица тем, слоты, картинки, RAG/ИИ:** `docs/gdepar_posting_matrix_2026.md`.

**Сад / огород — 14 рубрик и гибрид с расписанием:** `docs/garden_posting_matrix_2026.md`.

---

## 1. Проблема

Повторяются однотипные посты: тишина в парилке, верхняя полка, «веник на 15 минут», алкоголь + давление + сердце в одном тексте.

## 2. Решение в коде

| Механизм | Файл |
|----------|------|
| Семейства тем + cooldown 14 дней при выборе варианта | `data/gdepar_angle_families.json`, `gdepar_content.py`, `_pick_least_similar_variant` |
| Память тем 30 дней (Jaccard) | `TopicHistory` в `main.py` |
| Анти-клише в промпте gdepar | `generate_draft_content` |
| Расширенные рубрики в расписании | `content_config.json` → `gdepar.topics` |
| Еженедельный промо-пост карты | понедельник 10:00, `type: promo_map` |
| Литература | среда 18:00, `type: literature` |
| Промо-тексты | `data/gdepar_promo_copy.json` |
| Цитаты | `data/gdepar_literature.json` |

### Матрица семейств (не пересекать чаще 1×/2 нед)

| family_id | О чём | Примеры рубрик |
|-----------|--------|----------------|
| `этикет_тишина` | Молчание, психология, детокс | Социальные нормы, не «Тишина в парилке» заголовком |
| `полки_жар` | Полки, заходы, терпеть жар | Эргономика — без «лезь наверх» каждый раз |
| `алкоголь_сердце` | Алкоголь, давление, сердце | Здоровье — раз в 2 недели на слот |
| `веник_банник` | Веники, приметы | Чередовать с инженерией/гастрономией |
| `типы_бань` | Сауна/хамам/русская | История + традиции, не дублировать |

### Новые рубрики (добавлять в `content_config.json`)

- `[Инженерия]` — вентиляция, протяжка, дверь, утепление
- `[Гастрономия]` / `[Рецепты]` — чай, квас, еда к пару
- `[История]` / `[Литература]` — факты и художественные цитаты
- `[Социальные нормы]` — очередь, дети, границы (вместо «медитация/тишина»)
- `[Закаливание]` / `[Ароматерапия]` / `[Косметология]`

Редактор может дописать `variants` в JSON без деплоя `main.py`.

## 3. Литература о бане

**Кто подбирает:** стартовый набор в `data/gdepar_literature.json` (можно править вручную). Агент не заменяет литературоведа — для строгой точности сверяйте с изданием.

**Формат поста:**

1. Заголовок от Михалыча  
2. Цитата в кавычках  
3. Источник: автор, произведение  
4. 2–3 предложения комментария без морализаторства  
5. Хэштеги, без клише из §2  

**Добавить цитату:** объект в `quotes[]` с полями `id`, `author`, `work`, `text`, `angle`.

## 4. Промо gdepar.ru / гдепар.рф

- **Слот:** понедельник 10:00 МСК (`promo_map`).  
- **Тексты:** `data/gdepar_promo_copy.json` (3 варианта, ротация).  
- **Ссылка:** с UTM `utm_source=telegram&utm_medium=post&utm_campaign=weekly_map`.  
- **Слоган (основной):** «Где парить рядом — без лишних звонков».

### Аналитика TG → сайт

1. В посте только ссылки с UTM (уже в JSON).  
2. В Я.Метрике: отчёт «Источники» → UTM / переходы с `telegram`.  
3. В `analytics.db`: событие `tg_promo_map_draft` при создании черновика промо.  
4. Опционально: цель `gdepar_map_open` на сайте (см. `docs/metrika_goals_setup.md`).  
5. Сверка раз в неделю: посты с UTM vs визиты на `/map` с тем же `utm_campaign=weekly_map`.

## 5. Ленин: еженедельный «сбор»

- **Слот:** воскресенье 21:00, `type: channel_support`.  
- **Тексты:** `data/lenin_support_copy.json`.  
- **Тон:** ироничный заголовок («фонд победы в одном канале»), по сути — поддержка хостинга и редактора. **Без** призывов к насилию, экстремизма, незаконных действий.  
- **Донат-ссылка:** подключить после бота (§6).
