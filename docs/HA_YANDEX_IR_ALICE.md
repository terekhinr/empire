# ИК-пульт, лампы с пультом и Яндекс Алиса через Home Assistant

**Цель:** все сценарии и голос — через **HA** → навык **Yandex Smart Home** → колонки/ТВ с Алисой.  
**Ваш контекст:** квартира на HA (armbian), локальные устройства (ZHA, LocalTuya, SonoffLAN), колонки Алиса уже есть (по ТЗ).

---

## 1. Как это устроено (схема)

```
Голос «Алиса, …»
    ↓
Яндекс Умный дом (навык HA)
    ↓
Home Assistant (логика, сцены, %)
    ↓
┌─────────────────┬──────────────────┬─────────────────┐
│ light/switch    │ script / scene   │ ИК-шлюз         │
│ (Zigbee/Tuya)   │ (любые сценарии) │ Broadlink и др. │
└─────────────────┴──────────────────┴─────────────────┘
    ↓                    ↓                    ↓
Умная лампа          Автоматизации      ТВ, кондиционер,
точные % и К         «как кнопка        лампа «тупая»
                     пульта»            с ИК-пультом
```

**Главное правило:** для фраз вроде **«50% яркости»** и **«теплый свет 3000K»** нужна сущность **`light`** с реальной яркостью/температурой (Zigbee, Wi‑Fi LocalTuya, не «голый» ИК).

ИК — для устройств **без** обратной связи (большинство ТВ, старые LED-лампы с пультом, приставки).

---

## 2. ИК-шлюз: что купить / поставить

| Модель | Плюсы | HA |
|--------|-------|-----|
| **Broadlink RM4 Pro / RM4 mini** | Обучение пульта, стабильно | Интеграция **Broadlink** (встроенная) |
| **Tuya / Moes IR** | Дёшево | **LocalTuya** или облако |
| **Sonoff RF Bridge 433** | RF, не ИК | SonoffLAN |
| **USB ИК на HA-хост** | Всё локально | `remote`, MQTT |

**Рекомендация для старта:** Broadlink RM4 Pro (ИК + опционально RF) — максимум гайдов и **SmartIR**.

Размещение: один шлюз на комнату 15–25 м² без преград; для 2 зон — 2 шлюза или поворотный RM Pro.

## 3. Подключение ИК-шлюза к Home Assistant

### 3.1 Broadlink (пошагово)

1. Настроить RM в приложении Broadlink (Wi‑Fi **2.4 GHz**), запомнить IP → **DHCP reservation** в роутере.
2. HA → **Настройки** → **Устройства** → **Добавить** → **Broadlink**.
3. Ввести IP (или автообнаружение).
4. Появятся сущности `remote.broadlink_*` и возможность отправлять коды.

**Обучение кода с пульта:**

1. **Настройки** → **Устройства** → Broadlink → **Обучить** (или Developer Tools → Services `remote.learn_command`).
2. Навести пульт на шлюз → нажать кнопку на пульте → имя команды, например `lamp_power`, `lamp_bright_up`.
3. Повторить для всех нужных кнопок.

**Проверка:** Developer Tools → `remote.send_command` с `device` + `command`.

### 3.2 Скрипт = «кнопка пульта»

```yaml
# packages/empire_ir_lamp.yaml (пример)
script:
  lamp_gostevaya_power:
    alias: "Гостевая — питание (ИК)"
    sequence:
      - service: remote.send_command
        target:
          entity_id: remote.broadlink_gostevaya
        data:
          device: lamp
          command: power

  lamp_gostevaya_50:
    alias: "Гостевая — ~50% (ИК, дискретно)"
    sequence:
      - service: remote.send_command
        target:
          entity_id: remote.broadlink_gostevaya
        data:
          device: lamp
          command: brightness_50   # выученный код или цепочка dim
```

Так **дублируете кнопки пульта** один в один.

## 4. Лампы с пультом: что реально через ИК

### 4.1 Ограничения ИК

| Возможность | Умная лампа (light) | Лампа только с ИК-пультом |
|-------------|---------------------|---------------------------|
| Вкл/выкл | ✅ | ✅ |
| «Ярче/тусклее» по шагам | ✅ точный % | ⚠️ только шаги с пульта |
| «50% мощности» | ✅ | ⚠️ только если выучили отдельный код или серия dim |
| Цветовая температура | ✅ K | ⚠️ кнопки «теплее/холоднее» или фикс. режимы |
| RGB | ✅ | ⚠️ режимы с пульта, не «любой цвет» |
| HA знает текущее состояние | ✅ | ❌ часто **не знает** (после ручного пульта рассинхрон) |

**Вывод:** голос **«50 процентов»** и **«4000 кельвинов»** для лампы **с обычным пультом** — делается так:

1. **Лучше:** заменить/добавить **умные** лампы (Zigbee/Tuya Local) в ту же комнату — Алиса через HA даст нормальный `light`.
2. **ИК-обход:** SmartIR + JSON с таблицей яркости/температур (см. ниже) — много ручной работы, состояние «на глаз».
3. **Компромисс:** скрипты `яркость_25`, `яркость_50`, `яркость_100`, `тёплый`, `нейтральный`, `холодный` — голосом вызывать **сцены**, не точные проценты.

### 4.2 SmartIR для лампы (если остаётесь на ИК)

[HACS → SmartIR](https://github.com/smartHomeHub/SmartIR) + Broadlink.

В JSON для `light`:

- `commands.on` / `off`
- `brightness` — список кодов на уровни 1–100% (если пульт так умеет)
- или `brighten` / `dim` — по одному шагу
- `color_temp` — список K или `warmer` / `colder`

Появится `light.smartir_gostevaya` — его уже можно отдавать Алисе (с оговоркой по точности).

### 4.3 Синхронизация состояния (template)

Если лампа только ИК — часто делают **виртуальный** `input_boolean` / `light.template` и сбрасывают при «off» с пульта вручную нельзя отследить → периодически «Включи свет» может не совпасть с реальностью. Для критичных зон — умная лампа предпочтительнее.

## 5. Телевизор через ИК + Алиса

### 5.1 Подключение

1. Обучить: `power`, `volume_up`, `volume_down`, `mute`, `input_hdmi1`, `input_hdmi2`, …
2. Варианты в HA:
   - **remote** + скрипты;
   - **SmartIR** `media_player` для модели ТВ (готовые JSON в сообществе);
   - **Universal Media Player** — объединить ИК + приставку.

### 5.2 Голос через Алису

Фразы типа «Алиса, включи телевизор в гостиной» → в навыке HA сущность должна быть типа **media_player** или **switch/script** с понятным именем.

| Фраза | Реализация в HA |
|-------|----------------|
| Включи ТВ | script → ИК power (toggle осторожно — лучше отдельно on/off если есть) |
| Громче / тише | script → volume_up / down |
| HDMI 2 | script → input_hdmi2 |

**Особенность:** у многих ТВ **power = toggle** — HA не знает, включён ли ТВ. Решение: привязка к **розетке с мониторингом питания** или HDMI CEC (если ТВ поддерживает).

**ТВ с встроенной Алисой:** можно управлять и напрямую, но для **единого дома** удобнее сценарии в HA и один навык.

## 6. Яндекс Алиса ↔ Home Assistant (обязательный блок)

Официальный путь для РФ: интеграция **[Yandex Smart Home](https://github.com/dext0r/yandex_smart_home)** (форк развивается, документация [Yaha Cloud](https://docs.yaha-cloud.ru/)).

### 6.1 Установка

1. **HACS** → репозиторий `https://github.com/dext0r/yandex_smart_home` → установить.
2. Перезагрузка HA.
3. **Настройки** → **Добавить интеграцию** → **Yandex Smart Home**.

### 6.2 Тип подключения

| Режим | Когда |
|-------|--------|
| **Облако (Yaha Cloud)** | Проще, не нужен белый IP/HTTPS на HA |
| **Прямое** | Свой навык, HTTPS на HA — для продвинутых |

Для armbian за NAT обычно **облако**.

### 6.3 Что «увидит» Алиса

В настройках интеграции — фильтр сущностей. В Умный дом попадают (по типу):

| HA | Алиса |
|----|--------|
| `light` (яркость, ct, rgb) | Свет с % и температурой |
| `switch` | Выключатель |
| `cover` | Шторы |
| `climate` | Климат (позже Haier IR) |
| `media_player` | ТВ/колонка (ограниченно) |
| `scene`, `script` | Сценарии («запусти …») |
| `input_boolean` | Иногда как переключатель |

**Имена для голоса:** поле **«Имя в Умном доме»** / `entity_config` — коротко по-русски: «Свет гостиная», «Телевизор», «Ночь».

Пример YAML (фрагмент `configuration.yaml` или UI):

```yaml
yandex_smart_home:
  entity_config:
    light.gostevaya_potolok:
      name: Свет гостиная
      room: Гостевая
    script.lamp_gostevaya_50:
      name: Свет гостиная пятьдесят процентов
      type: scene
```

### 6.4 Голосовые команды — примеры

После синхронизации (приложение **Дом с Алисой** → устройства обновились):

| Скажете | Нужно в HA |
|---------|------------|
| «Алиса, включи **свет в гостиной**» | `light` или script on |
| «Алиса, сделай **свет в гостиной** на пятьдесят процентов» | `light` с brightness (не ИК-лампа) |
| «Алиса, **теплый свет** в гостиной» | `light` color_temp или script «тёплый» |
| «Алиса, **холодный свет**» | color_temp ↑ или script |
| «Алиса, запусти сценарий **ночь**» | `scene` / `script` |
| «Алиса, включи **телевизор**» | script / media_player |

Для **ИК-лампы** создайте **отдельные сцены** с говоримыми именами:

- «Свет гостиная половина» → script brightness_50  
- «Свет гостиная тёплый» → script color_warm  

Алиса плохо понимает «2700K», но хорошо — **«тёплый свет»**, **«приглуши»** (если есть brighten в light).

### 6.5 Комнаты Алисы = Areas HA

Назначьте устройствам **области** в HA (Гостевая, Кухня…) — в навыке укажите `room` — фразы «в гостиной» заработают точнее.

Совпадение с ТЗ: в Алисе спальня родителей может называться **«Спальня»** (`entity_config.name` / room).

## 7. Гостевая + комната Макса (только ИК, без реле)

Зафиксированный план: в этих двух комнатах **не ставить** Zigbee/Wi‑Fi реле в стену — только лампы с штатным пультом + **ИК-шлюз** в HA.

| Шаг | Действие |
|-----|----------|
| 1 | По **1 Broadlink** на комнату (или тест одного на две комнаты) |
| 2 | Обучить все нужные кнопки пульта лампы |
| 3 | Скрипты: `svet_gostevaya_on`, `…_50`, `…_teply`, `svet_maksa_…` |
| 4 | Yandex Smart Home: имена «Свет гостиная», «Свет комната Макса», сцены «пятьдесят процентов» |
| 5 | Lovelace: вкладки **Гостевая** / **Комната Макса** — кнопки сцен |

**Не ждать** от ИК точных «47%» — формулировки для Алисы: «приглуши», «половина яркости», «тёплый свет».

## 8. Рекомендуемая стратегия для вашей квартиры

| Устройство | Путь | Алиса |
|------------|------|-------|
| Свет (новый/замена) | **Zigbee / LocalTuya** `light` | %, К, цвет |
| Sonoff / Tuya выключатели | LocalTuya / SonoffLAN `switch` | вкл/выкл |
| ТВ, приставка, старая лампа с пультом | **ИК Broadlink** + script | сцены/команды |
| Режимы «Ночь», «Отпуск» | `input_boolean` + automations | «Алиса, включи отпуск»* |
| Кондиционер Haier | ИК (фаза 3) | «кондиционер 24 градуса» |

\* Отпуск лучше как **сценарий** `script.rezhim_otpusk_on`, экспортировать в Яндекс.

### Порядок внедрения

1. **Yandex Smart Home** в HA + синхронизация существующих `light`/`switch`.  
2. Проверка голоса на **одной** умной лампе или розетке.  
3. Покупка/настройка **Broadlink** → ТВ + одна ИК-лампа (обучение кнопок).  
4. SmartIR или скрипты для дискретных режимов лампы.  
5. Сцены «50%», «тёплый» → экспорт в Яндекс.  
6. Постепенная замена ИК-ламп на **Zigbee** там, где нужны точные %.

## 9. Пример пакета HA (ИК + голос)

Файл `homeassistant/packages/empire_ir_yandex.yaml` (создать после появления Broadlink):

```yaml
script:
  tv_gostevaya_on:
    alias: "ТВ гостиная — включить"
    sequence:
      - service: remote.send_command
        target:
          entity_id: remote.broadlink_gostevaya
        data:
          device: tv
          command: power_on

  svet_gostevaya_tepliy:
    alias: "Свет гостиная — тёплый (ИК)"
    sequence:
      - service: remote.send_command
        data:
          device: lamp
          command: warm_white
        target:
          entity_id: remote.broadlink_gostevaya
```

В **Yandex Smart Home** → отметить эти `script` как сценарии с именами «ТВ гостиная», «Тёплый свет гостиная».

## 10. Частые ошибки

| Проблема | Решение |
|---------|---------|
| Алиса «не вижу устройство» | Обновить устройства в «Дом с Алисой»; проверить фильтр в интеграции |
| «50%» не работает на ИК-лампе | Нужен `light` с brightness, не script |
| После пульта HA «врёт» | ИК без обратной связи — умная лампа или сброс сцены |
| ИК не срабатывает | Шлюз вне шкафа, батарейка пульта, переобучить код |
| Задержка 2–5 с | Облако Yandex + облако Broadlink — норма; локальный HA быстрее |
