# Pension · YouTube + нативная реклама — дорожная карта 12 месяцев

**Статус:** рабочий план (июнь 2026 → май 2027).  
**Модель дохода:** Pension = **основной** (YouTube + прямая/нативная реклама + книга как trust asset).  
**Спутники** (Garden, Gdepar, Stern, Lenin) = трафик, доверие, автопост Empire — **не** отдельные бизнес-линии.  
**Связь:** `pension_youtube_launch_guide.md`, `pension_book_publish_tz.md`, `empire_business_plan_2026.md`, `growth_rf_no_max_2026.md`.

---

## 0. Принципы плана

| Принцип | Следствие |
|---------|-----------|
| **80% времени — Pension** | Съёмка, монтаж, outreach рекламодателям, книга |
| **1 ролик / нед** | Устойчивее, чем 3 ролика и выгорание |
| **Без VPN — Дзен + VK + сайт** | YouTube не единственная точка входа |
| **Нативка > AdSense** | AdSense — бонус 3–15k/мес, не опора |
| **Книга = доверие** | Launch нужен для медиакита, не для 100k/мес |
| **Спутники — контент-петля** | 1 цикл/нед: лучший пост → Дзен → клип VK → «полное на YT» |

**Три сценария в таблицах:**

- **База** — без рекламы, органика, 1 ролик/нед без пропусков  
- **Цель** — база + outreach рекламодателям с 5k subs + launch книги вовремя  
- **Амбиция** — 1–2 «выстрела» (ролик 100k+ просмотров) или таргет ВК на Pension-клипы  

---

## 1. Воронка (единая схема)

```
Спутники (Empire автопост)
    → Дзен-статья / пост VK (800–2500 зн.)
    → neverretire.ru/book + email
    → YouTube полный выпуск (15–25 мин)
    → Прямая реклама (брокер / финтех / EdTech)
    ↓
Книга PDF (trust) + повторные интеграции
```

**Спутники — минимальный регламент (≤3 ч/нед суммарно):**

| Персона | Действие | Зачем Pension |
|---------|----------|---------------|
| Garden / Gdepar | Empire approve → 1 Дзен/2 нед из лучшего поста | Холодный трафик, перекрёстная ссылка |
| Stern / Lenin | Только автопост, без продуктов | Объём ленты, не отвлекать |
| Pension TG | Анонс выпуска + `[ANALYSIS]` | Ядро, VPN-аудитория |

## 3. Помесячный план

### Q1 — Запуск (июнь – август 2026)

**Фокус:** канал, первые 12 роликов, сайт + Метрика, beta книги, медиакит v0.

| Мес | YT subs (база/цель) | Просмотры/ролик | Интеграции | Доход ₽ | Ключевые действия |
|-----|---------------------|-----------------|------------|---------|-------------------|
| **Июн** | 0 → 150 / 400 | 300–1 500 / 3 000 | 0 | 0–5k | Google-аккаунт, оформление канала, выпуски №1–4, `YANDEX_METRIKA_ID`, UTM |
| **Июл** | 150 → 400 / 900 | 800–2 500 / 5 000 | 0 | 0–10k | Выпуски №5–8, Pension VK (опц.), 2 статьи Дзен, beta 5 читателей |
| **Авг** | 400 → 800 / 1 500 | 1 500–3 000 / 8 000 | 0–1 × 15–25k | 5–40k | Выпуски №9–12, медиакит v0, outreach 10 брокерам, финал 70% книги |

**Расходы Q1:** ~5–7k/мес (VPS + Cursor + OpenRouter). Реклама — **не включать** до 5k subs.

**KPI «идёт туда» Q1:**

- ≥10 роликов за 12 нед без пропуска >2 нед подряд  
- ≥500 сессий neverretire.ru/мес к августу  
- Email pre-launch ≥50 адресов  
- CTR превью YT ≥4% (Studio)

**KPI «стоп» Q1:**

- <100 subs к концу августа при 12 роликах → пересмотр превью/тем/длины  
- 0 переходов UTM `youtube` на сайт → правка CTA в описании и финале ролика

## 4. Детализация доходов (структура)

### 4.1. Доли по источникам (целевой Q4)

| Источник | ₽/мес | Доля |
|----------|-------|------|
| **Нативная / прямая реклама** | 100–180k | **75–85%** |
| **Книга PDF + EPUB** | 10–30k | 10–15% |
| **AdSense** | 5–15k | 5% |
| **Донаты / прочее** | 2–10k | <5% |
| **Спутники (Garden/Stern)** | 0–5k | ~0% |

### 4.2. Прайс-лист интеграций (для медиакита)

| Подписчики YT | Ср. просмотры/ролик | Рекомендуемый прайс «от» |
|---------------|---------------------|--------------------------|
| 1–3k | 2–8k | 25 000 ₽ |
| 3–10k | 8–25k | 50 000 ₽ |
| 10–25k | 25–50k | 80 000 ₽ |
| 25–50k | 50–100k | **100 000 ₽** |
| 50k+ | 100k+ | 120–200 000 ₽ (пакеты) |

**Форматы:** 60–90 сек mid-roll, 2–3 мин нативный блок, dedicated 15–20 мин (×1,5–2 к прайсу), серия 3 ролика (пакет −10% за объём).

**Не принимать:** гарантированная доходность, не маркированная реклама, продукты без лицензии ЦБ (для брокеров — проверять реестр).

- YooKassa на Garden/Stern как приоритет  
- Spy live / нейрокомментинг

## 7. Юридические вехи

| Когда | Действие |
|-------|----------|
| Первая любая выплата | Чек **НПД** («Мой налог») |
| Первая интеграция >30k | Договор + **маркировка** (ORD/ЕРИР) |
| Выручка >150k/мес × 2 мес | Рассмотреть **ИП** (УСН 6%) |
| Накоплено >1,8 млн/год | ИП обязательно до лимита НПД 2,4 млн |
| Каждая интеграция | Чек-лист: не ИИР, не доходность, дисклеймер в описании |

## 9. Сигналы «ускорить / стоп / поворот»

| Сигнал | Действие |
|--------|----------|
| Ролик >50k просмотров | Срочно медиакit + outreach 20 контактов |
| 3 мес без интеграции при >5k subs | Снизить прайс на 20% или сменить формат (dedicated) |
| subs растут, просмотры нет | Темы/превью/первые 30 сек — A/B |
| Дзен даёт трафик, YT нет | Усилить CTA «полное видео» в каждой статье |
| Выгорание / пропуск >3 нед | Пауза 2 нед, выпуск «лучшее за квартал», не бросать канал |
| Рекламодатель просит «гарантию доходности» | **Отказ** |
