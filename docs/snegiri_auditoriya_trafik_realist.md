## 1. Правка финмодели под вашу реальность

Gemini считал SOM **1–3k** и M1 **20 платящих**. При **114** подписчиках и **5–8** активных читателях это **не так**.

### Реалистичная воронка «сейчас» (без роста канала)

| Этап | Объём / мес | Комментарий |
|------|-------------|-------------|
| Просмотр поста в TG | 30–80 | не все 114 открывают |
| Клик на сайт | 5–15 | из «тёплых» |
| Пробный разбор | 2–6 | 15–40% от клика |
| **Оплата** | **0–2** | первый месяц без доработки воронки |

**За 3 месяца только из текущего TG:** **3–10 платящих** — если каждый пост ведёт на продукт.

**30 платящих к м3** (критерий Gemini) **достижимы**, если параллельно:

1. Перенести/дублировать контент на **бренд Шterна** (Дзен, VK, TG).  
2. **2–4 поста/нед** с ссылкой на бесплатный разбор.  
3. **3–5 статей Дзен** под SEO («боль в пояснице дома», «гиря для новичка»).  
4. Один **запуск** на личном аккаунте: «открыл программу — вот ссылка».

### Сценарий «год 1 — только органика + ваше время»

| Месяц | Платящие (накоп.) | MRR | Реклама ₽ |
|-------|-------------------|-----|-----------|
| 1 | 2–5 | 1–3k | 0 |
| 3 | 10–20 | 5–10k | 0 |
| 6 | 25–50 | 12–25k | 0 |
| 12 | 50–120 | 25–60k | 0 |

Это **ниже** базового Gemini (300 к м12), но **совместимо** с break-even ~65 users **без рекламы**.

**В finmodel v4 реклама уже есть** (0 → 80k с м6) — для вас на год 1 закладываем **0 ₽ рекламы** и **время на контент** как CAC (не деньги).

## 4. Эталонное видео: откуда брать, можно ли «мультик»

### Иерархия (от дешёвого к дорогому)

| # | Вариант | Стоимость | Плюсы | Минусы |
|---|---------|-----------|-------|--------|
| **1** | **Схема/анимация** (SVG → MP4, Lottie) | 0–15k ₽ (сам или фриланс) | Обезличено, углы, стиль бренда | Не «живое» тело |
| **2** | **Вы снимаете** 18 коротких роликов (10–20 сек) | 0 ₽ + 1–2 дня | Доверие к Шterну | Лицо в кадре (если ок) |
| **3** | **Встроенные YouTube** (канал Back Mechanic и др.) | 0 | Быстро | Не ваш бренд; «по мотивам McGill»; зависимость от чужого канала |
| **4** | **LICENSE тренера** | 25–50k | Профи, 2 ракурса | Деньги, договор |
| **5** | **AI-видео** | 5–20k | Быстро | Низкое доверие в нише «спина» |

### Рекомендация для MVP (согласовано с Gemini «без съёмки»)

**Гибрид на каждое упражнение:**

```
[15 сек] Анимация: силуэт + углы спина/таз/колено (красный/зелёный)
[10 сек] Текст: 3 ключевые ошибки
[опционально] Ссылка «разбор на YouTube» для McGill Big 3
```

**Мультик — да, возможно и правильно:**

- Figma / Blender / After Effects → экспорт MP4 или **Lottie** в PWA.  
- Стиль: ч/б силуэт + **#FF3300** линии углов (как на лендинге CV).  
- Для **CV-разбора** эталон не обязателен — алгоритм сравнивает с **геометрией**, не с роликом тренера.  
- Для **обучения** «как вообще делать» — анимация **лучше** stub CV на старте.

**Не ждать** LICENSE для запуска. План:

1. **Нед 1–2 запуска:** статичные SVG + 3 GIF/MP4 анимации для S1–S3 (можно сгенерировать в Gemini/Runway или нарисовать).  
2. **М2:** вы доснимаете или заказываете пакет 18 анимаций (≈15–30k ₽).  
3. **М6+:** LICENSE эталоны для CV-калибровки, если есть платящие.

Ссылки McGill для embed (уже в коде Empire): `tools/build_stern_technique_matrix.py` — YouTube Back Mechanic для curl-up, side plank, bird-dog.
