## 6. Рекомендации v4 (согласовано Cursor + Gemini)

### До первой оплаты (MVP платный)

1. DNS → snegirinegiri.ru  
2. ЮKassa + выдача доступа  
3. Яндекс.Метрика + UTM  
4. Текст «как работает разбор» (честно про упрощённый алгоритм)  
5. **Не делать:** съёмку эталонов, рекламу, новые упражнения  

### Экономика до масштаба

1. **Лимит 8 разборов/мес** — уже в продукте; не обещать безлимит.  
2. **Годовой тариф:** поднять до **5990 ₽** или убрать с лендинга.  
3. **Реклама:** NO до **trial→paid ≥10%** на ≥500 визитах органики.  
4. **CAPEX съёмка 45k:** отложить; Gemini в MVP тоже говорит «не сейчас».  
5. **Отток в модели:** планировать **10%**, не 4%.

### Критерий «имеет смысл продолжать» (м3)

| Метрика | Порог |
|---------|-------|
| Платящие | **≥15** (Gemini: ~20 в базе к м1) |
| MRR | **≥8 000 ₽** |
| Trial→paid | **≥8%** |
| Источник | **≥70% органика** |

Если м3 < **10 платящих** при ≥300 визитах — **STOP** платного направления.
