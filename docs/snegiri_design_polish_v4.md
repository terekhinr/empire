## Версии: сайт + PWA

- **Лендинг** — адаптивный веб (телефон, планшет, десктоп).
- **Программа** — mobile-first PWA (`mockup.html` → prod), на десктопе макет в «рамке телефона» + боковая подсказка.
- Один бэкенд Empire, одна воронка: лендинг → `mockup.html` / будущий `/app`.

## Чек после загрузки новых PNG

```bash
./scripts/snegiri_compress_assets.sh   # step/logo* — без pngquant
# или вручную:
convert input.png -define png:color-type=6 output.png
cwebp -q 85 output.png -o output.webp
```

Обновить `?v=` в HTML/CSS после замены файлов.
