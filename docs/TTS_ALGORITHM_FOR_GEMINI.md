# Алгоритм RU Text → Speech (Empire) — бриф для оптимизации

**Назначение:** отдать в Gemini как ТЗ на ревью/оптимизацию пайплайна озвучки книжек и статей.  
**Стек сейчас:** preprocess в Python → Yandex SpeechKit (`filipp`) → fallback Silero; опционально Edge/Gemini TTS.  
**Главный принцип:** вся коррекция произношения — **в тексте до синтеза**. У SpeechKit нет hosted PLS (как у Azure/Polly).

Код: `scripts/prepare_md_for_tts.py`, `scripts/tts_pronunciation.py`, `scripts/tts_pronunciation_dict.txt`, `scripts/docx_to_mp3_yandex.py`, `bots/stepanich/pdf_audio_bot.py`.

---

## 0. Цель оптимизации (что улучшить)

1. Меньше ручных правок словаря при том же качестве.
2. Меньше ложных срабатываний (гео-АО vs юрформа АО; о́рган vs орга́н; сто́роны vs стороны́).
3. Стабильные ударения и фонемы на длинных книгах.
4. Переносимость: Yandex + Silero (+ Edge) без дублирования логики.
5. Измеримый QA: A/B текст → TTS → (опционально) STT / чеклист ушей.

**Не цель:** «заменить SpeechKit одной LLM-озвучкой» без доказанного выигрыша по цене/качеству/квоте.

---

## 1. Входы / выходы

| | |
|--|--|
| **Вход** | PDF / DOCX / MD / TXT (сырой текст книги/статьи) |
| **Промежуточный** | speech-ready plain text с разметкой SpeechKit (`+` ударение, `[[фонемы]]`) |
| **Выход** | MP3 части (~30–40 мин / лимит Telegram), голос `filipp`, speed `0.95` |

Провайдеры:

| Provider | Ударения | Фонемы `[[…]]` | Когда |
|----------|----------|----------------|--------|
| **yandex** (default) | `+` перед гласной | да | ключ есть |
| **silero** | `+` | нет (пропуск) | квота Yandex / fallback |
| **edge** | U+0301 acute | нет | явно |
| **gemini TTS** | acute | нет | явно |

---

## 2. Полный алгоритм (порядок слоёв — жёсткий)

```
RAW (pdf/docx/md/txt)
  │
  ├─ EXTRACT          текст из файла (PyMuPDF / docx / read)
  │
  ├─ 1. CLEAN         markdown, URL, эмодзи, редактура, таблицы→фразы
  │
  ├─ 2. ALIAS/ABBR    сокращения + юрформы (до нормализации и стресса)
  │
  ├─ 3. NORMALIZE     числа/даты (ru-normalizr light); снова abbr cleanup
  │
  ├─ 4. STRESS        silero-stress (чанки ≤1200); форма + или ́
  │
  ├─ 5. LEXICON       tts_pronunciation_dict.txt (longest-first, поверх стресса)
  │                   • alias / +stress / [[phonemes]]
  │                   • phonemes только если provider=yandex
  │
  ├─ 6. PACK          абзацы; резать на PART (~32k) и CHUNK (≤2500) по .!?…
  │
  ├─ 7. SYNTH         SpeechKit v1 tts:synthesize (mp3) / Silero
  │
  ├─ 8. CONCAT        ffmpeg concat → part MP3
  │
  └─ 9. QA LOOP       ухо → классификация ошибки → 1 строка в dict → переозвучка куска
```

### Почему именно такой порядок

| Правило | Почему |
|---------|--------|
| ALIAS/юрформы **до** STRESS | «акционерное общество» получает нормальные ударения |
| STRESS **до** LEXICON | иначе accentor ломает `[[фонемы]]` |
| LEXICON **после** STRESS | overrides побеждают модель (`мн+ого` → `[[…]]`, `со ст+ороны` → `со сторон+ы`) |
| Phonemes только Yandex | Silero/Edge читают скобки как мусор |
| Вся правка в тексте | один пайплайн на несколько TTS |

---

## 3. Слой 1 — CLEAN

Файл: `prepare_md_for_tts()`.

- Снять: `#` заголовки → фраза с точкой; `**bold**`, ссылки, URL, `#хештеги`.
- Выкинуть редактуру («Примечание к версии», таблицы-разделители).
- Табличные `|` строки → предложения через `. `.
- Кавычки «» → `"`, NFC unicode.
- Не трогать смысл слов.

---

## 4. Слой 2 — ALIAS / ABBR + юрформы

Файл: `expand_speech_abbreviations()` + `expand_legal_forms()`.

### Сокращения (примеры)

`т.д.` → так далее; `т.п.` → тому подобное; `т.е.` → то есть; `в т.ч.` → в том числе;  
`ув.` → уважаемый/уважаемая (по роду след. слова); `см.` → смотри; `рис.` → рисунок; …

### Юрформы (анти-«аоаоао» у SpeechKit)

| Токен | Замена |
|-------|--------|
| ООО | общество с ограниченной ответственностью |
| АО | акционерное общество |
| ПАО / ЗАО / ОАО | публичное / закрытое / открытое акционерное общество |
| ИП | индивидуальный предприниматель |

**Исключение географии (сначала!):**

- `Ненецкий/Чукотский/Ямало-Ненецкий/Ханты-Мансийский АО` → `… автономный округ`
- `Еврейская АО` → `Еврейская автономная область`
- `Ханты-Мансийский АО — Югра` → полное имя округа

Стемы с любым окончанием (`Чукотским АО` тоже).

---

## 5. Слой 3 — NORMALIZE

`ru-normalizr`, режим **light** (не разворачивать инициалы «Маша Н.» → «эн»).

- Числа → слова по-русски.
- Даты/прочее по опциям Normalizer.
- После прогона — снова `expand_speech_abbreviations` (normalizr мог оставить хвосты).
- Пробельный `+` («Вова + Настя») → «и»; покерный `АК+` → «и выше»; **не** ломать `п+окер`.

Env: `PDF_AUDIO_NORMALIZE_MODE=light|safe|full|off`.

---

## 6. Слой 4 — STRESS (автоударения)

Движок: **silero-stress** (в локальном генераторе также RUAccent).

- Чанки ≤ `PDF_AUDIO_STRESS_MAX_CHARS` (1200), по предложениям.
- Формат:
  - Yandex/Silero: `+` перед ударной гласной (`зам+ок`, `сторон+ы`)
  - Edge/Gemini: combining acute U+0301 (`о́`)
- Омографы без контекста часто ошибаются → чинит слой 5.

Env: `PDF_AUDIO_STRESS=1`, `PDF_AUDIO_STRESS_FORMAT=plus|acute`.

---

## 7. Слой 5 — LEXICON (исключения)

Файл: `scripts/tts_pronunciation_dict.txt`  
Код: `apply_pronunciation_lexicon()`.

### Формат строки

```
ключ = замена
```

- Регистр ключа не важен.
- Матч longest-first.
- Ключ матчится и к формам с `+` / ́ (гибкий regex по гласным).
- Поддержка **фраз** (пробелы → `\s+`).

### Типы замен

| Тип | Пример | Когда |
|-----|--------|--------|
| **alias** | (редко в dict; юрформы в коде) | расшифровка |
| **stress** | `панас = пан+ас` | омограф / имя |
| **phoneme** | `много = [[m n ɔ g ʌ]]` | подмена звука (г→в); только Yandex |

### Фонемы Yandex (IPA в `[[ ]]`)

- Ударная о = `ɔ`, безударная а = `ʌ`, твёрдая г = `g` (не `v`).
- Список: docs SpeechKit «поддерживаемые фонемы».

### Текущие классы в словаре (живой QA)

1. **много*** → phoneme (баг «мново»)
2. Покерные термины → stress
3. замок/мука → stress
4. Панас → `пан+ас`
5. о́рган vs орга́н → **только фразы с контекстом** (`звук органа` → `+органа`; `половой орган` → `орг+ан`)
6. стороны́ → фразы `со стороны`, `с одной стороны`, …

### Правило пополнения (обязательное)

1. Услышал ошибку → классифицируй: **alias | stress | phoneme**.
2. Одна ошибка → одна строка (или парадигма падежей).
3. Омографы без контекста → **фраза**, не голое слово.
4. Норму словаря (Ожегов) не переворачивать «по просьбе уха», если ухо путает омограф — сначала сверить словарь.
5. Не класть Yandex-phoneme туда, где ходит Silero без фильтра (фильтр `PDF_AUDIO_PHONEMES` уже есть).

---

## 8. Слой 6–8 — PACK / SYNTH / CONCAT

- PART ≈ `PDF_AUDIO_PART_TARGET_CHARS` (32000) — глава/кусок книги.
- CHUNK ≤ 2500 — лимит запроса SpeechKit.
- Резать по абзацам, затем по `.!?…`, иначе жёсткий slice.
- Yandex: `POST tts.api.cloud.yandex.net/speech/v1/tts:synthesize`  
  `lang=ru-RU`, `voice=filipp`, `format=mp3`, `speed=0.95`, разметка в `text`.
- Retries на 429/5xx; skip чисто латинских чанков.
- `ffmpeg -f concat -c copy` → итоговый MP3 части.
- При падении Yandex mid-book → Silero на остаток.

Разметка SpeechKit в `text`:

- ударение: `+` перед гласной (`зам+ок`)
- пауза: `sil<[300]>`, `<[small]>` …
- фонемы: `[[m n ɔ g ʌ]]`
- акцент: `**слово**` / `<[accented]>`

---

## 9. Слой 9 — QA

1. Слушать проблемные места (аббр, имена, омографы, «много», юрформы).
2. Опционально: `scripts/verify_tts_pronunciation.py --synth` (TTS+STT A/B; STT лучше на `oggopus`).
3. Запись в dict → перегнать только affected chunk/part.
4. Не переозвучивать всю книгу ради одной строки, если concat позволяет точечный rebuild.

---

## 10. Известные классы ошибок SpeechKit (чеклист)

| Симптом | Класс | Фикс |
|---------|-------|------|
| много → «мново» | phoneme г→в | `[[m n ɔ g ʌ]]` |
| АО → «аоаоао» / «ао» | alias | расшифровка юрформы |
| со стОроны | stress омограф | `со сторон+ы` |
| ПАнас | stress имя | `пан+ас` |
| о́рган / орга́н | stress + контекст | фразы, не голое слово |
| т.д. читается буквами | abbr | expand до TTS |
| `+` как «плюс» | артефакт | не слать пробельный + в Edge |

## 12. Вопросы к Gemini (оптимизация)

Просьба к модели: предложить улучшения **без ломания порядка слоёв**, если нет сильной причины.

1. **Homograph disambiguation:** нужен ли лёгкий contextual ranker (правила/маленькая модель) вместо роста фразового dict? Где ROI?
2. **Единый NSW taxonomy** (как в работах по RU TTS normalization): даты, телефоны, тикеры, латиница — что добавить в light-normalizr?
3. **Словарь:** формат PLS-подобный (grapheme/alias/phoneme + pos/context) vs плоский `k=v`?
4. **Phoneme generation:** авто-IPA для проблемных лемм или только ручной QA?
5. **Оценка качества:** метрики без человека (STT CER на контрольном наборе; список «золотых» фраз)?
6. **Chunking/prosody:** паузы `sil<>` у заголовков/диалогов — стоит ли эвристика?
7. **Multi-voice:** разные голоса под нарратив/цитату — цена vs польза?
8. **Что выкинуть:** избыточные падежные ряды в dict, дубли с silero-stress?

Ограничения ответа Gemini:

- Сохранить provider-agnostic preprocess.
- Не предлагать SSML-only решения, если они не работают в SpeechKit v1 `text` markup.
- Любой новый слой — указать **куда вставить в порядок 1–9** и почему не ломает фонемы/stress.
- Примеры на русском, с `+` и `[[ ]]`.

## 13. Мини-пример end-to-end

**Вход:**
```text
АО «Вектор» со стороны банка продало много акций. Звук органа.
```

**После слоёв 2–5 (yandex, plus, phonemes on) — ожидаемо:**
```text
акционерное общество "Вектор" со сторон+ы банка продало [[m n ɔ g ʌ]] акций. звук +органа.
```
(плюс авто-ударения silero на остальных словах)

**Синтез:** filipp → mp3 chunk → concat.

## 15. Вердикт по аудиту Gemini (2026-10-21) + roadmap

### Принять

| Предложение | Вердикт | Приоритет |
|-------------|---------|-----------|
| LEXICON полностью перебивает любой `+`/́ на токене | **да** (баг `со сто+роны` подтверждён) | P0 — сделано: `\+?` перед любым символом ключа |
| NSW: римские, диапазоны, валюты, %, единицы | **да**, точечно в light | P1 |
| Gold set + STT CER | **да**, расширить `verify_tts_pronunciation.py` | P1 |
| Плоский dict + контекстные теги `[after:…]` | **да**, без XML PLS | P2 |
| Паузы `sil<[ms]>` у заголовков/абзацев | **да**, единый синтаксис SpeechKit | P2 |
| 1 голос + accent/speed, не multi-voice | **да** | — |
| Phonemes только ручной QA | **да** (уже так) | — |

### Принять с правкой

| Предложение | Правка |
|-------------|--------|
| Слой **3.5 DISAMBIG до STRESS** с уже проставленным `+` | Опасно: silero-stress перетрёт разметку. Лучше: **3.5 пишет мягкие якоря** (или preferred lemma/tag), а **финальный stress override — в LEXICON после STRESS**; либо STRESS пропускает уже размеченные токены |
| «POS закроет 85% омографов» | Завышено. Natasha/pymorphy3 хорошо для `со стороны` / падежей; `зáмок/замóк`, `стóит/сто́ит` часто требуют семантики. Старт: **rule+morph на топ-N омографах**, не RuBERT сразу |
| Пример с `<[long]>` и `sil<[800]>` вперемешку | Унифицировать: только `sil<[t]>` и/или `<[tiny\|small\|medium\|large\|huge]>` по доке SpeechKit |

### Отклонить / отложить

| Предложение | Почему |
|-------------|--------|
| RuBERT-tiny2 в горячем book-path | Тяжело, GPU/latency, мало ROI до morph-правил |
| Авто-IPA на весь текст | SpeechKit G2P ок; `[[ ]]` только для багов |
| Выкинуть падежные ряды «много» phoneme | Парадигма phoneme остаётся — morph тут не поможет с г→в |
| Темпоральные теги «вместо» словаря омографов | Не заменяют ударение |

### Целевой порядок слоёв (согласованный)

```
1 CLEAN (+ опционально якоря пауз на заголовках)
2 ALIAS/ABBR
3 NORMALIZE (расширенный NSW)
3.5 DISAMBIG soft   # tags / preferred stress hints, без финального +
4 STRESS            # silero; уважает уже зафиксированные overrides если есть
5 LEXICON           # hard override, полное замещение токена
6 PACK + sil<> между абзацами
7–9 SYNTH / CONCAT / QA(CER)
```

### Фазы внедрения

1. **P0** — harden LEXICON match (готово)  
2. **P1** — NSW + gold + prosody + CER (готово)  
3. **P2** — паузы sil<> + dict `[after:…]` (готово)  
4. **P3** — омографы `tts_disambig.py` + pymorphy3 optional (готово):  
   стороны́/сто́роны, замо́к/за́мок, сто́ит/стои́т, мука́/му́ка  

Порядок слоёв сейчас: CLEAN → ABBR → NSW → STRESS → LEXICON → **DISAMBIG** → PROSODY → SYNTH.

*Версия брифа: 2026-10-21f. P0–P3.*
