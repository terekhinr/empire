## Сообщение 1 · Инвентаризация

### 1. Инвентаризация текущих активов и препятствий

| Категория | Сильные стороны (что имеет ценность) | Слабые стороны и препятствия (что блокирует продажи) |
| --- | --- | --- |
| **Продукт и контент** | Готовые программы тренировок (12 и 24 недели), база из 18 упражнений. Сформированная тарифная сетка (590 / 1490 / 3990 ₽). | Отсутствие эталонных видео тренеров для системы компьютерного зрения (снижает точность обратной связи). |
| **Технологии** | Быстрая сборка (~3 дня): готово веб-приложение, программный интерфейс (API), базовая логика распознавания видео. | **Критическое препятствие:** Домен не привязан (нет DNS), продукт недоступен пользователям в сети. |
| **Инфраструктура** | Наличие собственной площадки (целевая страница + веб-приложение). | **Критическое препятствие:** Не подключена платежная система (ЮKassa). Отсутствует система сбора статистики (Метрика). |
| **Маркетинг и бренд** | Наличие теплых каналов трафика (Дзен, личный канал Штерна). Готовая концепция бренда («Снегири не гири»). | Основной тематический канал проекта («Снегири») имеет малую базу подписчиков. |

### 2. Минимальный рабочий продукт для первой оплаты

| № | Необходимый шаг / Элемент | Цель внедрения |
| --- | --- | --- |
| **1** | Настройка DNS-записей для купленного домена | Обеспечить физический доступ пользователей к целевой странице и приложению из браузера. |
| **2** | Интеграция платежного шлюза (ЮKassa) | Дать возможность технически принять деньги и автоматически выдать доступ к программам. |
| **3** | Установка счетчика веб-аналитики (Яндекс Метрика) | Отследить источник первой покупки, поведение пользователя на странице и конверсию в оплату. |
| **4** | Настройка базового доступа в личном кабинете | Гарантировать, что после списания средств клиент получает обещанные программы (на 12 или 24 недели). |
| **5** | Текстовая инструкция к функции разбора видео | Нивелировать отсутствие эталонных видео: объяснить, как работает упрощённый алгоритм и что он оценивает. |

### 3. Что является лишним на текущем этапе

| № | Избыточный элемент | Причина отказа |
| --- | --- | --- |
| **1** | Съёмка и разметка эталонных видео от тренеров | Значительные затраты; на этапе проверки спроса достаточно упрощённого CV. |
| **2** | Платное привлечение трафика (реклама) | Сначала — первые продажи на органике (Штерн, Дзен). |
| **3** | Расширение базы упражнений (сверх 18) | Текущего объёма хватает на 12–24 недели. |
| **4** | Сложная аналитика внутри программ | До первых платящих — фокус на конверсии в покупку. |
| **5** | Нативные мобильные приложения | PWA закрывает мобильный доступ. |

## Сообщение 3 · Продукт и P&L

### 1. Value Proposition (3 варианта)

1. **Функциональное:** Здоровая спина и базовая сила дома. Гиря + контроль техники алгоритмом за 590 ₽/мес.
2. **Проблема:** Избавьтесь от боли в пояснице. McGill + гиря. Камера проверит ошибки без тренера.
3. **Бренд:** Система Штерна дома: гиря + спина. План 24 недели с автоматическим разбором.

### 2. Позиционирование

**Для кого:** офис + спина · занятые · силовая база · интроверты · контроль без тренера · читатели Шterна · дисциплина.

**Не для кого:** кубики · острая боль без врача · кардио-фитнес · штанги/PL · без гiri · нужно разнообразие · нужен живой чат.

### 3. Продуктовая лестница

Бесплатно (1 разбор + 3 тренировки) → 590 → 1490 → 3990 → будущее (TG 990?, PDF, книга).

### 4. Расходы

| Статья | Значение |
|--------|----------|
| COGS/активный/мес | **185 ₽** (8×20 CV + 15 LLM + 10 storage) |
| CAPEX м1 | **87 000 ₽** (лицензия 25k, юрист 12k, домен 5k, съёмка 45k) |
| OPEX инфра | 3–15k/мес |
| Налог + эквайринг | ~10% |
| RevShare | 20% от «чистой» |
| Реклама | 0 (м1–5), 80k с м6 |
| Основатель | 120k/мес (60ч×2000) |

### 5. Доходы и unit economics

**Микс:** 30% мес / 30% квартал / 40% год.

| Метрика | Значение |
|---------|----------|
| Средний cash с нового клиента | **2 220 ₽** |
| Средний MRR на пользователя | **~459 ₽** |

**⚠️ Годовой тариф 3990 ₽:** 332 ₽/мес − 278 ₽ расходов = **54 ₽ маржи/мес**. При 12 разборах/мес — **убыток**. Рекомендация Gemini: **5990 ₽** или жёсткий лимит разборов.

### 7. Break-even

| Тип | Порог |
|-----|-------|
| Операционный (без рекламы) | **~65 users** |
| С рекламой 80k/мес | **~600 users** |
| Экономический (+ основатель 120k) | **~1400 users** |

### 8. Чувствительность

- **Отток:** 4% vs 10% — разница в выручке >50% за 2 года; закладывать **10%**, не 4%.
- **Trial→paid:** 5% → CAC >2000 ₽ (убьёт экономику); 15% → CAC ~650 ₽ (реклама окупается).
- **Реклама:** без неё потолок 150–200 users; 50k/мес без правки тарифов → кассовый разрыв к м7.

1. Снизить COGS (лимит загрузок видео).  
2. Поднять годовой тариф до **5990 ₽** или ограничить разборы.  
3. Платный трафик — **только после** проверки органической воронки.

1–2: стабильность · 3–4: заголовки · 5–6: цена/год · 7–8: напоминания. Sample: **100–150** на вариант.
