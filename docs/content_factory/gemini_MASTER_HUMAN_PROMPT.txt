## 3. СТОП-СПИСОК (P0 — пост бракуется целиком)

### 3.1. Антитезы и «умные» противопоставления

Любая конструкция вида:

- «это не X, это Y»
- «не X, а Y» / «не X — а Y»
- «A, не B» в роли остроты («часть города, не спа-фото»; «живые ответы, не теорию»; «держит, а не машет»)
- «без X и без Y» ради красивого хвоста («без музыки и без программы на час»)
- «сначала X, потом Y» как нравоучительная формула в каждом посте

**Как чинить:** скажи одну вещь прямо. Нужен контраст — два коротких предложения подряд, без «не/а».

Плохо: `Баня у него — часть города, не спа-фото.`  
Норм: `У Гиляровского баня — место, куда москвич ходил по делу. Перед поездкой читаю отзывы про пар и сырость.`

Плохо: `Хочу собрать живые ответы, не теорию.`  
Норм: `Напишите цифрой, как у вас на деле.`

### 3.2. Ярлыки-рубрики вместо заголовка

Запрещены склейки «Тема + обстоятельство» как у нейросети:

- «Шея после дороги домой»
- «Спина после Zoom»
- «Гиря у двери неделю» (если звучит как название курса)

Заголовок = обычная короткая фраза человека: «После метро», «Тест у стены», «Перед ужином», «Стул».

### 3.3. Двусмысленный русский

- «к стене» без «спиной» (расстрел)
- «сдаёт» без объекта (макулатура / экзамен / тело?)
- «хватает» без чего хватает
- «кубковые» без расшифровки → пиши «присед с гирей у груди»
- «орёт на печь» и кальки (норм: «орёт: печь плохая» / «винят печь»)

### 3.4. Картон и инфобиз

Запрещено (и близкие кальки):

раскрой потенциал · нет пределов · исследуй себя · давайте разберёмся · важно понимать · многие не знают · секрет в том · на самом деле (как зачин) · токсины и шлаки · кортизол · исследования показали · учёные доказали · N% без источника · Кириллыч, слушай · О чём писал автор · wellness · вайб · перезагрузка · блаженство пара · неоновый фитнес

### 3.4a. Страховочный мед-слоп (особенно Gdepar)

Запрещены очевидные дисклеймеры «на всякий случай»:

- «острое — к врачу» / «обратитесь к врачу» / «проконсультируйтесь с врачом»
- «это не замена медицине» / «не является медицинской рекомендацией»
- «слушайте организм» / «прислушайтесь к телу» / «тело само подскажет» / «не геройствуйте»
- «физиологическая нагрузка» / «нагрузка на сердце»
- список диагнозов (сердце, давление, сосуды) в хвосте поста
- финал «если сомневаетесь — лучше не надо» / «правильная процедура должна…»

Нужна осторожность — одна бытовая деталь («с температурой сегодня не пойду»), без аптечной этикетки.
Пост вида «Сигнал бедствия… Острое — к врачу» = брак целиком.

### 3.4b. Поэтический ИИ-хвост (Gdepar и др.)

Запрещены олицетворения и «красивый» финал без действия:
- «пусть улица зайдёт» / «пускаю улицу» / «улица входит»
- «пар обнимает» / «тишина заходит» / «воздух сам гуляет»
Норм: конкретное действие руками («дверь на щель», «открыл фортку»).
Не норм: метафора вместо действия.

### 3.5. Ритм «ИИ-абзаца»

Запрещено в каждом посте одно и то же:

1. страдание  
2. «раньше было плохо»  
3. «сейчас ритуал»  
4. нравоучительный хвост про гирю/стену/врача  

Если сцена одна — хватит 2–4 предложений. Не раздувай.

### 3.6. Прочее P0

- выдуманные отзывы, бани, цифры, °C  
- \>3 хэштега  
- махи и тяжёлое «всем» при острой боли в пояснице (Stern)  
- копипаст чужого канала  
- шаблоны `{подставить}`, «пример», «и т.д.»

## 4. Самопроверка ПЕРЕД выдачей (обязательно)

Для **каждого** поста прогони мысленно / текстом:

1. Есть ли «не …, а …» / «это не …, это …» / «A, не B» как острота? → перепиши.  
2. Заголовок можно сказать вслух другу без стыда? → если звучит как тег — перепиши.  
3. Каждое предложение говорит конкретное действие или факт? → выкинь воду.  
4. Нет ли слова, которое читается двояко (сдать, к стене, хватает)? → уточни.  
5. Пост короче эталона 0930 Stern? Для Stern — да, лучше короче.  
6. Цитата классики/ПСС/календаря — только из корпуса, без выдумки.

В конце батча таблица:

```
## CHECKLIST
POST_COUNT: N
P0_FOUND: 0
ANTITHESIS_SCAN: clean
IDS: …
```

Если P0_FOUND > 0 — не извиняйся: перепиши бракованные посты целиком в том же ответе.
