# Гдепар · выбранные темы из разведки (рабочий список)

**Дата:** 2026-07-21  
**Источник:** конкуренты TG/ВК/Дзен (`BATH_COMPETITORS_ALL_SEGMENTS_2026-07-21.md`)  
**Правило:** механику хита берём; текст «токсины / 9 причин / Кириллыч слушай» — нет.  
**Ядро канала рядом:** Классическая баня (цитата + портрет + «О чём писал») — эти темы её не заменяют.

Каждая тема = **1 угол = 1 пост**. Не раздувать в энциклопедию.

## 1. Веник — одна порода + как

| # | Угол | Формат | Не делать |
|---|------|--------|-----------|
| V1 | Берёза: запарить без кипятка | 6–8 строк + 1 ошибка | целлюлит, токсины |

**Старт:** V1 или V2.

## 2. Польза / списки (охват есть — качество наше)

Не «9 причин». Список только если каждый пункт = **бытовой факт**, не «наука доказала».

| # | Угол | Формат |
|---|------|--------|
| L1 | 5 вещей, которые портят заход (дверь/ковш/веник/телефон/спор) | чеклист без эмодзи-ракет |
| L2 | 3 строки до выезда по карте: топка / пар / сырость | pragmatic hit |
| L3 | Что обычно **не** входит в билет (веник, банщик, простыня) | шаблон, цифры только с карточки |

**Старт:** L2 (под сайт). L1 — только если пункты не дублируют старые дуэты один в один.

## 6. Печь, дымоход, истопник

Для Гдепара — **гость общественной**, не строитель. Технарь `@v_banu` — референс глубины, не тон.

| # | Угол | Формат |
|---|------|--------|
| P1 | «Бешеный истопник»: больше дров не значит быстрее пар | 1 мысль + быт |
| P2 | Запах гари / дым в парной — когда уходить | стоп-сигнал |
| P3 | Электро vs дрова в отзыве — что люди хвалят | словарь отзыва |

**Не:** сажа в дымоходе на 2 экрана (это канал хозяина).  
**Старт:** P1 или P3.
