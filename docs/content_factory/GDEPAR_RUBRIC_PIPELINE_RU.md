**Дата:** 2026-07-21  
**Разведка:** [`GDEPAR_COMPETITOR_PUBLIC_BATHS_2026-07-21.md`](GDEPAR_COMPETITOR_PUBLIC_BATHS_2026-07-21.md)

## Ядро

**Классическая баня** — единственный цельный формат (цитата + портрет + «О чём писал автор»).  
Всё LLM-дуэтное — шлак, не доливать.  
Сайт = общественные бани → второй столп контента = **карточки / выбор места**, не ликбез про щель.

## Запас классики

160 в пуле · **~30 свежих** (~4 нед.) · слот 15:00 ежедневно.

Сейчас в коде `show_commentary=False` — блок «О чём писал» **не публикуется**, хотя `note` в JSON есть. Вернуть — по твоему ОК.

## Сетка (черновик)

| Слот | Содержание |
|------|------------|
| 15:00 | **Классика** (полная, с «О чём писал» если включим) |
| 11:00 / 21:00 | Карта / **Баня недели** / редко курированный разбор отзыва — **не** новые дуэты |
| Книги | только если цитата уровня классики + сильный `note`; не пачками |

## Не делать

Пачки дуэтов, «N причин», wellness, повтор топиков про веник/дверь.
