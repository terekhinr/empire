# 0. Хорошие темы у смежных каналов

Срез публичных постов (лето 2026). Смотрим **формат**, который набирает просмотры внутри ниши — не копируем чужой текст.

---

## Спина / гири / офис (для Снегирей)

**Кого смотрели:** Епифанов, Денисов (гири), science-каналы.

| Что заходит | Как звучит у них | Нам брать так |
|-------------|------------------|---------------|
| Узнавание боли | «после созвонов / МРТ / плечо» | Сцена из быта без диагноза: стул, шея, дорога |
| До / после | Видео лечения | Неделя с одной привычкой (гиря у двери) — без клиники |
| Разнос кликбейта | «грыжу за 7 дней» | Коротко: закрыл ролик, сделал своё |
| Опрос | «что первым…» | «что устаёт раньше» + 4 пункта |
| Короткое видео техники | FAQ 15–40 сек | Суббота: один присед / жим |
| Наука длинно | Обзоры статей | **Не брать** — у них же слабый охват |

**Не брать:** проценты, «исследования показали», обещания вылечить диск.

## Баня (для Гдепара)

**Кого смотрели:** «Русская Баня», «Живая баня».

| Что заходит | Как звучит у них | Нам брать так |
|-------------|------------------|---------------|
| Красивое место / фото | сауна в скале, вид | Фото + 2 строки: на что смотреть до поездки (пар, сырость, дверь) |
| Веник одной породой | липа / дуб длинно | Один веник — один пост |
| Список ошибок | «9 причин» | 5 бытовых ошибок без «науки» |
| Видео атмосферы | пар, веник | Редко; у нас сильнее текст + карта |
| Техника печи для профи | вентиляция «Живая» | Только простой угол: дверь, камни, ковш |

**Уже наше и сильное (не у конкурентов):** классика литературы в 15:00 — **не выкидывать**.

**Не брать:** токсины/шлаки, эзотерика, фейковые градусы.

---

## Сад / дача (для Сада)

**Кого смотрели:** «Моя дача», «Дачный агроном».

| Что заходит | Как звучит у них | Нам брать так |
|-------------|------------------|---------------|
| Симптом сезона | пятно на томате, муравьи | Заголовок = что видишь на грядке сейчас |
| Три беды → одна причина | полив | Степаныч: одна причина + одно действие |
| Чеклист «сохрани» | после клубники | 4–5 шагов, цена ошибки на следующий год |
| Заготовки | банки, салаты | Редко, не ядро канала |
| Короткие видео «как» | черенкование | Опционально |

**Не брать:** ежедневный «план на день», тонны народных отваров, реклама удобрений в каждом посте.

## История / СССР (для Ленина)

**Кого смотрели:** крупные ностальгия-каналы («Мы из СССР» и рядом).

| Что заходит | Как звучит у них | Нам брать так |
|-------------|------------------|---------------|
| Квиз по фото | «кто на снимке» | 1× в неделю + подпись из корпуса |
| Бытовая вещь | портянки, номера на авто | Артефакт + год/источник |
| Дата с жёстким заголовком | рождение дипломата и т.п. | **Революционный календарь** (уже есть) |
| Кино / песня + год | фрагмент | Рубрика 12:00 из корпуса |
| Мемы без источника | — | **Не брать** |

**Уже наше ядро:** календарь каждое утро — **не заменять** мемами.
