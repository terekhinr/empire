# Пакет для Gemini (делаешь сам, пачками)

**Дата:** 2026-07-19  
**Каналы:** Снегири (Stern), Гдепар, Ленин, Сад.

## Как пользоваться

1. Открой **новый** чат в Gemini.  
2. Вставь целиком файл **`1_PERVOE_SOOBSHCHENIE.txt`** (правила + стоп-слова).  
3. Дождись: `Принял. Жду задание.`  
4. Вставь **одно** задание из папки `zadaniya/` (один файл = одна пачка, обычно 6–8 постов).  
5. Сохрани ответ Gemini в файл и занеси в Empire как раньше (ingest / руками в curated).  
6. Следующая пачка — **новый** файл задания в **том же** чате (или новый чат + снова шаг 2).

Классическую баню и календарь Ленина **не генери** заново — они уже в базе. В заданиях для Гдепара/Ленина классика и календарь помечены отдельно.

Для **NotebookLM** (один пост за раз, по источникам) — отдельный пакет:  
`docs/content_factory/notebooklm_dlya_tebya/`
