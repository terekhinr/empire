# Снегири · ручной конвейер рубрик (до автопоста)

**Дата:** 2026-07-21  
**Режим:** `auto_publish.json` → `enabled=false` до твоего финального ОК.  
**Принято:** аудиты, матрицы автопостинга, расписание 5–6 постов/нед.  
**Не делаем в Cursor:** пачки «картонных» постов — только промпты, темы, проверка, ingest в JSON.

---

## Как работаем

1. **Одна рубрика за раз** — ты генерируешь в Gemini/NotebookLM, читаешь вслух, правишь.
2. Я **не** автопостю, пока не скажешь «рубрика N принята, можно в очередь».
3. После approve — заливаю в нужный JSON, проверяю слот в `content_config.json`, показываю превью расписания.
4. Когда **все рубрики** проверены — включаю автопост только для Stern (остальные каналы отдельно).

**Промпты:**  
- Общий голос: [`gemini_MASTER_HUMAN_PROMPT.txt`](gemini_MASTER_HUMAN_PROMPT.txt)  
- Первое сообщение в чат: [`gemini_dlya_tebya/1_PERVOE_SOOBSHCHENIE.txt`](gemini_dlya_tebya/1_PERVOE_SOOBSHCHENIE.txt)

## Рубрика 1 · Техника + видео (СТАРТ)

**Зачем первой:** тексты уже в JSON, видео-пайплайн описан — ты только **читаешь** 40 разборов и подтверждаешь, что субботний слот ок.

| Параметр | Значение |
|----------|----------|
| Файл | `data/stern_technique_matrix_161_200.json` |
| Слот | **Суббота 15:00** (`stern_technique` в `content_config.json`) |
| Формат | Заголовок + 3–5 фаз + типичные ошибки + **видео** (клип атлета) |
| Политика | Без «я на помосте»; разбор **чужой** техники чемпионов |

**Твоя проверка (чеклист на один пост):**
- [ ] Нет «не просто… а», «исследования показали», PubMed-спама  
- [ ] Фазы совпадают с тем, что видно на клипе  
- [ ] Имя атлета и упражнение — факт, не выдумка  
- [ ] Длина: читается за ~45–60 секунд вслух  

**После approve рубрики 1:** не генерировать заново — только фикс отдельных `id`, если найдёшь косяк.

**Команда превью одного поста:**
```bash
./venv/bin/python -c "
import asyncio, stern_content as sc
t, body, img = asyncio.run(sc.build_technique_post())
print(body[:2000])
"
```

## Карта «книга → серия постов» (готовые темы для NotebookLM)

### Из «Занимайтесь гиревым спортом»
1. Почему 16 кг у двери — не «стыдный» вес  
2. Перетрен: признаки из брошюры vs офисная неделя  
3. Рывок: маятник vs рука (связка с субботним видео Руднева)  
4. Толчок: дыхание на фазах  
5. Перед первым соревнованием: что измерять дома  
6. Гиря на базаре → гиря в квартире (история снаряда)

### Из «ВСТАНЬ»
1. Час сидения — встать 2 минуты (офис)  
2. Как сидеть, чтобы таз не «уехал»  
3. Перегруз одного плеча (сумка/рюкзак)  
4. Утро: 5 минут перед душем — таз и грудной  
5. Командировка: отель, стул, полотенце под поясницу  
6. «Мобилити» без йога-шума — язык Штерна

### Из Епифанова (осторожно)
1. Острая боль vs усталость — стоп-сигнал  
2. Дыхательная гимнастика перед нагрузкой  
3. После простуды — не «отрабатывать» гирю  
4. Когда ЛФК важнее «личного рекорда»

### Из Ильина
1. Пропуск тренировки без самобичевания  
2. Серия из 10 — куда уходит внимание  
3. Перед «тяжёлым» подходом дома — ритуал 30 секунд  
4. Сравнение с чужими цифрами в ленте
