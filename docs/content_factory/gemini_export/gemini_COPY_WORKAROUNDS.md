# Gemini зависает при копировании — что делать

## Лучший способ (у тебя уже сработал)

**Не копируй в файл из Gemini.** Вставляй **сюда в чат Cursor** — даже без `---`, я разберу и импортирую.

Можно **по 1–2 поста** за сообщение, если шесть сразу тормозит.

---

## Если всё же копируешь из браузера

### 1. По одному посту
В том же чате Gemini напиши:
```
Дай только пост duo_pr_019_b02. Полный текст. Без остальных постов.
```
Скопируй **одно** сообщение — меньше объём, реже зависает.

### 2. Копируй не весь чат
- Клик **внутри ответа Gemini** (пузырь), не выделяй всю страницу.
- Или кнопка «Copy» у сообщения (если есть), не Ctrl+A.

### 3. Браузер
- Попробуй **Firefox** или **Chrome** (наоборот от текущего).
- Режим инкогнито без расширений (буфер обмена часто ломают менеджеры клипборда).

### 4. Обход зависания
- Выделил текст → **Ctrl+Shift+C** (копировать как HTML) иногда не помогает; лучше обычный Ctrl+C и сразу вставить в Cursor.
- Промежуточно: вставь в **Блокнот / VS Code**, потом оттуда в чат.
- На телефоне в приложении Gemini копирование иногда стабильнее — перешли себе в Telegram, с телефона в чат.

### 5. Не копируй CHECKLIST отдельно
Достаточно постов с `id:` — CHECKLIST опционален.

## На VPS / локально (файл)

```bash
# сохранил paste.txt из чата
./venv/bin/python tools/ingest_gdepar_paste.py paste.txt
```

Скрипт понимает формат **без** `---` (как Gemini отдаёт при копировании).
