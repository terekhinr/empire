🏛️ **Гири и суставы**

После 40 я перестал гнаться за весами, которые рвут связки. 

Вместо одного подхода с предельным весом я делаю три, но в идеальной технике. Суставы — не расходник, их в магазине не купишь. Сила должна быть контролируемой, а не «на разрыв». Работаю с гирей так, чтобы на следующий день хотеть тренироваться снова, а не лечиться.

🏛️ **Мотивация — это мусор**

Все эти «вставай и делай», «нет предела» — красивая обёртка, которая работает ровно два дня. 

Я давно выкинул это из головы. Есть работа, есть время для тренировки. Я просто иду и делаю. Когда у тебя есть план, мотивация не нужна. Она для тех, кто ищет повод не делать. У меня поводов нет.
