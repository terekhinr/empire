# Решения: канал «Где Пар?» (gdepar)

**Период:** контент до 15.09.2026 → автопост без ежедневной правки.

## Позиционирование
- Флагман TG → **gdepar.ru** (карта, отзывы, карточки, Premium 2 990 ₽/мес).
- Не энциклопедия в TG: сайт = факты, канал = живой голос.

## Расписание (МСК, 3 поста/день)

| Слот | Что | Источник |
|------|-----|----------|
| 11:00 | практика / промо / книга | `duo_curated` pool=practice ИЛИ промо/книга |
| 15:00 | Классическая баня | JSON 160 цитат — **не генерировать** |
| 21:00 | вечер | `duo_curated` pool=evening ИЛИ книга |

**Gemini генерирует только:** duo practice (~58), duo evening (~69), duo banya_week (~12).

## Персонажи
- **Михалыч** — традиция, пар, веник, этикет, быт.
- **Кириллыч** — печь, вентиляция, материалы, отзывы с карты.

Формат: `<b>Михалыч:</b>` / `<b>Кириллыч:</b>`, 3–5 реплик.  
**Запрет:** «Кириллыч, слушай» в начале.

## P0 (брак)
- Выдуманные °C, %, «исследования», «Финляндия».
- Фейковые отзывы и названия бань.
- Нравоучительные тирады.
- Flux-картинки без контроля — фото вручную.
