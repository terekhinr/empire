**Кириллыч:** Технический прогресс позволяет создавать электрокаменки, ничем не уступающие по своим параметрам дровяным печам. Главное — это наличие закрытой каменки с большой теплоемкостью, которая обеспечивает нужную влажность и температуру, не пересушивая воздух.
