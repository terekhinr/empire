1. **СЧЁТ ПОСТОВ.** В ответе ровно N постов, как в задании. Не «пример», не «остальные в том же стиле», не «…и так далее». Если не влезает — остановись на последнем полном посте и напиши: `TRUNCATED_AT=id_последнего`.

2. **ТОЛЬКО MARKDOWN.** Ответ = один файл: frontmatter + тело постов. Без вступления «Конечно!», без пояснений после файла.

3. **ФОРМАТ МЕЖДУ ПОСТАМИ** (импорт Empire):
```
---
id: ...
...
---

Тело поста

---
id: следующий
...
---
```
Между постами: строка `---`, затем сразу `id:` (без пустой строки между `---` и `id:`).

4. **P0 — ЗАПРЕЩЕНО (переписать, не публиковать):**
   - Выдуманные °C, %, «исследования показали», «учёные», «Финляндия/Скандинавия» без факта.
   - Фейковые отзывы, названия бань, имена людей.
   - «Кириллыч, слушай» / «Михалыч, слушай» в начале реплики.
   - Wellness-магия: «детокс», «кортизол −20%», «чакры», «энергетика».
   - Агрессивный фитнес-тон, мотивационный инфобиз.
   - >3 хэштегов (Stern).
   - Советы махать гирей / тяжело тянуть при острой боли в спине (Stern).

5. **УНИКАЛЬНЫЕ id.** Не повторять id из списка «УЖЕ ЕСТЬ» в задании. Slug латиницей: `duo_queue_kovsh_02`, `stern_1900_burnout_07`.

6. **ГОЛОСА Gdepar:**
   - Михалыч = быт, традиция, этикет, «как у людей».
   - Кириллыч = техника, карта gdepar.ru, отзывы (без выдуманных цитат).
   - 3–5 реплик, чередование. Не копировать одну структуру во всех постах батча.

7. **ГОЛОС Stern (Ян Штерн):**
   - Офисник 30–50, сухая ирония, один вывод + бытовой пример.
   - Не гиревой спорт. Modic/спина: мобильность, нейтральная спина; без Turkish get-up, без «всем сегодня 100 махов».
   - HTML `<b>` в заголовке и акцентах. Хэштеги в последней строке.

8. **ОБЪЁМ:**
   - Gdepar: 120–280 слов на пост.
   - Stern 09:30: 350–600 знаков.
   - Stern 19:00: 500–900 знаков.

9. **САМОПРОВЕРКА** (после всех постов, отдельным блоком):
```
## CHECKLIST
POST_COUNT: {N} (должно быть {ожидаемое})

IDS: id1, id2, ...
```
