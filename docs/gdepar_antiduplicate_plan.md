# Gdepar TG: почему посты «одинаковые» и что делаем

**Симптом:** не просто одна тема (полка, тишина), а **почти тот же текст** снова и снова.

**Причина в системе (до правки):**

| Что было | Чего не хватало |
|----------|-----------------|
| Память **тем** (TopicHistory) | Памяти **текста** поста |
| Штраф семейств тем | Проверки «похож ли готовый текст на прошлый» |
| temperature 0.2 для всех | Низкая вариативность у Михалыча |
| Self-critique только при клише | Принудительной уникальности тела |

---

## Украдем у конкурентов?

**Нет — не копируем.** Иначе бан, репутация, юридически слабо.

**Да — забираем схему:**

```
Конкурент (zhivayabanya / obrazpar) — взлётевший пост
    → Spy: только тема + структура (список? история? ошибка?)
    → Михалыч: свой текст, свой Кириллыч, своя шутка
    → Карта gdepar.ru в конце (если уместно)
```

Это не «воровство», а **редакционная переработка** — как все медиа.

---

## План (код + процесс)

### Уже в коде (деплой + restart empire_main)

1. **Память текстов** — в prompt последние 5 постов (обрезка), запрет копировать.
2. **Проверка после генерации** — Jaccard по телу; если ≥72% — переписать; ≥58% — смягчённое предупреждение.
3. **temperature 0.55** только для gdepar (остальные 0.2).
4. **Self-critique** для gdepar почти всегда (уникальность).
5. **Spy → черновик** — в теме явно «не копия конкурента».
6. **cooldown** семейств тем 21 день.

### Процесс (вы)

| Действие | Частота |
|----------|---------|
| Approve только если текст **визуально другой** | каждый пост |
| Раз в неделю — слот **spy_inspired** (вс) | авточерновик |
| Раз в 2 недели — пост **[Литература]** | цитата + коммент |
| Промо карты — 1×/нед | уже в расписании |
| Не публиковать «на автомате» без чтения | пока quality не ок |

## Если снова повторится

1. В дашборде откройте последние 5 gdepar — сравните тексты.

3. Временно: **Regen** в боте + правка руками 2 предложений — быстрее всего.
