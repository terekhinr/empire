## 4. Порядок: рывок vs толchок

| Источник | Порядок | Аргумент |
|----------|---------|----------|
| **Гorbunov / InfoUrok** | **Сначала рывок** | «Наиболее понятное для начинающих» |
| **Каширин (mosgiri)** | Мах → clean → **толchок** → **рыvok** | Фитнес-круг |
| **Денисов** | Отдельные курсы; ДЦ = clean + jerk | Соревновательная специализация |
| **Руднев (YouTube)** | Параллельные серии по каждому элементу | Не жёсткая линейная программа |

**Решение для «Снегири»:** после clean + жим + TGU идёт **high pull → рыvok → тolchok** (классика + логика «рыvok сложнее одной руки вверх, толchok опирается на стойку двух гирь у нас — одна»).
