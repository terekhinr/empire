# Sonoff BASICR2 в Home Assistant — сделать сейчас

**HA:** `http://192.168.1.41:8123` (Tailscale `100.80.133.85`)  
**Модель:** 2× **SONOFF BASICR2** (eWeLink, **не** Tuya)  
**Интеграция:** **SonoffLAN** (HACS) → в HA называется **Sonoff**  
**Tuya / LocalTuya** — отдельно, **позже**.

Полная версия с теорией и Tasmota: [`HA_SONOFF_BASICR2.md`](HA_SONOFF_BASICR2.md).

---

## Не путать

| Это | Не это |
|-----|--------|
| Wi‑Fi реле **BASICR2** в eWeLink | Zigbee **донгл** Sonoff (ZHA) |
| Интеграция **Sonoff** (SonoffLAN) | **LocalTuya** |
| Приложение **eWeLink** | Smart Life |

---

## Порядок (≈ 45–60 мин на оба реле)

```text
eWeLink (оба реле онлайн) → IP на роутере → HACS SonoffLAN → HA Sonoff (auto)
→ Areas → тест → записать entity_id
```

---

## Шаг 0. Подготовка

- [ ] Оба реле **уже** в **eWeLink**, свет из приложения вкл/выкл.
- [ ] Wi‑Fi **2.4 GHz**, тот же роутер, что HA (`192.168.1.x`).
- [ ] **HACS** в HA работает.
- [ ] Решили **комнаты** (не гостевая / не Макс — там план ИК Broadlink).

Имена в eWeLink сразу понятные, например:

- `Свет кухня`
- `Свет спальня`

---

## Шаг 1. Постоянный IP (роутер)

Для **каждого** BASICR2:

1. eWeLink → устройство → **MAC** (или наклейка на корпусе).
2. Роутер Keenetic / др. → **DHCP reservation** / «Зарезервировать IP».
3. Записать:

| Имя в eWeLink | MAC | IP |
|---------------|-----|-----|
| Свет … | | 192.168.1. |
| Свет … | | 192.168.1. |

---

## Шаг 2. HACS — SonoffLAN

1. HA → **HACS** → **Интеграции**.
2. **⋮** (справа вверху) → **Пользовательские репозитории**.
3. URL: `https://github.com/AlexxIT/SonoffLAN`  
   Категория: **Интеграция** → **Добавить**.
4. **HACS** → поиск **SonoffLAN** → **Установить**.
5. **Настройки → Система → Перезагрузка** (полная перезагрузка HA).

---

## Шаг 3. Интеграция Sonoff в HA

1. **Настройки → Устройства и службы → Добавить интеграцию**.
2. Найти **Sonoff** (иконка eWeLink/Sonoff, **не** ZHA).
3. Логин и пароль **eWeLink** (как в приложении на телефоне).
4. Регион: как при регистрации (**+7 / Russia**).
5. **Mode: `auto`** — не менять на `local` для BASICR2.
6. Дождаться списка устройств → **Готово**.

Должны появиться **оба** BASICR2.

---

## Шаг 4. Области и имена

Для каждого устройства:

1. **Настройки → Устройства** → открыть реле.
2. **Область** — Кухня / Спальня / …
3. **Настройки → Сущности** → `switch.*` → переименовать, например:
   - `switch.kuhnya_svet`
   - `switch.spalnya_svet`

Запишите **реальные** `entity_id` из HA — они могут отличаться (`switch.sonoff_...`).

---

## Шаг 5. Проверка

| Тест | Ожидание |
|------|----------|
| Вкл/выкл в HA | свет реагирует |
| Вкл/выкл в eWeLink | HA обновляет состояние |
| Журнал, фильтр `sonoff` | без ERROR при переключении |

**Опционально (LAN):** отключить интернет на WAN роутера на 1–2 мин → переключить из HA.  
Если работает — LAN ок; если нет — всё равно может работать через облако в режиме `auto`.

---

## Шаг 6. SSH (если реле не видно)

На armbian:

```bash
# мост жив (для других задач)
curl -s -m 3 http://127.0.0.1:8766/health

# HA видит LAN
docker exec homeassistant curl -s -m 5 http://172.30.32.1:8766/health

# ping реле (подставьте IP)
ping -c 2 192.168.1.XX
```

В HA: **Настройки → Sonoff → Перезагрузить**; проверить, что Wi‑Fi клиенты не в гостевой VLAN без доступа к HA.

## Если не заводится

| Симптом | Действие |
|---------|----------|
| Нет устройств после входа | eWeLink: оба **Online**; перелогин в интеграции |
| `unavailable` | IP на роутере; перезагрузка реле; режим **auto**, не `local` |
| Путается с ZHA | Интеграция именно **Sonoff**, не «Zigbee Home Automation» |
| Нужно 100% без облака | позже **Tasmota** — см. `HA_SONOFF_BASICR2.md` §4 |
