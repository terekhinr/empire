# Трек K v3 · лестница по Блуд / Каширин / Алферова

**Дата:** июль 2026  
**Код:** `snegiri_kb/program_data.py` · `static/snegiri/js/program.js`  
**Было:** 11 упражнений, 6 фаз × 4 нед — без подводящих, свинг сразу после hinge+goblet  
**Стало:** **17 шагов**, **10 фаз** × ~2,5 нед (**170 дней**)

---

## 1. Что изучали у школ (публичные программы)

| Школа | Логика прогрессии | Что взяли |
|-------|-------------------|-----------|
| **Виктор Блуд** (вводный + 4-нед.) | Разминка → как брать гирю → **наклон** → **присед goblet** → подготовка стойки → **свинг** → жим / турлиш → элементы рывка | Dead stop, goblet до свинга, стойка до заброса |
| **Сергей Каширин** (mosgiri) | **Мах** → подъём на грудь → швунг → **толчок** → **рывок** → **комплексы** + статика для суставов | Порядок: swing → clean → press → snatch → complex |
| **Валентина Алферова** | Стойка (треугольник локтей), **толчок/рывок/ДЦ** — для тех, кто уже держит гирю | Фаза «Стойка», толchок после рывка (соревновательный слой) |
| **StrongFirst / RKC** | Hinge → swing → **get-up** → clean → press → snatch | TGU после жима, до тяжёлого рывка |

**Принцип v3:** один **новый паттерн** на фазу; в rotation — **1–2 подводящих** из прошлых фаз (maintenance).

## 3. Сравнение v2 → v3

| | v2 | v3 |
|--|----|----|
| Шагов K | 11 | **17** |
| Фаз K | 6 × 28 дн | **10 × ~17 дн** |
| Дней K | 168 | **170** |
| Подводящие | hinge+goblet → сразу swing | **dead stop, halo, rack hold, high pull** |
| TGU vs press | TGU до press (фаза 4) | **Press → TGU** (SF/Blud) |
| Snatch prep | нет | **K14 high pull** |
| Front squat | нет | **K9** после clean |

---

## 4. Разблокировка фаз (без изменений)

- ≥8 CV-сессий в фазе со score ≥7  
- ≥3 разбора **босс-упражнения** фазы  
- Календарь не пропускает вперёд без unlock  

---

## 5. Что не включено (намеренно)

| Элемент | Почему |
|---------|--------|
| Hand-to-hand передача | Следующий релиз после v3 validation |
| Длинный цикл (ДЦ) | Отдельная фаза K+ после 170 дней |
| Windmill, bent press | K+ контент |
| Жонглирование (Блуд) | Не домашний MVP |
