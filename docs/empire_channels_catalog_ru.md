# Empire: Pension + Gdepar + Финансы — каталог с пояснениями

Согласовано 2026-06-29. Источники сведены: `Empire/_scenarios/checklists/` (07, 08, 13), `data/empire_finance_ledger.json`, «Грубая финансовая модель» (Медиаимперия).

В приложении: **3 проекта** + **4 ритуала-чеклиста** (в т.ч. общий автопост) + **% прогресса** в шапке проекта.

**Важно:** проекты `Empire · Gdepar/Pension/Финансы` содержат **только** задачи из Obsidian (`obsidian_source=empire:obsidian:*`). Личные задачи из TickTick **не входят** в эти проекты и не могут там закрываться.

**Автопост (июнь 2026):** все каналы — garden, gdepar, stern, lenin, pension — в едином пайплайне `data/auto_publish.json`. Ритуал: «Ритуал · Автопост все каналы (ежедневно)».

---

## Как читать пункт

Каждая задача в проекте содержит в заметке:
- **След. шаг** — что сделать прямо сейчас
- **Проект** — к какому блоку пайплайна относится
- **Источник** — файл Obsidian / сценарий
- **Финмодель** — зачем это для денег/метрик

## Прогресс в приложении

- **Проект:** % = закрытые / (открытые + закрытые) по задачам проекта.
- **Чеклист:** % пунктов с галочкой; в шапке проекта — сводка по связанным ритуалам.
- В боковом меню у проектов `Empire ·` показывается **%** вместо числа открытых.

Повторный импорт: `./venv/bin/python scripts/import_empire_obsidian_channels.py` (не дублирует задачи).  
Синхронизация текстов: `--sync`. Отвязка ошибочных TickTick: `--unmerge-ticktick`.
