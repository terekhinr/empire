## Универсальные `image_mode` у рубрики (зафиксировано)

В UI у каждой рубрики канала — выбор **одного** режима:

| Как в UI | Код | Поведение |
|----------|-----|-----------|
| **Генерация на лету** | `generate` | Промпт рубрики/поста → Gemini → файл. Ошибка → `on_missing` |
| **Из базы (пул)** | `archive_pool` | Файл из библиотеки/папки рубрики |
| **Одна и та же** | `fixed` | Всегда один файл рубрики |
| **Своя у каждого поста** | `post` | Нужен `image_path` у поста |
| **Без картинки** | `none` | Только текст |

`on_missing` / сбой `generate`: **`stub`** + ops-алерт.
