## 1. Стратегия в одном абзаце

**Главный проект:** Pension («На пенсию НИКОГДА») — **YouTube + нативная реклама** (основной доход), сайт, книга, Дзен.  
**Спутники:** Garden, Gdepar, Stern, Lenin — трафик и прогрев к Pension; не отдельные бизнес-линии.  
**Дорожная карта 12 мес:** `docs/pension_youtube_roadmap_12m_2026.md`.  
**Принцип 2026:** рост **без VPN** (ВК + Дзен + сайты); TG — ядро и модерация.  
**Юр. режим:** **НПД (самозанятый)** до ~2,4 млн ₽/год выручки; чеки на каждую оплату.  
**Инфра:** VPS + API ≤ целевого потолка расходов (см. §3).

### 3.3. Потолок из решений заказчика

**≤ 3 000 ₽/мес** — цель только на **LLM + S3 + мелочь** (`TZ_FINAL` §0).  
**VPS ~2 400 ₽** — **отдельно**, иначе суммарно **~5 500–6 000 ₽/мес** на всю Empire — закладывать в план реалистично.

**Правило:** если **сумма расходов Empire > 6 000 ₽/мес** два месяца подряд без роста выручки — стоп реклама, ревизия LLM, отложить необязательные API.

## 6. Метрики: что отслеживать

### 6.1. Уровни

| Уровень | Вопрос | Частота |
|---------|--------|---------|
| **L0 Инфра** | VPS жив, бэкапы, бюджет LLM | ежедневно авто / алёрт |
| **L1 Охват** | Подписчики, просмотры, сессии сайта | **еженедельно** |
| **L2 Вовлечение** | ER, дочитывания, approve→publish | еженедельно |
| **L3 Воронка** | Клик → лид → оплата | еженедельно при продажах |
| **L4 Деньги** | Выручка, маржа, CAC, ROMI | **ежемесячно** |

## 7. Регламент контроля

### 7.1. Еженедельно (воскресенье или понедельник, 30–45 мин)

1. Заполнить строку в **сводной таблице** §6.2 (или Obsidian growth checklist).  
2. Обновить `data/pension_weekly_metrics.json` если трогали Pension.  
3. Сверить **расходы** за неделю с ledger.  
4. Просмотреть **дашборд**: очередь approve, ошибки publish, spy/neuro.  
5. Одно решение: **продолжать / ускорить / остановить** (реклама, нейро, новый продукт).

### 7.2. Ежемесячно (1-е число)

1. P&L §4.4.  
2. НПД: сумма выручки, % от лимита 2,4 млн.  
3. Сравнить **факт LLM** с потолком §3.  
4. Обновить статусы в `empire_master_backlog.md` / checkpoints.  
5. Записать **3 гипотезы** на следующий месяц (из AI Insights или вручную).

### 7.3. Квартально

- Пересмотр приоритетов персон (Pension vs спутники).  
- Решение: реклама ВК, launch книги, апгрейд VPS/ПК.  
- Сверка с `empire_master_plan_rf_2026.md` фазы A–D.

## 8. Сигналы «стоп / ускорить»

| Сигнал | Действие |
|--------|----------|
| 2 месяца расходы > 6 000 ₽, доход 0 | Стоп реклама, LLM ревизия, не масштабировать Spy |
| Garden ВК >300, продаж 0 | Включить оплату / tripwire, проверить CTA |
| gdepar.ru рост, карта стагнирует | Приоритет парсер/контент карты, не LLM |
| Pension launch, CR buy <1% | Правка `/buy`, цена, отзывы, не реклама |
| НПД >80% лимита | План перехода ИП или пауза платных продуктов |
| Всё зелёное 2 месяца | +реклама 3–5 тыс. на **один** канал, A/B UTM |
