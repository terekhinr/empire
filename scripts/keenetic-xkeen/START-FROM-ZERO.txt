=== ЧАСТЬ 1 — ФЛЕШКА НА ПК (WSL) ===

1. Вытащи маленькую флешку (12–16 ГБ) из роутера, воткни в ПК.
2. PowerShell → wsl → lsblk  (найди флешку, НЕ системный диск!)

3. Замени sde на свою букву:

   sudo parted /dev/sde --script mklabel gpt
   sudo parted /dev/sde --script mkpart primary ext3 1MiB 1025MiB
   sudo parted /dev/sde --script mkpart primary ext4 1025MiB 100%
   sudo mkswap /dev/sde1
   sudo mkfs.ext4 -L OPKG /dev/sde2
   sudo mkdir -p /mnt/usb
   sudo mount /dev/sde2 /mnt/usb
   sudo mkdir -p /mnt/usb/install
   sudo wget -O /mnt/usb/install/mipsel-installer.tar.gz \
     https://bin.entware.net/mipselsf-k3.4/installer/mipsel-installer.tar.gz
   ls -la /mnt/usb/install/
   sudo umount /mnt/usb
   exit

   Файл: install/mipsel-installer.tar.gz  (именно mipsel, не mips!)

=== ЧАСТЬ 2 — РОУТЕР: ENTWARE ===

4. Флешку в USB-порт 2 роутера (большой NTFS — порт 1).

5. Keenetic Web → Управление → OPKG:
     Накопитель = EXT4 ~12.7 ГБ (не SWAP, не NTFS, не встроенное)
     Доступ = вкл
     initrc = пусто
     Сохранить → перезагрузка

6. Диагностика → журнал: "Entware installed!"

7. Telnet 192.168.1.1:23 → admin → exec sh

   mount | grep 'on /opt '
   # должно: /dev/sdb2 ext4

   opkg update

   НИКОГДА не вводи: no opkg disk
