# Life/tasks — замена TickTick

Синхронизация: **Яндекс.Диск** (ПК + телефон). VPS эту папку **не меняет**.

## Obsidian (ПК и телефон)

1. Community plugin **Tasks**
2. Закладка: `Life/tasks/dashboard.md`
3. Новые задачи: `Life/tasks/inbox.md`

Формат строки:

```markdown
- [ ] Купить молоко 📅 2026-06-01 #дом
```

## Напоминания на Android

**Tasks.org** (бесплатно) — только задачи **с временем**, которые должны пикнуть.

Планирование и списки — в Obsidian.

## Импорт TickTick

CSV с ticktick.com → `Life/tasks/_import/` → скрипт на ПК или вручную в `inbox.md`.
