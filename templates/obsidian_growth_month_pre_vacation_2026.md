# Месяц до отпуска (Empire)

> **Куда в vault:** `Empire/_scenarios/month-pre-vacation-2026.md`  
> **День:** `templates/obsidian_growth_daily_note.md` (копия в Daily Notes)  
> **Принцип:** новых каналов нет — выверяем то, что есть. Пенсия = смысл; Сад/Гдепар = рост и деньги позже.

**Как пользоваться:** в начале месяца отметьте неделю W в Obsidian; каждую неделю — блок «Неделя N»; ежедневно — только [[growth-rf-2026#День]] / daily note.

---

## Цели месяца (реалистично)

| # | Результат к отпуску |
|---|-------------------|
| 1 | Автопост **стабилен**: approve без пропусков >5 дней подряд |
| 2 | **Метрика** на gdepar.ru + neverretire.ru, 1–2 цели видны в отчёте |
| 3 | **Сад:** ВК оформлен + **10+** постов + **2** статьи Дзен |
| 4 | **Гдепар:** **8+** постов ВК с UTM + **15+** точек с отзывами на карте |
| 5 | **Пенсия:** график TG + **1** материал под книгу/сайт |
| 6 | Инфра из Todoist: почта gdepar, SIM/ТГ — **только если** успеете (не блокер отпуска) |

## Неделя 1 — качество и метрика

### Инфраструктура (из скрина + REMINDERS)

- [ ] **Метрика gdepar:** `YANDEX_METRIKA_ID` в env → restart → `metrika_goals_setup.md`
- [ ] **Метрика pension / neverretire.ru:** счётчик + цели (те же правила)
- [ ] Проверка: «Пар?» на gdepar, 1 тестовый goal в кабинете
- [ ] **Почта gdepar:** ящик с домена → в контакты сайта и Telegram (bio/закреп)

### Автопост Empire

- [ ] Расписание TG: все 5 персон публикуются после approve (без «забытых» слотов 3 дня)
- [ ] Gdepar: меньше повторов (проверить 3 поста на клише)
- [ ] Pension: режим **raw_news** по умолчанию; разбор — только из дашборда
- [ ] Stern: рубрики **с фото** (не пропускать approve без картинки)

### Сад

- [ ] ВК: аватар, описание, закреп (ссылка TG или PDF)
- [ ] 2–3 поста ВК из лучших TG-постов

### Пенсия

- [ ] Идея в очередь: **«пилить гири»** — только если в тему моста здоровье (опционально в Штерн)
- [ ] Идея в очередь: **средний возраст / «старперы и мир»** — черновик Obsidian
- [ ] Идея в очередь: **акции и «всё колхозное моё»** — без инвестсоветов, с дисклеймером

## Неделя 2 — рост ВК + Дзен

### Сад (приоритет №1)

- [ ] 3 поста ВК
- [ ] 1 статья Дзен (1500–2500 зн.) → ссылка на ВК
- [ ] 1 клип ВК 30–45 с (или черновик сценария)
- [ ] TG: approve по `garden_posting_matrix_2026.md`

### Гдепар (приоритет №2)

- [ ] ВК: сообщество создано/оформлено
- [ ] 2 поста с **gdepar.ru** + UTM
- [ ] 1 статья Дзен с UTM
- [ ] Сайт: **+5** отзывов на разных банях (залп или inspector)

### Штерн

- [ ] 1 клип ВК
- [ ] Пост «**пилить гири**» (выражение / рубрика) — approve + фото

### Техника

- [ ] `VK_ACCESS_TOKEN` — получить и **1** тест `vk_wall` из дашборда
- [ ] Записать подписчиков: Сад ВК, Гдепар ВК, Пенсия TG (таблица внизу)

---

## Неделя 3 — продукт и пенсия

### Сад

- [ ] Ещё 3 поста ВК (итого **8+** за месяц к этому моменту)
- [ ] PDF tripwire: в документах ВК **или** waitlist в боте (одно из двух)
- [ ] 1 статья Дзен

### Гдепар

- [ ] 3 поста ВК
- [ ] Obsidian: **2** своих текста в `gdepar/queue` → импорт → approve
- [ ] Промо карты: слот понедельник 10:00 не пропущен

### Пенсия

- [ ] TG: стабильный график 2–3/день (или ваш согласованный)
- [ ] **1** пост из очереди: средний возраст / влияние поколений
- [ ] **1** связка TG → статья на neverretire.ru **или** черновик Дзен
- [ ] Книга: 1 шаг (`pension_book_publish_tz.md`) — оглавление / глава / `/buy` черновик

### Штерн

- [ ] 2 клипа ВК
- [ ] Решение: дата съёмки урока **1 из 3**

## Неделя 4 — закрытие перед отпуском

### Перед отпуском (обязательно)

- [ ] Approve запас **на 3–5 дней** отпуска (или пауза autopublish в `auto_publish.json` — осознанно)
- [ ] VPS: таймеры cron/rclone работают (`YANDEX_RCLONE_START.md`)
- [ ] Боты: токены и `systemctl` без failed
- [ ] Таблица метрик месяца заполнена (см. ниже)

### Сад

- [ ] Итого **10+** постов ВК за месяц
- [ ] Цель: **+50…100** подписчиков ВК (подставьте факт)

### Гдепар

- [ ] **15+** точек с **3+** отзывами на карте
- [ ] Итого **8+** постов ВК за месяц

### Ретро месяца

- [ ] Что выросло / что нет
- [ ] 1 гипотеза на после отпуска (не больше)

## Из Todoist — в месяц, не срочно каждый день

|----------------|--------|----------------|

| Почта с сайта gdepar в контакты | **Неделя 1** | P1 |
| ВК и Дзен под свои аккаунты | **Неделя 2–3** | после оформления; ИП — когда готов |
| Макс запустить | **После отпуска** | не блокер (`growth_rf_no_max_2026.md`) |
| ТГ партизанщина: SIM МТС + новый ТГ | **Неделя 3–4 или после отпуска** | только для Spy; не блокер роста |
