# ТЗ: Локальная образовательная платформа "Empire Practicum"

## 1. Концепция платформы
Платформа представляет собой локальный монорепозиторий в Cursor/VS Code, который объединяет теорию, практику и систему автоматической проверки кода.

**Архитектура платформы:**
*   **Движок:** Python (локально) + `pytest` (для автоматической проверки заданий).
*   **Интерфейс:** Текстовый редактор Cursor. Задачи описаны в файлах `task.md` внутри каждой папки-урока.
*   **Трекинг прогресса:** Локальный файл `progress.json` и скрипт `dashboard.py`.
*   **Ментор:** ИИ Cursor (`.cursorrules`), который даёт подсказки, но не пишет решения за студента.
