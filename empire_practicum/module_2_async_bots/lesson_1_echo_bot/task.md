# Урок 2.1 — Эхо-бот (логика без реального токена)

## Зачем это нужно
Telegram-бот отвечает на сообщения асинхронно. Прежде чем подключать токен, научись выделять **чистую логику**: «что ответить на этот текст?». Так тесты работают без сети.

## Теория (кратко)
1. **`async def`** — асинхронная функция. Внутри можно `await` ждать I/O.
2. В Aiogram 3 хендлер выглядит так:
   ```python
   @router.message()
   async def echo(message: Message):
       await message.answer(message.text)
   ```
3. **Фильтры** — решать, какой хендлер сработает (`Command("start")`, `F.text`, …).

Аналогия: эхо — как зеркало в переговорке. Сказал «привет» — услышал «привет» обратно. Бот делает то же самое, только через API Telegram.

## Твоя задача
В `solution.py` реализуй **чистые** (синхронные) функции — их проверят тесты. Потом по желанию оберни их в aiogram-хендлеры.

### 1. `echo_text(text: str | None) -> str`
- Если `text` — обычная строка: верни её же.
- Если `text is None` (стикер, фото без подписи): верни `"Я понимаю только текст 📝"`.
- Если `text` пустая строка `""`: верни `"Пустое сообщение"`.

### 2. `handle_command(text: str) -> str | None`
- Если текст начинается с `/start` — верни приветствие:
  `"Привет! Я эхо-бот Empire Practicum. Напиши что угодно."`
- Если `/help` — верни:
  `"Команды: /start, /help. Остальное я повторю."`
- Иначе верни `None` (это не команда — пусть сработает эхо).

### 3. `build_reply(text: str | None) -> str`
- Сначала попробуй `handle_command` (если text не None).
- Если команда распознана — верни её ответ.
- Иначе верни результат `echo_text(text)`.
