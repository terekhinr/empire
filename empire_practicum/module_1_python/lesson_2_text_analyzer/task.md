# Урок 1.2 — Анализатор текста

## Зачем это нужно
В B2B-ботах часто нужно разбирать текст: считать слова в заявке, искать ключевые фразы, строить статистику. Словари (`dict`) — главный инструмент для «подсчёта чего угодно».

## Теория (кратко)
1. **Строка** — последовательность символов. Методы: `.lower()`, `.split()`.
2. **Цикл `for`** — пройтись по списку слов по одному.
3. **Словарь** — пары «ключ → значение». Удобно хранить `{"слово": сколько_раз}`.
4. **`.get(key, 0)`** — безопасно прочитать значение, если ключа ещё нет.

Аналогия: словарь — как ящик с ячейками. На каждой ячейке табличка (слово), внутри — счётчик.

## Твоя задача
В `solution.py` реализуй три функции:

### 1. `count_words(text: str) -> dict[str, int]`
- Приведи текст к нижнему регистру.
- Разбей по пробелам (`split()` без аргументов).
- Посчитай, сколько раз встречается каждое слово.
- Пустая строка → пустой словарь `{}`.
- Знаки препинания пока **не** удаляй (считай `"привет,"` и `"привет"` разными — упростим себе жизнь).

Пример:
```text
"Hello world hello"  →  {"hello": 2, "world": 1}
```

### 2. `most_common_word(text: str) -> str | None`
- Верни слово с максимальным числом вхождений.
- Если текст пустой — верни `None`.
- При ничьей верни любое из слов-победителей (тесты проверят одно из допустимых).

### 3. `word_count(text: str) -> int`
- Верни общее количество слов (после `split()`).
- Пустая строка → `0`.
