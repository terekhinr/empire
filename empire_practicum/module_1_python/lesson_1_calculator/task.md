# Урок 1.1 — Калькулятор

## Зачем это нужно
Калькулятор — классика первого проекта: ты учишься принимать данные, ветвить логику (`if/else`) и возвращать результат из функции. Это фундамент любого бэкенда: «вход → правило → выход».

## Теория (кратко)
1. **Функция** — именованный блок кода. Объявляется через `def`.
2. **Аргументы** — значения, которые ты передаёшь в функцию.
3. **`if / elif / else`** — ветвление: «если операция сложение — сложи, иначе…».
4. **`return`** — вернуть результат вызывающему коду (тестам или `print`).

Аналогия: функция — как окошко кассы. Ты подаёшь два числа и операцию, касса выдаёт чек с ответом.

## Твоя задача
В файле `solution.py` реализуй функцию:

```python
def calculate(a: float, b: float, operation: str) -> float:
    ...
```

### Требования
| `operation` | Результат |
|-------------|-----------|
| `"+"`       | `a + b`   |
| `"-"`       | `a - b`   |
| `"*"`       | `a * b`   |
| `"/"`       | `a / b`   |

- При делении на ноль (`b == 0` и `operation == "/"`) верни строку `"Error: division by zero"` (да, тип возврата смешанный — так задумано для практики).
- При неизвестной операции верни строку `"Error: unknown operation"`.
