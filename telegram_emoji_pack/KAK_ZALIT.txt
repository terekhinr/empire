Варианты:

  variant_2_mult     — мультяшный стикер

В каждом варианте две папки:
  stickers_512/  — обычные стикеры 512×512 PNG (с текстом). Заливать в @Stickers → /newpack
  emoji_100/     — кастомные эмодзи 100×100 PNG (без текста, чтобы читались в строке).
                   Заливать в @Stickers → /newemojipack
                   Нужен Telegram Premium.

Как залить стикеры (рекомендуется — текст на них читается)
----------------------------------------------------------
Бот @Stickers шлёт StickerExample.psd — это шаблон вида, не файл для заливки.
Заливать нужно PNG из папок export_png/ (белый контур + тень, 512×512, прозрачный фон, <512 КБ).

1. Telegram Desktop → чат @Stickers → Start
2. /newpack
3. Название, например: Пролетарское танго • фото
4. Короткое имя латиницей, уникальное, например: proletarian_tango_foto
5. Каждый PNG из export_png/ отправлять как ФАЙЛ (скрепка → File), не как сжатое фото
6. После каждого файла бот просит «связанный эмодзи». Можно так:
     01 😄
     02 🙅
     03 ❤️
     04 🌲
7. /publish

Архивы для заливки:
  variant_1_foto_export.png.zip
  variant_2_mult_export.png.zip
  variant_3_vintazh_export.png.zip
  ALL_export_png.zip

Как залить кастомные эмодзи
---------------------------
1. @Stickers → /newemojipack
2. То же самое, файлы из emoji_100/
3. После публикации ссылка вида t.me/addemoji/...

Готовые архивы лежат рядом: variant_1_foto.zip, variant_2_mult.zip, variant_3_vintazh.zip
