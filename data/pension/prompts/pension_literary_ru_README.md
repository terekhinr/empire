# Алиса / GigaChat: один файл за раз

В Алису **не влезает** система + статья + SOURCES. Рабочий режим — **один paste**.

## Быстрый путь

```bash
# из корня репо или из этой папки:
python3 data/pension/prompts/make_alice_paste.py 00   # или 01 02 03 04 / all
```

Открой `data/pension/prompts/alice_ready/alice_00_manifest.md` → **скопировать всё** → одно сообщение в Алису.

Повтори для следующей статьи новым чатом (или новым сообщением только с новым `alice_0N_…md`).

## Вручную

Шаблон: `pension_alice_one_paste.md`  
Вставь **один** `dzen/0N_….md` между `<<<СТАТЬЯ` и `СТАТЬЯ>>>`. Больше ничего не прикладывай.

## Полные правила (для агента / длинного контекста)

`pension_literary_ru_system.md` — развёрнутая система. В Алису целиком **не** тащи, если уже используешь `pension_alice_one_paste.md` / `alice_ready/*`.

## Объёмы

| | символов с пробелами |
|--|--|
| мало | < 8 000 |
| лонгрид | 12 000–18 000 |

В конце ответа Алисы должна быть строка `Объём: …`. Если меньше 12 000 — в том же чате: «Допиши до 15 000, не лей воду».
