# YT-000 · Рамки кадра для AI-картинок (Gemini / любой генератор)

**Мастер-кадр монтажа:** 1920×1080 px · 16:9 · sRGB  
**Папка:** `images/` · промпты — `images_config.json` + `image_prompts.md`

---

## Общие правила

| Параметр | Значение |
|----------|----------|
| Генерация | **16:9** (Gemini: `aspectRatio: "16:9"`, `imageSize: "2K"` → upscale до 1920×1080) |
| Растягивание | Допустимо **uniform scale** до 1920×1080; **не** растягивать по одной оси |
| Кроп | Если кадр 1344×768 — **center crop** или **letterbox** на `#0d1117`, не обрезать лица по краю |
| Текст на картинке | **Не генерировать** — титры и цифры в монтаже |
| Safe zone | Центральные **80%** ширины и **75%** высоты — главный объект; края под титры/графику |

```
┌──────────────────────────────── 1920 ────────────────────────────────┐
│ ░░░░░░░░░░░░░  верх 12% — титр, не класть лицо  ░░░░░░░░░░░░░░░░░░░ │
│ ░  ┌──────────────────────────────────────────────────────┐  ░     │
│ ░  │           SAFE ZONE (1536 × 810)                      │  ░ 10%│
│ ░  │              сюда — герой, метафора                   │  ░     │
│ ░  └──────────────────────────────────────────────────────┘  ░     │
│ ░░░  низ 18% — субтитры, insight-полоса графиков  ░░░░░░░░░░░░░░░░ │
└────────────────────────────────────────────────────────────────────┘
```

**Negative (ко всем):** `text, letters, numbers, watermark, logo, readable signs, distorted hands, extra fingers`

**Style A** (фото): см. `image_prompts.md` раздел 0  
**Style B** (схема): см. `image_prompts.md` раздел 0

## Промпт-обёртка (копировать к каждому)

**В начало промпта из `images_config.json`:**
```
16:9 aspect ratio, 1920x1080 master frame, main subject in central safe zone,
leave top 12% and bottom 18% relatively empty for titles, no text in image,
```

**В конец — Style A или B из `image_prompts.md`**

---

## Gemini (пример `generationConfig`)

```json
{
  "responseModalities": ["IMAGE"],
  "responseFormat": {
    "image": {
      "aspectRatio": "16:9",
      "imageSize": "2K"
    }
  }
}
```

После сохранения: resize → **1920×1080** (LANCZOS), как в `generate_yt000_images_gemini.py`.
